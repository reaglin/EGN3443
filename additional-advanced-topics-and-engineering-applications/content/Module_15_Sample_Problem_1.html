Design of Experiments in Materials Engineering: Optimization of Polymer Composite Properties

This is a comprehensive example of Design of Experiments (DOE) for optimizing a polymer composite material used in aerospace engineering. This example demonstrates key DOE principles while providing practical code and visualizations.

Problem Statement

An aerospace engineering team needs to develop a lightweight polymer composite with optimal mechanical properties for aircraft interior panels. They need to understand how processing factors affect the final material properties.

Factors to investigate:

  1. Curing temperature (°C)
  2. Curing time (hours)
  3. Filler content (% by weight)
  4. Mixing speed (RPM)

Response variables:

  1. Tensile strength (MPa)
  2. Impact resistance (J/m)
  3. Weight density (g/cm³)

Design of Experiments Concepts Implemented

1. Factorial Design

The example implements a full 2^4 factorial design with four factors at two levels each, resulting in 16 experimental runs. This approach:

  • Allows estimation of all main effects and interactions
  • Provides comprehensive coverage of the experimental space
  • Creates a foundation for understanding factor relationships

2. Fractional Factorial Design

I implemented a 2^(4-1) fractional factorial design with 8 runs, using the generator relationship D = ABC. This:

  • Reduces experimental effort by half compared to the full factorial
  • Confounds some higher-order interactions
  • Remains efficient for initial screening of significant factors

3. Response Surface Methodology (RSM)

The Central Composite Design (CCD) builds on factorial designs by adding:

  • Center points (5 replicates at factor level 0)
  • Axial points at ±α from center (α=1.414)
  • Enables quadratic modeling of response surfaces
  • Allows optimization of factor settings

4. Experimental Units

Each run constitutes an experimental unit with:

  • Unique identifier (Unit_ID)
  • Specific treatment combination
  • Complete randomization of run order

5. Randomization

The design implements randomization through:

  • Random run order assignment
  • Block structure to account for potential day-to-day variations
  • Visualization of the randomization pattern

6. Replication

Replication is incorporated through:

  • Five center point replicates in the CCD design
  • Analysis and visualization of replicate variability
  • Estimation of pure experimental error

Results Analysis

Factor Effects Analysis

From the Pareto charts, we can observe:

  1. Tensile Strength: Most influenced by filler content, temperature, and their interaction. Higher filler content and temperature generally increase tensile strength up to optimal levels.
  2. Impact Resistance: Negatively affected by higher filler content and temperature, with mixing speed showing a positive effect.
  3. Weight Density: Primarily driven by filler content, with processing conditions having minimal effects.

Response Surface Analysis

The contour and 3D surface plots reveal:

  1. Curvilinear Relationships: Non-linear responses to factor changes, with clear optimal regions.
  2. Factor Interactions: Significant interactions between temperature and filler content affect material properties.
  3. Trade-offs: Optimal settings for tensile strength may compromise impact resistance or weight density.

Optimization Results

The optimal settings found balance all three responses:

  • Temperature: Slightly above midpoint
  • Time: Closer to higher level
  • Filler: Moderate level (optimal balance between strength and weight)
  • Mixing Speed: Higher level

These settings are predicted to yield excellent tensile strength while maintaining good impact resistance and reasonably low weight density.

Benefits of DOE in Engineering Practice

  1. Resource Efficiency: Minimizes the number of experiments needed to understand complex systems
  2. Quantitative Understanding: Provides mathematical models of how factors affect responses
  3. Optimization: Enables finding optimal conditions for multiple, sometimes competing objectives
  4. Risk Reduction: Reduces development time and costs by focusing on critical factors
  5. Scientific Insight: Reveals interactions between factors that might be missed in one-factor-at-a-time approaches

The systematic approach demonstrated in this polymer composite example can be adapted to countless engineering optimization problems, providing engineers with powerful tools to develop and improve products and processes efficiently.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from mpl_toolkits.mplot3d import Axes3D
from scipy import stats
import statsmodels.api as sm
from statsmodels.formula.api import ols
from itertools import combinations
import random

# Set random seed for reproducibility
np.random.seed(42)
random.seed(42)

# Define the factors and their levels for a 2^4 factorial design
factors = {
    'Temperature': [-1, 1],  # 140°C (-1) and 180°C (+1)
    'Time': [-1, 1],         # 2 hours (-1) and 4 hours (+1)
    'Filler': [-1, 1],       # 10% (-1) and 20% (+1)
    'MixSpeed': [-1, 1]      # 1000 RPM (-1) and 2000 RPM (+1)
}

actual_values = {
    'Temperature': [140, 180],  # °C
    'Time': [2, 4],             # hours
    'Filler': [10, 20],         # %
    'MixSpeed': [1000, 2000]    # RPM
}

# Function to create a full factorial design
def create_full_factorial(factors):
    n_factors = len(factors)
    factor_names = list(factors.keys())
    
    # Calculate number of runs
    n_runs = 2**n_factors
    
    # Create a dataframe with all combinations
    design = pd.DataFrame(index=range(n_runs), columns=factor_names)
    
    for i, factor in enumerate(factor_names):
        levels = factors[factor]
        repeats = 2**(n_factors - i - 1)
        design[factor] = np.tile(np.repeat(levels, repeats), 2**i)
    
    return design

# Function to create a fractional factorial design (1/2 fraction of 2^4)
def create_fractional_factorial(factors):
    n_factors = len(factors)
    factor_names = list(factors.keys())
    
    # Create a half-fraction by using D = ABC relationship
    # Start with full factorial for first three factors
    design = create_full_factorial({k: factors[k] for k in list(factors.keys())[:3]})
    
    # Add the fourth factor as D = ABC
    design[factor_names[3]] = design[factor_names[0]] * design[factor_names[1]] * design[factor_names[2]]
    
    return design

# Function to create a central composite design for response surface methodology
def create_central_composite(factors, alpha=1.414):
    n_factors = len(factors)
    factor_names = list(factors.keys())
    
    # Create factorial points
    factorial_design = create_full_factorial(factors)
    
    # Create center points (5 replicates)
    center_points = pd.DataFrame(np.zeros((5, n_factors)), columns=factor_names)
    
    # Create axial points
    axial_points = []
    for i, factor in enumerate(factor_names):
        for level in [-alpha, alpha]:
            point = np.zeros(n_factors)
            point[i] = level
            axial_points.append(point)
    
    axial_design = pd.DataFrame(axial_points, columns=factor_names)
    
    # Combine all designs
    ccd_design = pd.concat([factorial_design, center_points, axial_design], ignore_index=True)
    
    return ccd_design

# Model to generate synthetic tensile strength response
def tensile_strength_model(temp, time, filler, mix_speed):
    # Main effects
    main_effects = 50 + 5*temp + 3*time + 7*filler - 2*mix_speed
    
    # Two-factor interactions
    interactions = 2*temp*time + 4*temp*filler - temp*mix_speed
    
    # Quadratic effects for RSM
    quadratic = -3*temp**2 - 2*time**2 - 5*filler**2 - mix_speed**2
    
    # Add some random noise
    noise = np.random.normal(0, 2)
    
    return main_effects + interactions + quadratic + noise

# Model to generate synthetic impact resistance response
def impact_resistance_model(temp, time, filler, mix_speed):
    # Main effects
    main_effects = 30 - 3*temp + time - 4*filler + 2*mix_speed
    
    # Two-factor interactions
    interactions = -2*temp*filler + temp*mix_speed - time*filler
    
    # Quadratic effects for RSM
    quadratic = -temp**2 - time**2 - 2*filler**2 - mix_speed**2
    
    # Add some random noise
    noise = np.random.normal(0, 1.5)
    
    return main_effects + interactions + quadratic + noise

# Model to generate synthetic weight density response
def weight_density_model(temp, time, filler, mix_speed):
    # Mainly affected by filler content, slightly by processing conditions
    base = 1.2  # Base polymer density
    
    # Linear effect of filler (more filler = higher density)
    filler_effect = 0.015 * filler
    
    # Small effects from processing
    processing = -0.005 * temp - 0.002 * time + 0.001 * mix_speed
    
    # Add some random noise
    noise = np.random.normal(0, 0.01)
    
    return base + filler_effect + processing + noise

# Convert coded values to actual values for a given design
def add_actual_values(design):
    design_actual = design.copy()
    
    for factor in factors.keys():
        low, high = actual_values[factor]
        # Linear transformation from coded (-1, 1) to actual values
        # For CCD points outside [-1, 1], we extend the transformation
        design_actual[f"{factor}_actual"] = low + (design[factor] + 1) * (high - low) / 2
    
    return design_actual

# Function to add experimental units and randomization
def prepare_for_execution(design, num_blocks=2):
    design_exec = design.copy()
    
    # Add experimental unit IDs
    design_exec['Unit_ID'] = [f"Unit_{i+1}" for i in range(len(design_exec))]
    
    # Add randomized run order
    run_order = list(range(1, len(design_exec) + 1))
    random.shuffle(run_order)
    design_exec['Run_Order'] = run_order
    
    # Assign blocks for execution (simulating running the experiment on different days)
    block_size = len(design_exec) // num_blocks
    blocks = []
    for i in range(num_blocks):
        if i < num_blocks - 1:
            blocks.extend([i+1] * block_size)
        else:
            # Last block may have extra runs
            blocks.extend([num_blocks] * (len(design_exec) - len(blocks)))
    
    design_exec['Block'] = blocks
    
    return design_exec

# Function to generate responses for a given design
def generate_responses(design):
    design_resp = design.copy()
    
    # Get actual values for calculation
    temp = design_resp['Temperature_actual']
    time = design_resp['Time_actual']
    filler = design_resp['Filler_actual']
    mix_speed = design_resp['MixSpeed_actual']
    
    # Generate responses
    design_resp['Tensile_Strength'] = [tensile_strength_model(t, tim, f, m) 
                                      for t, tim, f, m in zip(temp, time, filler, mix_speed)]
    
    design_resp['Impact_Resistance'] = [impact_resistance_model(t, tim, f, m) 
                                       for t, tim, f, m in zip(temp, time, filler, mix_speed)]
    
    design_resp['Weight_Density'] = [weight_density_model(t, tim, f, m) 
                                    for t, tim, f, m in zip(temp, time, filler, mix_speed)]
    
    return design_resp

# Function to analyze factorial design effects
def analyze_factorial_effects(design, response_var):
    # Extract factors and response
    factor_cols = [col for col in design.columns if col in factors.keys()]
    X = design[factor_cols]
    y = design[response_var]
    
    # Add intercept
    X_with_const = sm.add_constant(X)
    
    # Fit the model
    model = sm.OLS(y, X_with_const).fit()
    
    # Create interaction terms
    for i, pair in enumerate(combinations(factor_cols, 2)):
        X[f"{pair[0]}:{pair[1]}"] = X[pair[0]] * X[pair[1]]
    
    # Add intercept to the new X with interactions
    X_with_interactions = sm.add_constant(X)
    
    # Fit the model with interactions
    model_with_interactions = sm.OLS(y, X_with_interactions).fit()
    
    return model, model_with_interactions

# Function to create Pareto chart of effects
def plot_pareto_effects(model, title):
    # Extract parameter estimates (excluding intercept)
    effects = model.params[1:].abs().sort_values(ascending=False)
    
    plt.figure(figsize=(10, 6))
    effects.plot(kind='bar', color='steelblue')
    plt.axhline(y=2*model.bse[1:].mean(), color='red', linestyle='--', 
                label='2 × Avg Std Error')
    plt.title(f'Pareto Chart of Effects - {title}')
    plt.ylabel('Absolute Effect Size')
    plt.xlabel('Factors and Interactions')
    plt.xticks(rotation=45, ha='right')
    plt.tight_layout()
    plt.legend()
    
    return plt

# Function to create contour plots for response surface
def plot_response_surface(design, response_var, factor1, factor2, fixed_factors=None):
    if fixed_factors is None:
        fixed_factors = {}
    
    # Create a grid of values for the two factors of interest
    x1 = np.linspace(design[factor1].min(), design[factor1].max(), 50)
    x2 = np.linspace(design[factor2].min(), design[factor2].max(), 50)
    X1, X2 = np.meshgrid(x1, x2)
    
    # Fit a quadratic model
    formula = f"{response_var} ~ {factor1} + {factor2} + I({factor1}**2) + I({factor2}**2) + {factor1}:{factor2}"
    model = ols(formula, data=design).fit()
    
    # Prepare the grid data for prediction
    grid_data = pd.DataFrame({factor1: X1.ravel(), factor2: X2.ravel()})
    
    # Add fixed factors to the grid
    for factor, value in fixed_factors.items():
        grid_data[factor] = value
    
    # Make predictions
    Z = model.predict(grid_data).values.reshape(X1.shape)
    
    # Create contour plot
    plt.figure(figsize=(10, 8))
    
    # Contour plot
    contour = plt.contourf(X1, X2, Z, cmap='viridis', alpha=0.7)
    plt.colorbar(contour, label=response_var)
    
    # Add data points
    plt.scatter(design[factor1], design[factor2], color='red', marker='o', label='Design points')
    
    # Formatting
    plt.xlabel(factor1)
    plt.ylabel(factor2)
    title = f'Response Surface for {response_var}'
    if fixed_factors:
        fixed_str = ', '.join([f"{k}={v}" for k, v in fixed_factors.items()])
        title += f' (Fixed: {fixed_str})'
    plt.title(title)
    plt.legend()
    plt.tight_layout()
    
    return plt

# Function to visualize replication and experimental variability
def plot_replication_analysis(design, response_var, factor):
    plt.figure(figsize=(10, 6))
    
    # Group data by the factor and calculate mean and std
    grouped = design.groupby(factor)[response_var]
    means = grouped.mean()
    stds = grouped.std()
    
    # Create bar plot with error bars
    x = np.arange(len(means))
    plt.bar(x, means, yerr=stds, capsize=10, color='skyblue', alpha=0.7)
    
    # Add individual data points
    for i, level in enumerate(means.index):
        points = design[design[factor] == level][response_var]
        plt.scatter(np.repeat(i, len(points)) + np.random.normal(0, 0.05, len(points)), 
                    points, color='navy', alpha=0.6)
    
    plt.xlabel(factor)
    plt.ylabel(response_var)
    plt.title(f'Effect of {factor} on {response_var} with Replication')
    plt.xticks(x, means.index)
    plt.grid(axis='y', linestyle='--', alpha=0.7)
    plt.tight_layout()
    
    return plt

# Function to find optimal settings
def find_optimal_settings(ccd_results):
    from scipy.optimize import minimize
    
    # Define objective function (we want to maximize tensile strength and impact resistance
    # while minimizing weight density)
    def objective(x):
        temp, time, filler, mix_speed = x
        
        # Calculate predicted responses
        tensile = tensile_strength_model(temp, time, filler, mix_speed)
        impact = impact_resistance_model(temp, time, filler, mix_speed)
        density = weight_density_model(temp, time, filler, mix_speed)
        
        # Create a combined objective (negative because we want to maximize)
        # We want to maximize tensile and impact, minimize density
        return -((tensile/60) + (impact/30) - (density/1.3))
    
    # Define bounds for each factor (in coded units)
    bounds = [(-1.414, 1.414), (-1.414, 1.414), (-1.414, 1.414), (-1.414, 1.414)]
    
    # Run optimization with multiple starting points
    best_result = None
    best_value = float('inf')
    
    for _ in range(10):
        start = np.random.uniform(-1, 1, 4)
        result = minimize(objective, start, bounds=bounds, method='L-BFGS-B')
        
        if result.fun < best_value:
            best_value = result.fun
            best_result = result
    
    # Convert optimal coded values to actual values
    optimal_coded = best_result.x
    optimal_actual = {}
    
    for i, factor in enumerate(factors.keys()):
        low, high = actual_values[factor]
        optimal_actual[factor] = low + (optimal_coded[i] + 1) * (high - low) / 2
    
    # Calculate predicted responses at optimal settings
    temp, time, filler, mix_speed = best_result.x
    optimal_tensile = tensile_strength_model(temp, time, filler, mix_speed)
    optimal_impact = impact_resistance_model(temp, time, filler, mix_speed)
    optimal_density = weight_density_model(temp, time, filler, mix_speed)
    
    return optimal_coded, optimal_actual, optimal_tensile, optimal_impact, optimal_density
