Module 8 Sample Problem 2

Problem Statement

An automotive engineering team is developing a new design for brake pads. The current brake pad design lasts on average 50,000 miles with a standard deviation of 5,000 miles. The team has developed a new material and wants to determine if it significantly changes the lifespan of the brake pads. They've tested 35 prototype brake pads and found a mean lifespan of 51,800 miles.

Hypothesis Setup

  • Null Hypothesis (H₀): The new brake pad material has the same mean lifespan as the current material (μ = 50,000 miles)
  • Alternative Hypothesis (H₁): The new brake pad material has a different mean lifespan than the current material (μ ≠ 50,000 miles)
  • Significance level (α): 0.05 (5%)

Statistical Analysis

Let's perform a two-tailed hypothesis test to determine if there's a statistically significant difference.

Step 1: Calculate the test statistic

We use a z-test since we know the population standard deviation:

z = (x̄ - μ₀)/(σ/√n)

Where:

  • x̄ = sample mean = 51,800 miles
  • μ₀ = hypothesized population mean = 50,000 miles
  • σ = population standard deviation = 5,000 miles
  • n = sample size = 35

z = (51,800 - 50,000)/(5,000/√35) = 1,800/(5,000/5.92) = 1,800/845.2 = 2.13

Step 2: Calculate the p-value

For a two-tailed test, p-value = 2 × P(Z > |z|) = 2 × P(Z > 2.13)

Python Code Solution (link)

import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# Given information
current_mean = 50000  # miles
std_dev = 5000  # miles
sample_size = 35
new_mean = 51800  # miles
alpha = 0.05

# Calculate z-statistic
z_stat = (new_mean - current_mean) / (std_dev / np.sqrt(sample_size))
print(f"Z-statistic: {z_stat:.4f}")

# Calculate p-value for two-tailed test
p_value = 2 * (1 - stats.norm.cdf(abs(z_stat)))
print(f"P-value: {p_value:.4f}")

# Decision
print(f"Significance level (alpha): {alpha}")
if p_value < alpha:
    print("Reject null hypothesis: There is a significant difference in brake pad lifespan")
else:
    print("Fail to reject null hypothesis: There is not enough evidence of a difference")

# Calculate confidence interval (95%)
margin_of_error = stats.norm.ppf(1 - alpha/2) * (std_dev / np.sqrt(sample_size))
ci_lower = new_mean - margin_of_error
ci_upper = new_mean + margin_of_error
print(f"95% Confidence Interval: ({ci_lower:.1f}, {ci_upper:.1f}) miles")

# Power analysis
effect_size = abs(new_mean - current_mean) / std_dev
power = stats.norm.cdf(effect_size * np.sqrt(sample_size) - stats.norm.ppf(1 - alpha/2)) + \
        stats.norm.cdf(-effect_size * np.sqrt(sample_size) - stats.norm.ppf(1 - alpha/2))
print(f"Effect size: {effect_size:.4f}")
print(f"Statistical power: {power:.4f}")

# Visualization
plt.figure(figsize=(10, 6))
x = np.linspace(current_mean - 4*std_dev/np.sqrt(sample_size), 
                current_mean + 4*std_dev/np.sqrt(sample_size), 1000)
y = stats.norm.pdf(x, current_mean, std_dev/np.sqrt(sample_size))

plt.plot(x, y, label="H₀ distribution", color="blue")
plt.axvline(x=current_mean, color='blue', linestyle='--', 
            label=f"H₀ mean = {current_mean}")

# Critical regions
critical_value = stats.norm.ppf(1 - alpha/2)
critical_x_neg = current_mean - critical_value * std_dev/np.sqrt(sample_size)
critical_x_pos = current_mean + critical_value * std_dev/np.sqrt(sample_size)

plt.axvline(x=critical_x_neg, color='red', linestyle='--', 
            label=f"Critical values at α = {alpha}")
plt.axvline(x=critical_x_pos, color='red', linestyle='--')

# Observed sample mean
plt.axvline(x=new_mean, color='green', linewidth=2, 
            label=f"Sample mean = {new_mean}")

# Shade rejection regions
x_fill_left = np.linspace(current_mean - 4*std_dev/np.sqrt(sample_size), critical_x_neg, 100)
y_fill_left = stats.norm.pdf(x_fill_left, current_mean, std_dev/np.sqrt(sample_size))
plt.fill_between(x_fill_left, y_fill_left, alpha=0.3, color='red')

x_fill_right = np.linspace(critical_x_pos, current_mean + 4*std_dev/np.sqrt(sample_size), 100)
y_fill_right = stats.norm.pdf(x_fill_right, current_mean, std_dev/np.sqrt(sample_size))
plt.fill_between(x_fill_right, y_fill_right, alpha=0.3, color='red', label="Rejection regions")

plt.title("Two-tailed Hypothesis Test for Brake Pad Lifespan")
plt.xlabel("Mean Lifespan (miles)")
plt.ylabel("Probability Density")
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Practical significance analysis
practical_threshold = 1000  # miles (assuming engineers consider 1000 miles practically significant)
if abs(new_mean - current_mean) > practical_threshold:
    print(f"The difference of {abs(new_mean - current_mean):.1f} miles is practically significant")
else:
    print(f"The difference of {abs(new_mean - current_mean):.1f} miles may not be practically significant")

Analysis of Solution

Results Analysis

From our calculations:

  • Z-statistic: 2.13
  • P-value: 0.0332
  • Significance level (α): 0.05
  • 95% Confidence Interval: (49,144.1, 54,455.9) miles

Since p-value (0.0332) < α (0.05), we reject the null hypothesis. There is statistically significant evidence that the new brake pad material changes the lifespan compared to the current material.

Type I and Type II Errors

Type I Error (False Positive):

  • Definition: Rejecting H₀ when it's actually true
  • In this context: Concluding the new brake pads are different when they actually perform the same as the current pads
  • Probability: Equal to our significance level α = 0.05 (5%)
  • Consequence: Potentially costly transition to a new material with no actual benefit

Type II Error (False Negative):

  • Definition: Failing to reject H₀ when it's actually false
  • In this context: Concluding the new brake pads perform the same when they actually perform differently
  • Probability: β = 1 - Power ≈ 0.36 (64% power)
  • Consequence: Missing an opportunity for improved product performance

Statistical vs. Practical Significance

While our test shows statistical significance (p < 0.05), we should also consider practical significance:

The new brake pads last 1,800 miles longer on average than the current design. Is this difference practically meaningful? This depends on several factors:

  • Cost implications: Is the increased lifespan worth any additional manufacturing costs?
  • Marketing value: Would a "3.6% longer-lasting brake pad" be a meaningful selling point?
  • Industry standards: Is a 1,800-mile improvement significant in the automotive industry?
  • Customer expectations: Would customers notice or value this difference?

For many automotive applications, a 1,800-mile improvement (approximately 3.6%) might have practical significance as it represents roughly 1-2 months of additional usage for average drivers (at 15,000 miles/year).

Conclusion

The data provides statistical evidence that the new brake pad material changes the lifespan of the brake pads (p = 0.0332). The engineering team should now evaluate whether this difference (1,800 miles increase) justifies the costs of implementing the new design, considering both manufacturing economics and market positioning.
