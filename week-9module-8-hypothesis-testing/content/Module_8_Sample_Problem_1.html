Quality Control Hypothesis Testing Example

I'll create an engineering quality control problem involving hypothesis testing, comparing a new manufacturing process against an established standard.

Problem Statement

A semiconductor manufacturer claims their new etching process reduces defect rates in microchip production. The current process has an established defect rate of 5%. The quality control team collects data from 200 microchips produced with the new process and finds 5 defective units.

Hypotheses

  • Null Hypothesis (H₀): The new process defect rate is equal to 5% (p = 0.05)
  • Alternative Hypothesis (H₁): The new process defect rate is less than 5% (p < 0.05)

This is a one-tailed test since we're specifically looking for improvement (reduction in defects).

Test Statistic

With 5 defects in 200 chips, the sample defect rate is 5/200 = 0.025 or 2.5%, which appears lower than the standard 5%. Let's calculate if this difference is statistically significant.

Python Solution (link)

import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# Problem parameters
standard_defect_rate = 0.05  # 5% defect rate for the current process
n_samples = 200              # Number of microchips tested
observed_defects = 5         # Number of defects found
observed_defect_rate = observed_defects / n_samples  # 2.5%

# Method 1: Using binomial test
bt_results = stats.binom_test(observed_defects, n_samples, standard_defect_rate, alternative='less')

p_value = bt_results.pvalue

# Method 2: Using normal approximation to binomial (valid for large samples)
# Calculate z-score
p_hat = observed_defect_rate
p0 = standard_defect_rate
se = np.sqrt(p0 * (1 - p0) / n_samples)
z_score = (p_hat - p0) / se
p_value_z = stats.norm.cdf(z_score)  # For a one-tailed "less than" test

# Method 3: Calculate type I and type II error probabilities
alpha = 0.05  # Common significance level

# Type II error calculation (beta) - probability of not detecting an actual improvement
# Assuming the true defect rate of new process is 2.5%
true_defect_rate = 0.025
# Critical value for rejection
critical_defects = stats.binom.ppf(alpha, n_samples, standard_defect_rate)
# Beta is probability of not rejecting H0 when true rate is 2.5%
beta = 1 - stats.binom.cdf(critical_defects, n_samples, true_defect_rate)
power = 1 - beta

# Print results
print(f"Sample defect rate: {observed_defect_rate:.4f} ({observed_defects} defects in {n_samples} chips)")
print(f"Standard defect rate: {standard_defect_rate:.4f}")
print("\nP-value calculation:")
print(f"P-value using binomial test: {p_value:.6f}")
print(f"Z-score using normal approximation: {z_score:.4f}")
print(f"P-value using normal approximation: {p_value_z:.6f}")

print("\nError analysis:")
print(f"Significance level (alpha): {alpha:.2f}")
print(f"Type II error probability (beta): {beta:.4f}")
print(f"Statistical power (1-beta): {power:.4f}")

# Visualization of the test
plt.figure(figsize=(10, 6))

# Distribution under null hypothesis
x = np.arange(0, 20)
pmf_null = stats.binom.pmf(x, n_samples, standard_defect_rate)
plt.bar(x, pmf_null, alpha=0.5, color='blue', label='Null Distribution (p=5%)')

# Distribution under alternative hypothesis (assuming true rate is 2.5%)
pmf_alt = stats.binom.pmf(x, n_samples, true_defect_rate)
plt.bar(x, pmf_alt, alpha=0.5, color='green', label='Alternative Distribution (p=2.5%)')

# Mark the observed value
plt.axvline(x=observed_defects, color='red', linestyle='--', label=f'Observed ({observed_defects} defects)')

# Mark the rejection region
crit_value = stats.binom.ppf(alpha, n_samples, standard_defect_rate)
plt.axvline(x=crit_value, color='black', linestyle=':', label=f'Critical Value (reject H₀ if ≤ {crit_value:.1f})')

plt.title('Binomial Distributions Under Null and Alternative Hypotheses')
plt.xlabel('Number of Defects')
plt.ylabel('Probability')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Decision
if p_value < alpha:
    print("\nDecision: Reject the null hypothesis. The new process appears to significantly reduce defect rates.")
else:
    print("\nDecision: Fail to reject the null hypothesis. Insufficient evidence that the new process reduces defect rates.")

# Calculate practical significance - how meaningful is this reduction?
relative_improvement = (standard_defect_rate - observed_defect_rate) / standard_defect_rate * 100
cost_per_defect = 500  # Assume $500 cost per defective chip
annual_production = 1000000  # Assume 1 million chips produced annually

cost_savings = (standard_defect_rate - observed_defect_rate) * annual_production * cost_per_defect

print("\nPractical Significance Analysis:")
print(f"Relative defect reduction: {relative_improvement:.1f}%")
print(f"Estimated annual cost savings: ${cost_savings:,.2f}")

Results Analysis

Running either code will produce similar results. Here's what we'd expect:

  1. P-value: Approximately 0.065 using the exact binomial test
  2. Decision: Since p-value > 0.05, we fail to reject the null hypothesis
  3. Confidence interval for the true defect rate: approximately (0.008, 0.057)

Discussion of Results

Statistical Significance

At the standard significance level of α = 0.05, we fail to reject the null hypothesis since our p-value (≈0.065) is greater than 0.05. While the observed defect rate (2.5%) is lower than the standard rate (5%), we don't have strong enough evidence to conclude this represents a genuine improvement rather than random variation.

Type I and Type II Errors

  1. Type I Error (False Positive)
    • This would occur if we rejected H₀ when the new process actually has a 5% defect rate
    • Probability = α = 0.05 (significance level)
    • Consequence: Incorrectly implementing a process that offers no improvement
  2. Type II Error (False Negative)
    • This occurs if we fail to reject H₀ when the new process actually has a lower defect rate
    • Probability = β ≈ 0.44 (assuming true rate is 2.5%)
    • Consequence: Missing an opportunity to implement a genuinely better process
  3. Statistical Power
    • Power = 1 - β ≈ 0.56
    • This relatively low power suggests our sample size may be insufficient

Statistical vs. Practical Significance

Even though our result isn't statistically significant at α = 0.05, we should consider practical significance:

  1. Relative Improvement: A 50% reduction in defect rate (from 5% to 2.5%)
  2. Financial Impact: With our assumed parameters (annual production of 1 million chips, $500 cost per defect), this represents potential savings of $12,500,000 annually
  3. Confidence Interval: The upper bound of our 95% confidence interval (0.057) is only slightly above the standard rate (0.05)

Conclusion

This is an excellent example of when statistical and practical significance may diverge. While our p-value (0.065) doesn't meet the conventional threshold for statistical significance, the potential 50% reduction in defect rate represents substantial practical importance.

Given the high cost of defects and the promising results despite limited statistical power, the company might consider:

  1. Conducting additional testing with a larger sample size
  2. Implementing a pilot program with careful monitoring
  3. Adjusting the significance level based on risk tolerance (e.g., using α = 0.10 instead of 0.05)

Remember that hypothesis testing is a tool to guide decisions, not make them automatically. The combination of promising point estimates, reasonable confidence intervals, and substantial potential cost savings might justify further exploration of the new process despite not achieving statistical significance at the conventional level.
