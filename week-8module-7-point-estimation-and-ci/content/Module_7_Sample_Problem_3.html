Module 7 Problem 3: Confidence Interval for Material Strength

Problem Statement

An aerospace engineer is testing the tensile strength of a new aluminum alloy for aircraft components. They test 25 specimens and find a mean tensile strength of 520 MPa with a sample standard deviation of 15 MPa. Determine the 95% confidence interval for the mean tensile strength of this alloy.

Step-by-Step Solution

  1. Identify the given values:
    • Sample size (n) = 25
    • Sample mean (x̄) = 520 MPa
    • Sample standard deviation (s) = 15 MPa
    • Confidence level = 95%
  2. Since the population standard deviation is unknown, we use the t-distribution:
    • Degrees of freedom = n - 1 = 24
    • t(0.025, 24) for a 95% confidence level = 2.064
  3. Calculate the margin of error:
    • Margin of error = t(0.025, 24) × (s/√n)
    • Margin of error = 2.064 × (15/√25)
    • Margin of error = 2.064 × (15/5)
    • Margin of error = 2.064 × 3
    • Margin of error = 6.192
  4. Calculate the confidence interval:
    • CI = x̄ ± margin of error
    • CI = 520 ± 6.192
    • CI = (513.808, 526.192)

Therefore, the 95% confidence interval for the mean tensile strength is (513.81 MPa, 526.19 MPa).

Solution in Python (link)

import numpy as np
import matplotlib.pyplot as plt
import scipy.stats as stats
import seaborn as sns

# Example 1: Aerospace aluminum alloy tensile strength
sample_mean = 520  # MPa
sample_std = 15    # MPa
sample_size = 25
confidence_level = 0.95

# Calculate degrees of freedom and t-critical value
df = sample_size - 1
alpha = 1 - confidence_level
t_critical = stats.t.ppf(1 - alpha/2, df)

# Calculate margin of error
margin_of_error = t_critical * (sample_std / np.sqrt(sample_size))

# Calculate confidence interval
ci_lower = sample_mean - margin_of_error
ci_upper = sample_mean + margin_of_error

print(f"Example 1: Tensile Strength of Aluminum Alloy")
print(f"Sample Mean: {sample_mean} MPa")
print(f"Sample Size: {sample_size}")
print(f"Sample Standard Deviation: {sample_std} MPa")
print(f"Degrees of Freedom: {df}")
print(f"t-critical value (95% confidence): {t_critical:.3f}")
print(f"Margin of Error: {margin_of_error:.3f} MPa")
print(f"95% Confidence Interval: ({ci_lower:.3f}, {ci_upper:.3f}) MPa")

# Generate a normal distribution for visualization
x = np.linspace(sample_mean - 4*sample_std, sample_mean + 4*sample_std, 1000)
y = stats.norm.pdf(x, sample_mean, sample_std)

# Create visualization
plt.figure(figsize=(10, 6))
plt.plot(x, y, 'b-', linewidth=2, label='Distribution')
plt.axvline(sample_mean, color='red', linestyle='-', linewidth=2, label='Sample Mean')
plt.axvline(ci_lower, color='green', linestyle='--', linewidth=2, label='95% CI Lower')
plt.axvline(ci_upper, color='green', linestyle='--', linewidth=2)

# Shade the confidence interval
ci_x = np.linspace(ci_lower, ci_upper, 100)
ci_y = stats.norm.pdf(ci_x, sample_mean, sample_std)
plt.fill_between(ci_x, ci_y, alpha=0.3, color='green')

plt.title('Tensile Strength of Aluminum Alloy with 95% Confidence Interval')
plt.xlabel('Tensile Strength (MPa)')
plt.ylabel('Probability Density')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Create a bootstrap simulation to validate our confidence interval
np.random.seed(42)
bootstrap_samples = 10000
bootstrap_means = np.zeros(bootstrap_samples)

# Generate sample data based on our sample statistics
original_sample = np.random.normal(sample_mean, sample_std, sample_size)

# Bootstrap procedure
for i in range(bootstrap_samples):
    # Resample with replacement
    resample = np.random.choice(original_sample, size=sample_size, replace=True)
    bootstrap_means[i] = np.mean(resample)

# Calculate bootstrap confidence interval
bootstrap_ci_lower = np.percentile(bootstrap_means, 2.5)
bootstrap_ci_upper = np.percentile(bootstrap_means, 97.5)

print("\nBootstrap Validation:")
print(f"Bootstrap 95% CI: ({bootstrap_ci_lower:.3f}, {bootstrap_ci_upper:.3f}) MPa")

# Plot bootstrap distribution
plt.figure(figsize=(10, 6))
sns.histplot(bootstrap_means, bins=50, kde=True)
plt.axvline(sample_mean, color='red', linestyle='-', linewidth=2, label='Sample Mean')
plt.axvline(bootstrap_ci_lower, color='purple', linestyle='--', linewidth=2, label='Bootstrap 95% CI')
plt.axvline(bootstrap_ci_upper, color='purple', linestyle='--', linewidth=2)
plt.title('Bootstrap Distribution of Sample Means')
plt.xlabel('Tensile Strength (MPa)')
plt.ylabel('Frequency')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

Solution in R

# Example 1: Aerospace aluminum alloy tensile strength
sample_mean <- 520  # MPa
sample_std <- 15    # MPa
sample_size <- 25
confidence_level <- 0.95

# Calculate degrees of freedom and t-critical value
df <- sample_size - 1
alpha <- 1 - confidence_level
t_critical <- qt(1 - alpha/2, df)

# Calculate margin of error
margin_of_error <- t_critical * (sample_std / sqrt(sample_size))

# Calculate confidence interval
ci_lower <- sample_mean - margin_of_error
ci_upper <- sample_mean + margin_of_error

# Print results
cat("Example 1: Tensile Strength of Aluminum Alloy\n")
cat(sprintf("Sample Mean: %g MPa\n", sample_mean))
cat(sprintf("Sample Size: %d\n", sample_size))
cat(sprintf("Sample Standard Deviation: %g MPa\n", sample_std))
cat(sprintf("Degrees of Freedom: %d\n", df))
cat(sprintf("t-critical value (95%% confidence): %.3f\n", t_critical))
cat(sprintf("Margin of Error: %.3f MPa\n", margin_of_error))
cat(sprintf("95%% Confidence Interval: (%.3f, %.3f) MPa\n", ci_lower, ci_upper))

# Generate a normal distribution for visualization
x <- seq(sample_mean - 4*sample_std, sample_mean + 4*sample_std, length.out = 1000)
y <- dnorm(x, mean = sample_mean, sd = sample_std)

# Create visualization
png("tensile_strength_ci.png", width = 800, height = 600)
plot(x, y, type = "l", col = "blue", lwd = 2,
     main = "Tensile Strength of Aluminum Alloy with 95% Confidence Interval",
     xlab = "Tensile Strength (MPa)", ylab = "Probability Density")

# Add lines for sample mean and CI
abline(v = sample_mean, col = "red", lwd = 2)
abline(v = ci_lower, col = "green", lwd = 2, lty = 2)
abline(v = ci_upper, col = "green", lwd = 2, lty = 2)

# Shade the confidence interval
ci_x <- seq(ci_lower, ci_upper, length.out = 100)
ci_y <- dnorm(ci_x, mean = sample_mean, sd = sample_std)
polygon(c(ci_x, rev(ci_x)), c(ci_y, rep(0, length(ci_y))), col = rgb(0, 1, 0, 0.3), border = NA)

# Add legend
legend("topright", legend = c("Distribution", "Sample Mean", "95% CI"),
       col = c("blue", "red", "green"), lty = c(1, 1, 2), lwd = c(2, 2, 2))
grid()
dev.off()

# Create a bootstrap simulation to validate our confidence interval
set.seed(42)
bootstrap_samples <- 10000
bootstrap_means <- numeric(bootstrap_samples)

# Generate sample data based on our sample statistics
original_sample <- rnorm(sample_size, mean = sample_mean, sd = sample_std)

# Bootstrap procedure
for (i in 1:bootstrap_samples) {
  # Resample with replacement
  resample <- sample(original_sample, size = sample_size, replace = TRUE)
  bootstrap_means[i] <- mean(resample)
}

# Calculate bootstrap confidence interval
bootstrap_ci <- quantile(bootstrap_means, c(0.025, 0.975))

cat("\nBootstrap Validation:\n")
cat(sprintf("Bootstrap 95%% CI: (%.3f, %.3f) MPa\n", bootstrap_ci[1], bootstrap_ci[2]))

# Plot bootstrap distribution
png("tensile_strength_bootstrap.png", width = 800, height = 600)
hist(bootstrap_means, breaks = 50, col = "lightblue", border = "white",
     main = "Bootstrap Distribution of Sample Means",
     xlab = "Tensile Strength (MPa)", freq = FALSE)
lines(density(bootstrap_means), col = "blue", lwd = 2)
abline(v = sample_mean, col = "red", lwd = 2)
abline(v = bootstrap_ci[1], col = "purple", lwd = 2, lty = 2)
abline(v = bootstrap_ci[2], col = "purple", lwd = 2, lty = 2)
legend("topright", legend = c("Density", "Sample Mean", "Bootstrap 95% CI"),
       col = c("blue", "red", "purple"), lty = c(1, 1, 2), lwd = c(2, 2, 2))
grid()
dev.off()

# Verify with built-in t.test function
t_test_result <- t.test(original_sample, conf.level = confidence_level)
cat("\nVerification with t.test function:\n")
print(t_test_result$conf.int)
