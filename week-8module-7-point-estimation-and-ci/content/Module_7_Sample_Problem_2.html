Module 7 Example 2: Clinical Trial Response

Consider a clinical trial where we want to estimate the response rate to a new treatment. We have data from 50 patients, where 1 represents a positive response and 0 represents no response. The true response rate is 60%.

Mathematical Solution

The mathematical derivation follows the same steps as in Example 1, since we're still working with a Bernoulli distribution.

Step 1: Construct the likelihood function

L(p)=∏i=1npxi(1−p)1−xiL(p) = \prod_{i=1}^{n} p^{x_i}(1-p)^{1-x_i} L(p)=∏i=1n​pxi​(1−p)1−xi​

Step 2: Take the natural log (log-likelihood)


ln⁡L(p)=ln⁡(p)∑i=1nxi+ln⁡(1−p)(n−∑i=1nxi)\ln L(p) = \ln(p)\sum_{i=1}^{n} x_i + \ln(1-p)(n-\sum_{i=1}^{n} x_i) lnL(p)=ln(p)∑i=1n​xi​+ln(1−p)(n−∑i=1n​xi​)

Step 3: Differentiate with respect to the parameter pp p

ddpln⁡L(p)=1p∑i=1nxi−11−p(n−∑i=1nxi)\frac{d}{dp}\ln L(p) = \frac{1}{p}\sum_{i=1}^{n} x_i - \frac{1}{1-p}(n-\sum_{i=1}^{n} x_i) dpd​lnL(p)=p1​∑i=1n​xi​−1−p1​(n−∑i=1n​xi​)

Step 4: Set the derivative to zero

1p∑i=1nxi−11−p(n−∑i=1nxi)=0\frac{1}{p}\sum_{i=1}^{n} x_i - \frac{1}{1-p}(n-\sum_{i=1}^{n} x_i) = 0 p1​∑i=1n​xi​−1−p1​(n−∑i=1n​xi​)=0

Step 5: Solve for the parameter estimate 

p^=∑i=1nxin\hat{p} = \frac{\sum_{i=1}^{n} x_i}{n} p^​=n∑i=1n​xi​​

Again, the MLE is the sample mean, but now in the context of treatment response rate.

Solution in Python (link)

import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy.stats import bernoulli, binom
from scipy import optimize

# Example 2: Clinical Trial Response
# Generate some sample data: 50 patients with 60% response rate
np.random.seed(123)
true_p = 0.60
n_samples = 50
data = bernoulli.rvs(true_p, size=n_samples)

def bernoulli_mle(data):
    """Calculate MLE for Bernoulli parameter p"""
    return np.mean(data)

# Calculate MLE
p_hat = bernoulli_mle(data)
print(f"True response rate: {true_p}")
print(f"MLE estimate response rate: {p_hat}")

# Negative log-likelihood function (for optimization)
def neg_log_likelihood(p, data):
    """Negative log-likelihood for Bernoulli distribution"""
    return -np.sum(data * np.log(p) + (1 - data) * np.log(1 - p))

# Find MLE using optimization (alternative approach)
result = optimize.minimize_scalar(neg_log_likelihood, bounds=(0, 1), args=(data,), method='bounded')
p_hat_optim = result.x
print(f"MLE via optimization: {p_hat_optim}")

# Calculate log-likelihood for a range of p values
p_values = np.linspace(0.3, 0.9, 100)
log_likelihoods = []

for p in p_values:
    log_likelihood = np.sum(data * np.log(p) + (1 - data) * np.log(1 - p))
    log_likelihoods.append(log_likelihood)

# Plot log-likelihood function
plt.figure(figsize=(10, 6))
plt.plot(p_values, log_likelihoods)
plt.axvline(p_hat, color='red', linestyle='--', label=f'MLE = {p_hat:.3f}')
plt.axvline(true_p, color='green', linestyle=':', label=f'True p = {true_p}')
plt.xlabel('p (response rate)')
plt.ylabel('Log-likelihood')
plt.title('Log-likelihood Function for Clinical Trial Response')
plt.legend()
plt.grid(True)

# Create confidence interval via profile likelihood
max_ll = max(log_likelihoods)
threshold = max_ll - 1.92  # Based on chi-square with 1 df (95% CI)

# Find confidence interval bounds
above_threshold = np.array(log_likelihoods) >= threshold
ci_indices = np.where(above_threshold)[0]
ci_lower = p_values[ci_indices[0]]
ci_upper = p_values[ci_indices[-1]]

plt.axhline(threshold, color='blue', linestyle='-.', alpha=0.5, label='95% CI threshold')
plt.fill_between(p_values, min(log_likelihoods), log_likelihoods, 
                 where=(p_values >= ci_lower) & (p_values <= ci_upper),
                 color='gray', alpha=0.3)
plt.legend()

print(f"95% CI: ({ci_lower:.3f}, {ci_upper:.3f})")

# Calculate standard error using Fisher Information
se = np.sqrt(p_hat * (1 - p_hat) / n_samples)
print(f"Standard error: {se:.3f}")

# Calculate Wald confidence interval
wald_ci_lower = p_hat - 1.96 * se
wald_ci_upper = p_hat + 1.96 * se
print(f"95% Wald CI: ({wald_ci_lower:.3f}, {wald_ci_upper:.3f})")

# Plot the distribution of the MLE
plt.figure(figsize=(10, 6))

# Create simulation of sampling distribution
n_simulations = 10000
sample_means = []
for _ in range(n_simulations):
    sample = bernoulli.rvs(true_p, size=n_samples)
    sample_means.append(np.mean(sample))

# Plot histogram of sampling distribution
sns.histplot(sample_means, bins=30, kde=True, color='skyblue')
plt.axvline(true_p, color='green', linestyle=':', label=f'True p = {true_p}')
plt.axvline(p_hat, color='red', linestyle='--', label=f'Sample MLE = {p_hat:.3f}')
plt.xlabel('Estimated response rate (p)')
plt.ylabel('Frequency')
plt.title('Sampling Distribution of MLE for Clinical Trial Response Rate')
plt.legend()

# Plot for original data
plt.figure(figsize=(10, 6))
values, counts = np.unique(data, return_counts=True)
plt.bar(['No Response (0)', 'Positive Response (1)'], counts, color=['orange', 'blue'])
plt.axhline(n_samples * (1 - p_hat), color='darkorange', linestyle='--', 
           label=f'Expected no response: {n_samples * (1 - p_hat):.1f}')
plt.axhline(n_samples * p_hat, color='darkblue', linestyle='--', 
           label=f'Expected positive response: {n_samples * p_hat:.1f}')
plt.ylabel('Count')
plt.title('Clinical Trial Responses')
plt.legend()
plt.show()

# Example 2: Clinical Trial Response
set.seed(123)
true_p <- 0.60
n_samples <- 50
data <- rbinom(n_samples, 1, true_p)

# MLE function for Bernoulli
bernoulli_mle <- function(data) {
  return(mean(data))
}

# Calculate MLE
p_hat <- bernoulli_mle(data)
cat("True response rate:", true_p, "\n")
cat("MLE estimate response rate:", p_hat, "\n")

# Negative log-likelihood function (for optimization)
neg_log_likelihood <- function(p, data) {
  -sum(data * log(p) + (1 - data) * log(1 - p))
}

# Find MLE using optimization (alternative approach)
result <- optimize(neg_log_likelihood, interval = c(0, 1), data = data)
p_hat_optim <- result$minimum
cat("MLE via optimization:", p_hat_optim, "\n")

# Log-likelihood function for Bernoulli
bernoulli_log_likelihood <- function(p, data) {
  sum(data * log(p) + (1 - data) * log(1 - p))
}

# Calculate log-likelihood for a range of p values
p_values <- seq(0.3, 0.9, length.out = 100)
log_likelihoods <- sapply(p_values, bernoulli_log_likelihood, data = data)

# Set up a 2x2 plot layout
par(mfrow = c(2, 2))

# Plot log-likelihood function
plot(p_values, log_likelihoods, type = "l", 
     xlab = "p (response rate)", 
     ylab = "Log-likelihood", 
     main = "Log-likelihood Function for Clinical Trial")
abline(v = p_hat, col = "red", lty = 2)
abline(v = true_p, col = "green", lty = 3)
legend("bottomright", 
       legend = c(paste("MLE =", round(p_hat, 3)), paste("True p =", true_p)),
       col = c("red", "green"), 
       lty = c(2, 3))

# Create confidence interval via profile likelihood
max_ll <- max(log_likelihoods)
threshold <- max_ll - 1.92  # Based on chi-square with 1 df (95% CI)

# Find confidence interval bounds
above_threshold <- log_likelihoods >= threshold
ci_indices <- which(above_threshold)
ci_lower <- p_values[min(ci_indices)]
ci_upper <- p_values[max(ci_indices)]

abline(h = threshold, col = "blue", lty = 4)
polygon(c(p_values[ci_indices], rev(p_values[ci_indices])),
        c(rep(min(log_likelihoods), length(ci_indices)), 
          rev(log_likelihoods[ci_indices])),
        col = rgb(0.5, 0.5, 0.5, 0.3), border = NA)

cat("95% CI: (", round(ci_lower, 3), ", ", round(ci_upper, 3), ")\n", sep = "")

# Calculate standard error using Fisher Information
se <- sqrt(p_hat * (1 - p_hat) / n_samples)
cat("Standard error:", round(se, 3), "\n")

# Calculate Wald confidence interval
wald_ci_lower <- p_hat - 1.96 * se
wald_ci_upper <- p_hat + 1.96 * se
cat("95% Wald CI: (", round(wald_ci_lower, 3), ", ", round(wald_ci_upper, 3), ")\n", sep = "")

# Simulate and plot distribution of MLE
n_simulations <- 10000
sample_means <- numeric(n_simulations)
for (i in 1:n_simulations) {
  sample <- rbinom(n_samples, 1, true_p)
  sample_means[i] <- mean(sample)
}

# Plot histogram of sampling distribution
hist(sample_means, breaks = 30, main = "Sampling Distribution of MLE", 
     xlab = "Estimated response rate (p)", col = "skyblue", probability = TRUE)
lines(density(sample_means), col = "blue", lwd = 2)
abline(v = true_p, col = "green", lty = 3)
abline(v = p_hat, col = "red", lty = 2)
legend("topright", 
       legend = c(paste("MLE =", round(p_hat, 3)), paste("True p =", true_p)),
       col = c("red", "green"), 
       lty = c(2, 3))

# Bar plot of observed data
counts <- table(factor(data, levels = c(0, 1)))
barplot(counts, names = c("No Response (0)", "Positive Response (1)"), 
        col = c("orange", "blue"),
        main = "Clinical Trial Responses",
        ylab = "Count")
abline(h = n_samples * (1 - p_hat), col = "darkorange", lty = 2)
abline(h = n_samples * p_hat, col = "darkblue", lty = 2)
legend("topright", 
       legend = c(paste("Expected no response:", round(n_samples * (1 - p_hat), 1)),
                  paste("Expected positive response:", round(n_samples * p_hat, 1))),
       col = c("darkorange", "darkblue"), 
       lty = 2)

# Plot theoretical vs. empirical CDF
ecdf_data <- ecdf(data)
p_seq <- seq(0, 1, 0.01)
plot(p_seq, pbinom(0, 1, p_hat) * (p_seq <= 0) + 1 * (p_seq > 0), 
     type = "s", xlab = "x", ylab = "CDF", 
     main = "Theoretical vs. Empirical CDF",
     col = "red", lwd = 2)
lines(ecdf_data, col = "blue", lwd = 2)

       legend = c("Theoretical CDF", "Empirical CDF"),
       col = c("red", "blue"),
