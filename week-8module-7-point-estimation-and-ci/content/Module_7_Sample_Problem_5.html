Module 7 Problem 5: Quality Control for Electronic Components

An electronics manufacturer produces microcontrollers for industrial equipment. Quality engineers need to estimate the proportion of microcontrollers that meet all performance specifications after manufacturing. They randomly sample 150 microcontrollers from a recent production run and find that 132 meet all the required specifications.

Task: Calculate a 95% confidence interval for the true proportion of microcontrollers in the production run that meet all specifications. Then interpret this confidence interval.

Solution in Python (link)

import numpy as np
import matplotlib.pyplot as plt
import scipy.stats as stats
import seaborn as sns

# Given information
n = 150  # sample size
x = 132  # number of successes
sample_proportion = x / n

# Calculate 95% confidence interval
z_critical = stats.norm.ppf(0.975)  # 95% confidence level (two-tailed)
standard_error = np.sqrt(sample_proportion * (1 - sample_proportion) / n)
margin_of_error = z_critical * standard_error

lower_bound = sample_proportion - margin_of_error
upper_bound = sample_proportion + margin_of_error

# Print results
print(f"Sample proportion: {sample_proportion:.4f}")
print(f"Standard error: {standard_error:.4f}")
print(f"Margin of error: {margin_of_error:.4f}")
print(f"95% Confidence interval: ({lower_bound:.4f}, {upper_bound:.4f})")

# Create visualization
plt.figure(figsize=(12, 6))

# Plot 1: Sample proportion with confidence interval
plt.subplot(1, 2, 1)
plt.bar(['Sample Proportion'], [sample_proportion], color='skyblue', width=0.5)
plt.errorbar(['Sample Proportion'], [sample_proportion], yerr=margin_of_error, 
             fmt='o', color='black', capsize=10)
plt.ylim(0.75, 1.0)
plt.title('Sample Proportion with 95% Confidence Interval')
plt.ylabel('Proportion of Functioning Microcontrollers')

# Plot 2: Visualization of what confidence interval means
plt.subplot(1, 2, 2)

# Simulate taking 100 different samples and calculating CIs
np.random.seed(42)
sample_proportions = []
lower_bounds = []
upper_bounds = []
contains_true = []

# Assume a true proportion of 0.88 (unknown in real scenario)
true_proportion = 0.88
for _ in range(100):
    # Simulate taking a sample
    sample = np.random.binomial(1, true_proportion, size=n)
    p_hat = np.mean(sample)
    se = np.sqrt(p_hat * (1 - p_hat) / n)
    me = z_critical * se
    lb = p_hat - me
    ub = p_hat + me
    
    sample_proportions.append(p_hat)
    lower_bounds.append(lb)
    upper_bounds.append(ub)
    contains_true.append(lb <= true_proportion <= ub)

# Create a subset of the simulations for visualization clarity
indices = np.arange(25)  # Show just 25 confidence intervals
y_positions = np.arange(len(indices))

plt.hlines(y=y_positions, xmin=[lower_bounds[i] for i in indices], 
          xmax=[upper_bounds[i] for i in indices], color=['green' if contains else 'red' for contains in [contains_true[i] for i in indices]], 
          alpha=0.8, linewidth=2)
plt.scatter([sample_proportions[i] for i in indices], y_positions, color='blue', s=30, zorder=3)
plt.axvline(x=true_proportion, color='black', linestyle='--', label='True Proportion')
plt.yticks([])
plt.title('Demonstration of 95% Confidence Interval')
plt.xlabel('Proportion')
plt.legend(loc='upper right')

plt.tight_layout()
plt.show()

# Calculate percentage of intervals containing true value
percent_containing = sum(contains_true) / len(contains_true) * 100
print(f"\nIn our simulation, {percent_containing:.1f}% of the confidence intervals contain the true proportion.")
print("This demonstrates what a 95% confidence level means: if we were to repeat")
print("the sampling process many times, about 95% of the resulting confidence intervals")
print("would contain the true population proportion.")

Solution and Interpretation

From our analysis:

  • Sample proportion = 132/150 = 0.88 or 88%
  • 95% confidence interval: (0.8272, 0.9328) or approximately (82.7%, 93.3%)

Interpretation of the Confidence Interval

We can say with 95% confidence that the true proportion of microcontrollers in the entire production run that meet all specifications is between 82.7% and 93.3%.

To understand what "95% confidence" means: If we were to take many different random samples of 150 microcontrollers from this production run and calculate a confidence interval for each sample, about 95% of those intervals would contain the true population proportion.

Engineering Context

This confidence interval provides critical information for the electronics manufacturer:

  1. Quality Assessment: Even at the lower bound (82.7%), there's a significant proportion of units not meeting specifications (17.3%), which might warrant process improvement.
  2. Business Decisions: The width of the interval (about 10.6 percentage points) indicates the precision of our estimate. Management might decide whether this precision is sufficient or if additional sampling is needed.
  3. Risk Management: The lower bound helps engineers assess worst-case scenarios for shipment quality, which impacts warranty costs and customer satisfaction.

The visualization in the code shows both the calculated confidence interval from our sample and a simulation demonstrating what confidence intervals actually mean - illustrating how approximately 95% of properly calculated intervals contain the true proportion value when sampling is repeated.
