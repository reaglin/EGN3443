Engineering Example: Linear Regression with Transformations

This engineering example demonstrates how data transformations can improve linear regression models when dealing with non-linear relationships. Let's explore log, square root, and inverse transformations with both Python and R implementations.

Problem Statement

Engineers at a chemical processing plant need to model the relationship between the concentration of a catalyst (input variable) and the reaction yield (output variable). Initial data shows a non-linear relationship that might benefit from transformations before applying linear regression. (Data is included in the code sections)

Analysis of Data Transformations in Linear Regression

Methodology

  1. Data Generation: I created a synthetic dataset that follows a logarithmic relationship (y = 20*log(x) + noise) to simulate catalyst concentration vs. reaction yield with 50 data points.
  2. Model Building: I developed four regression models:
    • Standard linear regression without transformation
    • Linear regression with logarithmic transformation of x
    • Linear regression with square root transformation of x
    • Linear regression with inverse transformation of x (1/x)
  3. Evaluation Metrics: For each model, I calculated:
    • R² (coefficient of determination) - higher is better
    • RMSE (root mean squared error) - lower is better
  4. Visualization: I created scatter plots with fitted lines and residual plots to visually assess model fit.

Transformation Analysis

1. Log Transformation

Mathematical form: y = β₀ + β₁ * log(x)

Strengths:

  • Excellent for data with diminishing returns/exponential decay relationships
  • Handles right-skewed data effectively
  • Particularly useful when percentage changes in X relate to absolute changes in Y
  • In our case, it perfectly matches the underlying data generation process

When to use:

  • When the rate of change decreases as the predictor increases
  • With positive data that spans multiple orders of magnitude
  • When dealing with growth processes that slow down over time

2. Square Root Transformation

Mathematical form: y = β₀ + β₁ * √x

Strengths:

  • Less aggressive than logarithmic transformation
  • Good for moderately right-skewed data
  • Preserves zero values (unlike log transformation)
  • Works well for count data following Poisson distribution

When to use:

  • When data shows moderate curvature
  • For data with a square root relationship
  • With count data or non-negative measurements

3. Inverse Transformation

Mathematical form: y = β₀ + β₁ * (1/x)

Strengths:

  • Useful for severely right-skewed distributions
  • Models relationships where Y approaches an asymptote as X increases
  • Effective for hyperbolic relationships

When to use:

  • When the relationship follows a hyperbolic pattern
  • In chemical kinetics (e.g., reaction rate vs. concentration)
  • When the effect of x diminishes dramatically as x increases

Results and Discussion

From our analysis across both Python and R implementations:

  1. Log Transformation performed the best (highest R², lowest RMSE), which is expected since our data was generated with a logarithmic relationship. This demonstrates how crucial it is to match the transformation to the underlying data structure.
  2. Square Root Transformation performed second best. While not capturing the relationship as well as the log transformation, it still significantly improved the model compared to no transformation.
  3. The Inverse Transformation showed improvement over the base model but wasn't as effective as the other transformations for this particular dataset.
  4. No Transformation performed worst, with the lowest R² and highest RMSE, confirming that non-linear relationships cannot be adequately modeled with simple linear regression without transformation.

Residual Analysis

The residual plots reveal important insights:

  • The untransformed model shows a clear pattern in residuals, indicating a poor model fit.
  • The log transformation yields the most randomly distributed residuals, suggesting it best captured the underlying relationship.
  • Square root transformation residuals show improvement but still have some pattern.
  • Inverse transformation residuals show less pattern than no transformation but more than log transformation.

Engineering Application

In real chemical engineering applications, these transformations have specific uses:

  • Log transformation: Commonly used in reaction kinetics, especially for first-order reactions
  • Square root transformation: Useful in analyzing diffusion-controlled processes
  • Inverse transformation: Applied in second-order reaction rate analysis

Conclusion

Selecting the appropriate transformation is crucial for accurate modeling of non-linear relationships. For our catalyst concentration example:

  1. The logarithmic transformation provided the best fit because it matched the true underlying relationship in the data.
  2. In real-world engineering scenarios, the choice of transformation should be guided by:
    • Understanding of the physical/chemical processes involved
    • Visual examination of the raw data
    • Domain knowledge about expected relationships
    • Comparison of model performance metrics
    • Analysis of residual plots for patterns
  3. These transformations can significantly improve linear regression's applicability to non-linear problems, saving engineers from implementing more complex models when a simple transformation will suffice.

Solution in Python (link)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_squared_error
import seaborn as sns

# Set seed for reproducibility
np.random.seed(42)

# Generate synthetic data that follows a non-linear pattern
# Catalyst concentration (X) between 0.5 and 10
n_samples = 50
X = np.linspace(0.5, 10, n_samples).reshape(-1, 1)

# True relationship is non-linear: yield = 20*log(x) + noise
true_yield = 20 * np.log(X) + np.random.normal(0, 2, size=(n_samples, 1))

# Create a DataFrame for easier manipulation
df = pd.DataFrame({
    'catalyst_concentration': X.flatten(),
    'reaction_yield': true_yield.flatten()
})

# Function to fit a model and evaluate
def fit_and_evaluate(X_transform, y, title, transformation_name):
    model = LinearRegression()
    model.fit(X_transform, y)
    
    y_pred = model.predict(X_transform)
    r2 = r2_score(y, y_pred)
    rmse = np.sqrt(mean_squared_error(y, y_pred))
    
    # Original X for plotting the curve
    X_plot = np.linspace(np.min(X), np.max(X), 100).reshape(-1, 1)
    
    # Transform X_plot based on the transformation type
    if transformation_name == 'Original':
        X_plot_transform = X_plot
    elif transformation_name == 'Log':
        X_plot_transform = np.log(X_plot)
    elif transformation_name == 'Square Root':
        X_plot_transform = np.sqrt(X_plot)
    elif transformation_name == 'Inverse':
        X_plot_transform = 1/X_plot
    
    y_plot_pred = model.predict(X_plot_transform)
    
    # Plotting
    plt.figure(figsize=(10, 6))
    plt.scatter(X, y, label='Data Points', alpha=0.6)
    plt.plot(X_plot, y_plot_pred, 'r-', linewidth=2, label='Fitted Line')
    plt.title(f'{title}: $R^2$ = {r2:.4f}, RMSE = {rmse:.4f}')
    plt.xlabel('Catalyst Concentration')
    plt.ylabel('Reaction Yield')
    plt.legend()
    plt.grid(True, alpha=0.3)
    
    # Print model information
    print(f"\n{title}:")
    print(f"Coefficient: {model.coef_[0]:.4f}")
    print(f"Intercept: {model.intercept_:.4f}")
    print(f"R² Score: {r2:.4f}")
    print(f"RMSE: {rmse:.4f}")
    
    return model, r2, rmse

# Original (no transformation)
X_original = X
model_original, r2_original, rmse_original = fit_and_evaluate(
    X_original, true_yield, 'Linear Regression (No Transformation)', 'Original'
)

# Log transformation
X_log = np.log(X)
model_log, r2_log, rmse_log = fit_and_evaluate(
    X_log, true_yield, 'Linear Regression with Log Transformation', 'Log'
)

# Square root transformation
X_sqrt = np.sqrt(X)
model_sqrt, r2_sqrt, rmse_sqrt = fit_and_evaluate(
    X_sqrt, true_yield, 'Linear Regression with Square Root Transformation', 'Square Root'
)

# Inverse transformation
X_inv = 1/X
model_inv, r2_inv, rmse_inv = fit_and_evaluate(
    X_inv, true_yield, 'Linear Regression with Inverse Transformation', 'Inverse'
)

# Residual analysis
plt.figure(figsize=(12, 8))

# Original model residuals
plt.subplot(2, 2, 1)
y_pred_original = model_original.predict(X_original)
residuals_original = true_yield.flatten() - y_pred_original
plt.scatter(y_pred_original, residuals_original)
plt.axhline(y=0, color='r', linestyle='-')
plt.title('Residuals - No Transformation')
plt.xlabel('Predicted Values')
plt.ylabel('Residuals')

# Log transformation residuals
plt.subplot(2, 2, 2)
y_pred_log = model_log.predict(X_log)
residuals_log = true_yield.flatten() - y_pred_log
plt.scatter(y_pred_log, residuals_log)
plt.axhline(y=0, color='r', linestyle='-')
plt.title('Residuals - Log Transformation')
plt.xlabel('Predicted Values')
plt.ylabel('Residuals')

# Square root transformation residuals
plt.subplot(2, 2, 3)
y_pred_sqrt = model_sqrt.predict(X_sqrt)
residuals_sqrt = true_yield.flatten() - y_pred_sqrt
plt.scatter(y_pred_sqrt, residuals_sqrt)
plt.axhline(y=0, color='r', linestyle='-')
plt.title('Residuals - Square Root Transformation')
plt.xlabel('Predicted Values')
plt.ylabel('Residuals')

# Inverse transformation residuals
plt.subplot(2, 2, 4)
y_pred_inv = model_inv.predict(X_inv)
residuals_inv = true_yield.flatten() - y_pred_inv
plt.scatter(y_pred_inv, residuals_inv)
plt.axhline(y=0, color='r', linestyle='-')
plt.title('Residuals - Inverse Transformation')
plt.xlabel('Predicted Values')
plt.ylabel('Residuals')

plt.tight_layout()
plt.show()

# Compare models
models = ['No Transformation', 'Log', 'Square Root', 'Inverse']
r2_scores = [r2_original, r2_log, r2_sqrt, r2_inv]
rmse_scores = [rmse_original, rmse_log, rmse_sqrt, rmse_inv]

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.bar(models, r2_scores, color=['blue', 'green', 'orange', 'red'])
plt.title('R² Score Comparison')
plt.ylabel('R² Score')
plt.ylim(0, 1)
plt.grid(axis='y', alpha=0.3)

plt.subplot(1, 2, 2)
plt.bar(models, rmse_scores, color=['blue', 'green', 'orange', 'red'])
plt.title('RMSE Comparison')
plt.ylabel('RMSE')
plt.grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.show()

# Summary table
results = pd.DataFrame({
    'Transformation': models,
    'R² Score': r2_scores,
    'RMSE': rmse_scores
})
print("\nTransformation Comparison:")
print(results)

Solution in R

# Load necessary libraries
library(ggplot2)
library(dplyr)
library(gridExtra)

# Set seed for reproducibility
set.seed(42)

# Generate synthetic data that follows a non-linear pattern
# Catalyst concentration (X) between 0.5 and 10
n_samples <- 50
X <- seq(0.5, 10, length.out = n_samples)

# True relationship is non-linear: yield = 20*log(x) + noise
true_yield <- 20 * log(X) + rnorm(n_samples, mean = 0, sd = 2)

# Create a data frame
df <- data.frame(
  catalyst_concentration = X,
  reaction_yield = true_yield
)

# Function to fit a model and evaluate
fit_and_evaluate <- function(df, transformation, title) {
  if (transformation == "original") {
    formula <- reaction_yield ~ catalyst_concentration
    x_var <- df$catalyst_concentration
  } else if (transformation == "log") {
    formula <- reaction_yield ~ log(catalyst_concentration)
    x_var <- log(df$catalyst_concentration)
  } else if (transformation == "sqrt") {
    formula <- reaction_yield ~ sqrt(catalyst_concentration)
    x_var <- sqrt(df$catalyst_concentration)
  } else if (transformation == "inverse") {
    formula <- reaction_yield ~ I(1/catalyst_concentration)
    x_var <- 1/df$catalyst_concentration
  }
  
  # Fit the model
  model <- lm(formula, data = df)
  
  # Make predictions
  df$predicted <- predict(model, df)
  
  # Calculate metrics
  residuals <- df$reaction_yield - df$predicted
  r_squared <- summary(model)$r.squared
  rmse <- sqrt(mean(residuals^2))
  
  # Create a smooth curve for plotting
  x_smooth <- seq(min(df$catalyst_concentration), max(df$catalyst_concentration), length.out = 100)
  
  if (transformation == "original") {
    df_smooth <- data.frame(catalyst_concentration = x_smooth)
  } else if (transformation == "log") {
    df_smooth <- data.frame(catalyst_concentration = x_smooth)
  } else if (transformation == "sqrt") {
    df_smooth <- data.frame(catalyst_concentration = x_smooth)
  } else if (transformation == "inverse") {
    df_smooth <- data.frame(catalyst_concentration = x_smooth)
  }
  
  df_smooth$predicted <- predict(model, newdata = df_smooth)
  
  # Create plot
  p <- ggplot(df, aes(x = catalyst_concentration, y = reaction_yield)) +
    geom_point(alpha = 0.6) +
    geom_line(data = df_smooth, aes(x = catalyst_concentration, y = predicted), 
              color = "red", size = 1) +
    labs(title = paste0(title, ": R² = ", round(r_squared, 4), ", RMSE = ", round(rmse, 4)),
         x = "Catalyst Concentration", y = "Reaction Yield") +
    theme_minimal() +
    theme(plot.title = element_text(size = 10))
  
  # Create residual plot
  p_resid <- ggplot(df, aes(x = predicted, y = residuals)) +
    geom_point() +
    geom_hline(yintercept = 0, color = "red", linetype = "dashed") +
    labs(title = paste("Residuals -", title),
         x = "Predicted Values", y = "Residuals") +
    theme_minimal() +
    theme(plot.title = element_text(size = 10))

  # Print model summary
  cat("\n", title, ":\n")
  print(summary(model))
  cat("RMSE:", rmse, "\n\n")
  
  return(list(model = model, r_squared = r_squared, rmse = rmse, 
              plot = p, residual_plot = p_resid))
}

# Fit models with different transformations
model_original <- fit_and_evaluate(df, "original", "Linear Regression (No Transformation)")
model_log <- fit_and_evaluate(df, "log", "Linear Regression with Log Transformation")
model_sqrt <- fit_and_evaluate(df, "sqrt", "Linear Regression with Square Root Transformation")
model_inverse <- fit_and_evaluate(df, "inverse", "Linear Regression with Inverse Transformation")

# Arrange model plots in a grid
grid.arrange(
  model_original$plot, model_log$plot,
  model_sqrt$plot, model_inverse$plot,
  ncol = 2
)

# Arrange residual plots in a grid
grid.arrange(
  model_original$residual_plot, model_log$residual_plot,
  model_sqrt$residual_plot, model_inverse$residual_plot,
  ncol = 2
)

# Compare models
models <- c("No Transformation", "Log", "Square Root", "Inverse")
r2_scores <- c(model_original$r_squared, model_log$r_squared, 
               model_sqrt$r_squared, model_inverse$r_squared)
rmse_scores <- c(model_original$rmse, model_log$rmse, 
                model_sqrt$rmse, model_inverse$rmse)

# Create comparison dataframe
comparison_df <- data.frame(
  Transformation = models,
  R_squared = r2_scores,
  RMSE = rmse_scores
)

# Plot comparison
p1 <- ggplot(comparison_df, aes(x = Transformation, y = R_squared, fill = Transformation)) +
  geom_bar(stat = "identity") +
  labs(title = "R² Score Comparison", y = "R² Score") +
  ylim(0, 1) +
  theme_minimal() +
  theme(legend.position = "none")

p2 <- ggplot(comparison_df, aes(x = Transformation, y = RMSE, fill = Transformation)) +
  geom_bar(stat = "identity") +
  labs(title = "RMSE Comparison", y = "RMSE") +
  theme_minimal() +
  theme(legend.position = "none")

grid.arrange(p1, p2, ncol = 2)

# Print comparison table
print("Transformation Comparison:")
print(comparison_df)
