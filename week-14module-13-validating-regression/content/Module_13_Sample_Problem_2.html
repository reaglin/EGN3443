Module 13 Sample Problem 2

Problem Statement (Influence Diagnostics)

A materials engineer is studying the relationship between the processing temperature (°C) and the tensile strength (MPa) of a new aluminum alloy. The engineer collected data from 20 test specimens processed at different temperatures. Initial regression analysis suggests a linear relationship, but the engineer suspects that some data points might be disproportionately influencing the regression results.

Theoretical Background

What Are Influence Diagnostics?

Influence diagnostics are statistical tools used to identify data points that have a disproportionate effect on the results of a regression analysis. These influential observations can substantially change:

  1. The estimated coefficients (intercept and slopes)
  2. The standard errors of these estimates
  3. The overall fit of the model (R²)
  4. The predictions made by the model

Key Diagnostic Measures

  1. Leverage (Hat Values) - Identifies observations with unusual predictor values.
    • Range: 0 to 1
    • Rule of thumb threshold: 2p/n (where p is the number of predictors + 1, n is sample size)
  2. Studentized Residuals - Standardized residuals that help identify outliers in the response variable.
    • Rule of thumb threshold: Values beyond ±2 are potential outliers
  3. Cook's Distance - Measures the overall influence of an observation on both the fitted values and estimated parameters.
    • Rule of thumb threshold: 4/n
  4. DFFITS - Measures how much the predicted value changes when the observation is excluded.
    • Rule of thumb threshold: 2√(p/n)
  5. DFBETAS - Measures how much each regression coefficient changes when the observation is excluded.
    • Rule of thumb threshold: 2/√n

Analysis of the Problem

In our example, the materials engineer has collected data on the relationship between processing temperature and tensile strength for a new aluminum alloy. After running the initial analysis, several key findings emerge:

Findings from Diagnostics

  1. Two influential data points: Using Cook's distance, we identified two observations that exceed the 4/n threshold.
  2. Impact on regression coefficients: These influential points substantially change both the intercept and slope of the regression line.
  3. Types of influential points:
    • One has high leverage (unusual x-value) but fits the general trend
    • One is an outlier (unusual y-value) but with moderate leverage

Effect on the Model

The identified influential points have several effects:

  • They pull the regression line toward themselves
  • They reduce the model's R² value
  • They increase the standard errors of the coefficient estimates
  • They might lead to incorrect inferences about the relationship between temperature and tensile strength

Solutions to Address Influential Points

There are several approaches to handling influential data points:

1. Investigate Potential Data Issues

Before removing any points, investigate whether they represent:

  • Measurement errors
  • Data entry mistakes
  • A different manufacturing process
  • Natural variation in the material

2. Remove Influential Points

If the points are confirmed to be errors or not representative of the process being studied:

  • Refit the model without these points
  • Compare the original and cleaned models
  • Document the reasons for removal

As shown in both the Python and R implementations, removing the influential points leads to:

  • A steeper slope (stronger relationship between temperature and strength)
  • Higher R² value (better fit)
  • Lower standard errors (more precise estimates)

3. Use Robust Regression Methods

Instead of removing points, robust regression techniques reduce their influence:

  • Huber Regression: Assigns lower weights to observations with large residuals
  • Tukey's Bisquare: More aggressive downweighting of outliers
  • RANSAC: Identifies inliers and fits the model only to them

The implementation demonstrates how Huber regression provides a middle ground between keeping all points and removing influential ones.

4. Transform Variables

In some cases, transforming variables can reduce the impact of influential points:

  • Log transformation
  • Box-Cox transformation
  • Other nonlinear transformations

5. Add Additional Predictors

Sometimes influential points indicate missing variables:

  • Consider if additional factors might explain the unusual observations
  • Add interaction terms if appropriate

Recommendations for the Materials Engineer

Based on our analysis, I would recommend:

  1. Investigate the two influential points - Determine if they represent experimental errors or legitimate but unusual specimens.
  2. Consider separate models - If the influential points represent a different manufacturing process or material composition, consider developing separate models.
  3. Use robust regression - If all data points are valid but some have high influence, use robust regression techniques to handle them without complete removal.
  4. Report multiple models - Show stakeholders both the original and modified models to help them understand the sensitivity of the results.
  5. Design future experiments - Plan future tests to include replicates at the temperature ranges where influential points were found to confirm or refute their behavior.

Conclusion

Influence diagnostics are essential tools for building reliable regression models in engineering applications. By systematically identifying and addressing influential observations, engineers can develop more robust models that better represent the true relationships between variables.

In this example, we've seen how seemingly small data issues can substantially impact model interpretation and predictions. The implementation in both Python and R provides a comprehensive framework for detecting and handling influential points in regression analysis.

Solution in Python (link)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.linear_model import LinearRegression
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import OLSInfluence
from statsmodels.graphics.regressionplots import influence_plot

# Set random seed for reproducibility
np.random.seed(42)

# Generate synthetic data for our aluminum alloy example
n = 20
temperature = np.linspace(450, 650, n)

# Create tensile strength with a linear relationship plus noise
tensile_strength = 200 + 0.5 * (temperature - 450) + np.random.normal(0, 10, n)

# Add two influential points
temperature = np.append(temperature, [500, 600])
# One high leverage point
tensile_strength = np.append(tensile_strength, [290, 350])

# Create a DataFrame
data = pd.DataFrame({
    'Temperature': temperature,
    'TensileStrength': tensile_strength
})

# Fit a linear regression model using statsmodels for detailed diagnostics
X = sm.add_constant(data['Temperature'])
y = data['TensileStrength']
model = sm.OLS(y, X).fit()

# Print summary of the model
print(model.summary())

# Calculate influence measures
influence = OLSInfluence(model)

# Extract key influence diagnostics
diagnostics = pd.DataFrame({
    'Leverage': influence.hat_matrix_diag,
    'Studentized_Residuals': influence.resid_studentized_external,
    'Cooks_Distance': influence.cooks_distance[0],
    'DFFITS': influence.dffits[0],
    'DFBETAS_Intercept': influence.dfbetas[:,0],
    'DFBETAS_Slope': influence.dfbetas[:,1]
})

diagnostics.index = data.index
diagnostics = pd.concat([data, diagnostics], axis=1)
print("\nInfluence Diagnostics:\n")
print(diagnostics)

# Visualize the data and regression line
plt.figure(figsize=(12, 8))

plt.subplot(2, 2, 1)
sns.regplot(x='Temperature', y='TensileStrength', data=data, 
            scatter_kws={'s': 80}, line_kws={'color': 'red'})
plt.title('Temperature vs Tensile Strength')
plt.xlabel('Temperature (°C)')
plt.ylabel('Tensile Strength (MPa)')

# Highlight points with high Cook's Distance
high_influence = diagnostics[diagnostics['Cooks_Distance'] > 4/len(data)]
plt.scatter(high_influence['Temperature'], high_influence['TensileStrength'], 
            s=150, facecolors='none', edgecolors='green', linewidth=2,
            label=f'High Influence Points (n={len(high_influence)})')
plt.legend()

# Plot Cook's distance
plt.subplot(2, 2, 2)
cook_threshold = 4/len(data)  # Common threshold: 4/n
plt.stem(diagnostics.index, diagnostics['Cooks_Distance'], markerfmt=',')
plt.axhline(y=cook_threshold, color='r', linestyle='--', 
           label=f'Threshold ({cook_threshold:.3f})')
plt.title("Cook's Distance")
plt.xlabel('Observation Index')
plt.ylabel("Cook's Distance")
plt.legend()

# Plot Leverage vs. Studentized Residuals
plt.subplot(2, 2, 3)
plt.scatter(diagnostics['Leverage'], diagnostics['Studentized_Residuals'])
plt.axhline(y=0, color='gray', linestyle='--')
plt.axhline(y=2, color='red', linestyle='--', label='Outlier Threshold (±2)')
plt.axhline(y=-2, color='red', linestyle='--')
leverage_threshold = 2 * (X.shape[1]) / len(data)
plt.axvline(x=leverage_threshold, color='blue', linestyle='--', 
           label=f'Leverage Threshold ({leverage_threshold:.3f})')
plt.title('Leverage vs. Studentized Residuals')
plt.xlabel('Leverage (Hat Value)')
plt.ylabel('Studentized Residuals')
plt.legend()

# Create a more detailed influence plot
plt.subplot(2, 2, 4)
influence_plot(model, ax=plt.gca())
plt.title('Influence Plot')
plt.tight_layout()
plt.show()

# Refit the model without influential points
influential_idx = diagnostics[diagnostics['Cooks_Distance'] > cook_threshold].index
clean_data = data.drop(influential_idx)

X_clean = sm.add_constant(clean_data['Temperature'])
y_clean = clean_data['TensileStrength']
model_clean = sm.OLS(y_clean, X_clean).fit()

# Compare original and cleaned models
print("\nOriginal Model:\n")
print(f"Intercept: {model.params[0]:.4f}")
print(f"Slope: {model.params[1]:.4f}")
print(f"R-squared: {model.rsquared:.4f}")

print("\nCleaned Model (without influential points):\n")
print(f"Intercept: {model_clean.params[0]:.4f}")
print(f"Slope: {model_clean.params[1]:.4f}")
print(f"R-squared: {model_clean.rsquared:.4f}")

# Plot both models
plt.figure(figsize=(10, 6))
sns.scatterplot(x='Temperature', y='TensileStrength', data=data, s=80, label='All Data')
sns.scatterplot(x='Temperature', y='TensileStrength', data=data.loc[influential_idx], 
                s=150, color='red', label='Influential Points')

# Add regression lines
x_range = np.linspace(data['Temperature'].min(), data['Temperature'].max(), 100)
# Original model
plt.plot(x_range, model.params[0] + model.params[1] * x_range, 
         'r-', label='Original Model')
# Cleaned model
plt.plot(x_range, model_clean.params[0] + model_clean.params[1] * x_range, 
         'g-', label='Cleaned Model')

plt.title('Comparison of Models With and Without Influential Points')
plt.xlabel('Temperature (°C)')
plt.ylabel('Tensile Strength (MPa)')
plt.legend()
plt.grid(True)
plt.show()

# Robust regression using Huber loss
from sklearn.linear_model import HuberRegressor

X_for_huber = data['Temperature'].values.reshape(-1, 1)
huber_model = HuberRegressor(epsilon=1.35).fit(X_for_huber, y)

# Plot Huber regression results
plt.figure(figsize=(10, 6))
sns.scatterplot(x='Temperature', y='TensileStrength', data=data, s=80, label='All Data')
sns.scatterplot(x='Temperature', y='TensileStrength', data=data.loc[influential_idx], 
                s=150, color='red', label='Influential Points')

# Add regression lines
plt.plot(x_range, model.params[0] + model.params[1] * x_range, 
         'r-', label='OLS Model')
plt.plot(x_range, model_clean.params[0] + model_clean.params[1] * x_range, 
         'g-', label='OLS without Influential Points')
plt.plot(x_range, huber_model.intercept_ + huber_model.coef_[0] * x_range, 
         'b-', label='Robust Huber Regression')

plt.title('Comparison with Robust Regression')
plt.xlabel('Temperature (°C)')
plt.ylabel('Tensile Strength (MPa)')
plt.legend()
plt.grid(True)
plt.show()

Solution in R

# Load necessary libraries
library(ggplot2)
library(dplyr)
library(gridExtra)
library(MASS)  # For robust regression

# Set seed for reproducibility
set.seed(42)

# Generate synthetic data for our aluminum alloy example
n <- 20
temperature <- seq(450, 650, length.out = n)

# Create tensile strength with a linear relationship plus noise
tensile_strength <- 200 + 0.5 * (temperature - 450) + rnorm(n, 0, 10)

# Add two influential points
temperature <- c(temperature, 500, 600)
# One high leverage point with unusual strength
tensile_strength <- c(tensile_strength, 290, 350)

# Create a data frame
data <- data.frame(
  Temperature = temperature,
  TensileStrength = tensile_strength
)

# Fit a linear regression model
model <- lm(TensileStrength ~ Temperature, data = data)

# Print model summary
summary(model)

# Calculate influence measures
influence_measures <- influence.measures(model)
print(influence_measures)

# Extract key influence diagnostics
diagnostics <- data.frame(
  Temperature = data$Temperature,
  TensileStrength = data$TensileStrength,
  Leverage = hatvalues(model),
  Studentized_Residuals = rstudent(model),
  Cooks_Distance = cooks.distance(model),
  DFFITS = dffits(model),
  DFBETAS_Intercept = dfbetas(model)[,1],
  DFBETAS_Slope = dfbetas(model)[,2]
)

print(head(diagnostics))

# Define thresholds
cook_threshold <- 4/nrow(data)
leverage_threshold <- 2 * (2) / nrow(data)  # 2 * (p/n), where p = 2 (intercept and slope)

# Create visualizations
# 1. Scatter plot with regression line
p1 <- ggplot(data, aes(x = Temperature, y = TensileStrength)) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", color = "red", se = FALSE) +
  geom_point(data = diagnostics[diagnostics$Cooks_Distance > cook_threshold,], 
             aes(x = Temperature, y = TensileStrength), 
             color = "green", size = 5, shape = 1, stroke = 2) +
  labs(title = "Temperature vs Tensile Strength",
       x = "Temperature (°C)",
       y = "Tensile Strength (MPa)") +
  theme_bw()

# 2. Cook's distance plot
p2 <- ggplot(diagnostics, aes(x = 1:nrow(diagnostics), y = Cooks_Distance)) +
  geom_segment(aes(x = 1:nrow(diagnostics), y = 0, xend = 1:nrow(diagnostics), yend = Cooks_Distance)) +
  geom_point(size = 2) +
  geom_hline(yintercept = cook_threshold, linetype = "dashed", color = "red") +
  labs(title = "Cook's Distance",
       x = "Observation Index",
       y = "Cook's Distance") +
  annotate("text", x = nrow(diagnostics)/2, y = cook_threshold + max(diagnostics$Cooks_Distance)/20, 
           label = paste("Threshold =", round(cook_threshold, 3)), color = "red") +
  theme_bw()

# 3. Leverage vs Studentized Residuals plot
p3 <- ggplot(diagnostics, aes(x = Leverage, y = Studentized_Residuals)) +
  geom_point(size = 3) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "gray") +
  geom_hline(yintercept = c(-2, 2), linetype = "dashed", color = "red") +
  geom_vline(xintercept = leverage_threshold, linetype = "dashed", color = "blue") +
  labs(title = "Leverage vs Studentized Residuals",
       x = "Leverage (Hat Value)",
       y = "Studentized Residuals") +
  annotate("text", x = leverage_threshold + max(diagnostics$Leverage)/20, y = 0, 
           label = paste("Leverage Threshold =", round(leverage_threshold, 3)), 
           color = "blue", angle = 90) +
  theme_bw()

# 4. Influence plot (bubble plot)
p4 <- ggplot(diagnostics, aes(x = Leverage, y = Studentized_Residuals)) +
  geom_point(aes(size = Cooks_Distance), alpha = 0.7) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "gray") +
  geom_hline(yintercept = c(-2, 2), linetype = "dashed", color = "red") +
  geom_vline(xintercept = leverage_threshold, linetype = "dashed", color = "blue") +
  labs(title = "Influence Plot",
       x = "Leverage (Hat Value)",
       y = "Studentized Residuals",
       size = "Cook's Distance") +
  theme_bw()

# Arrange plots in a grid
grid.arrange(p1, p2, p3, p4, ncol = 2)

# Identify influential points
influential_idx <- which(diagnostics$Cooks_Distance > cook_threshold)
print(paste("Influential observation indices:", paste(influential_idx, collapse = ", ")))

# Refit the model without influential points
clean_data <- data[-influential_idx, ]
model_clean <- lm(TensileStrength ~ Temperature, data = clean_data)

# Compare original and cleaned models
cat("\nOriginal Model:\n")
cat("Intercept:", coef(model)[1], "\n")
cat("Slope:", coef(model)[2], "\n")
cat("R-squared:", summary(model)$r.squared, "\n")

cat("\nCleaned Model (without influential points):\n")
cat("Intercept:", coef(model_clean)[1], "\n")
cat("Slope:", coef(model_clean)[2], "\n")
cat("R-squared:", summary(model_clean)$r.squared, "\n")

# Plot both models
comparison_plot <- ggplot() +
  geom_point(data = data, aes(x = Temperature, y = TensileStrength), size = 3) +
  geom_point(data = data[influential_idx,], 
             aes(x = Temperature, y = TensileStrength, color = "Influential Points"), 
             size = 5) +
  geom_abline(intercept = coef(model)[1], slope = coef(model)[2], 
              color = "red", size = 1, linetype = "solid") +
  geom_abline(intercept = coef(model_clean)[1], slope = coef(model_clean)[2], 
              color = "green", size = 1, linetype = "solid") +
  scale_color_manual(values = c("Influential Points" = "red")) +
  labs(title = "Comparison of Models With and Without Influential Points",
       x = "Temperature (°C)",
       y = "Tensile Strength (MPa)",
       color = "Legend") +
  theme_bw() +
  theme(legend.position = "bottom")

# Add a legend for the regression lines
comparison_plot <- comparison_plot +
  annotate("text", x = min(data$Temperature) + 20, y = max(data$TensileStrength) - 10, 
           label = "Original Model", color = "red") +
  annotate("text", x = min(data$Temperature) + 20, y = max(data$TensileStrength) - 20, 
           label = "Cleaned Model", color = "green")

print(comparison_plot)

# Fit a robust regression model using Huber's M-estimation
robust_model <- rlm(TensileStrength ~ Temperature, data = data)

# Compare all three models
cat("\nRobust Model (using Huber's M-estimation):\n")
cat("Intercept:", coef(robust_model)[1], "\n")
cat("Slope:", coef(robust_model)[2], "\n")

# Create a new x range for predictions
x_range <- seq(min(data$Temperature), max(data$Temperature), length.out = 100)
pred_df <- data.frame(Temperature = x_range)

# Make predictions
pred_original <- predict(model, newdata = pred_df)
pred_clean <- predict(model_clean, newdata = pred_df)
pred_robust <- predict(robust_model, newdata = pred_df)

# Create prediction data frames
pred_df_original <- data.frame(Temperature = x_range, TensileStrength = pred_original, Model = "OLS")
pred_df_clean <- data.frame(Temperature = x_range, TensileStrength = pred_clean, Model = "OLS without Influential Points")
pred_df_robust <- data.frame(Temperature = x_range, TensileStrength = pred_robust, Model = "Robust Regression")
pred_combined <- rbind(pred_df_original, pred_df_clean, pred_df_robust)

# Plot all three models
final_plot <- ggplot() +
  geom_point(data = data, aes(x = Temperature, y = TensileStrength), size = 3) +
  geom_point(data = data[influential_idx,], 
             aes(x = Temperature, y = TensileStrength), 
             color = "red", size = 5) +
  geom_line(data = pred_combined, aes(x = Temperature, y = TensileStrength, color = Model, linetype = Model), 
            size = 1) +
  scale_color_manual(values = c("OLS" = "red", 
                               "OLS without Influential Points" = "green",
                               "Robust Regression" = "blue")) +
  scale_linetype_manual(values = c("OLS" = "solid", 
                                  "OLS without Influential Points" = "dashed",
                                  "Robust Regression" = "dotdash")) +
  labs(title = "Comparison with Robust Regression",
       x = "Temperature (°C)",
       y = "Tensile Strength (MPa)") +
  theme_bw() +
  theme(legend.position = "bottom")

print(final_plot)
