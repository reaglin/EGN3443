Engineering Problem: Concrete Strength Prediction with Uncertainty Quantification

Problem Statement

A civil engineering firm needs to predict the compressive strength of concrete samples based on their water-cement ratio. While point estimates are useful, they want to understand the range of possible values to ensure structural safety with a specified confidence level.

For infrastructure projects, understanding not just the expected concrete strength but also the uncertainty in these predictions is critical for safety margins and quality control.

Theoretical Background

In linear regression, prediction intervals differ from confidence intervals:

  • Confidence intervals: Estimate uncertainty in the population mean
  • Prediction intervals: Account for both model uncertainty and inherent random variability in individual observations

A prediction interval is wider than a confidence interval because it includes:

  1. Uncertainty in estimating the model parameters
  2. Random variability of individual observations around the regression line

Solution Approach

I'll develop both Python and R solutions that:

  1. Generate synthetic data representing concrete samples
  2. Fit a linear regression model
  3. Calculate prediction intervals
  4. Visualize the results with appropriate charts
  5. Analyze the findings

Analysis and Insights

Interpretation of Results

From both the Python and R implementations, we can observe several key insights:

  1. Model Fit: The linear regression shows a strong negative correlation between water-cement ratio and concrete strength. This aligns with engineering principles - higher water-cement ratios generally produce weaker concrete.
  2. Prediction Intervals: The prediction intervals widen as we move away from the mean of the water-cement ratio data. This illustrates an important property of regression models - predictions have greater uncertainty at the boundaries of our data.
  3. Uncertainty Quantification: The width of the prediction intervals provides crucial information about concrete strength variability. For example, at a water-cement ratio of 0.35, we might expect a strength of approximately 42-43 MPa, but with a 95% prediction interval of about ±6 MPa.
  4. Bootstrapping Validation: The bootstrap validation confirms that our prediction intervals have approximately the expected coverage rate of 95%, validating our statistical approach.

Engineering Applications

This analysis has several practical applications in civil engineering:

  1. Quality Control: Prediction intervals can be used to establish acceptable ranges for concrete strength testing. If test results fall outside the prediction intervals, it may indicate issues with the concrete mix or curing process.
  2. Safety Factors: Engineers can use the width of prediction intervals to inform safety factors in structural design. Wider intervals suggest greater variability, which may necessitate larger safety margins.
  3. Mix Design Optimization: By understanding the relationship between water-cement ratio and strength (including uncertainty), engineers can optimize concrete mix designs for specific applications.
  4. Risk Management: When a specific minimum strength is required, the lower bound of the prediction interval provides a more conservative estimate than the point prediction, helping manage risk in critical applications.

Limitations and Considerations

  1. Model Assumptions: Linear regression assumes a linear relationship and homoscedastic errors. Real concrete strength data might violate these assumptions, potentially requiring more sophisticated models.
  2. Additional Variables: Real concrete strength depends on many factors beyond water-cement ratio, including cement type, aggregate properties, additives, and curing conditions. A multivariate approach would be more comprehensive.
  3. Sample Size: Larger sample sizes would provide more reliable estimates of both the regression parameters and the prediction intervals.
  4. Non-linear Effects: At extreme water-cement ratios, the relationship may become non-linear. Our model would need to be adjusted accordingly.

Conclusion

Prediction intervals provide a valuable tool for engineers to quantify uncertainty in concrete strength predictions. By accounting for both model uncertainty and inherent variability, they offer a more complete picture than point estimates alone.

Solution in Python (link)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score
import scipy.stats as stats

# Set random seed for reproducibility
np.random.seed(42)

# Generate synthetic data
# Water-cement ratio typically ranges from 0.3 to 0.7
# Higher water-cement ratio generally leads to lower strength
n_samples = 100
water_cement_ratio = np.random.uniform(0.3, 0.7, n_samples)

# True relationship: strength = 60 - 50*(water_cement_ratio) + noise
# Adding noise to simulate real-world variability
noise = np.random.normal(0, 3, n_samples)  # 3 MPa standard deviation
strength = 60 - 50 * water_cement_ratio + noise

# Create a dataframe
df = pd.DataFrame({
    'water_cement_ratio': water_cement_ratio,
    'strength': strength
})

# Split data into X and y
X = df[['water_cement_ratio']]
y = df['strength']

# Fit linear regression model
model = LinearRegression()
model.fit(X, y)

# Get model parameters
slope = model.coef_[0]
intercept = model.intercept_

# Calculate predictions
y_pred = model.predict(X)

# Calculate R² and RMSE for model evaluation
r2 = r2_score(y, y_pred)
rmse = np.sqrt(mean_squared_error(y, y_pred))

# Calculate prediction intervals
# For this we need the mean squared error and the leverage
n = len(X)
p = 1  # Number of predictors (excluding intercept)
dof = n - p - 1  # Degrees of freedom

# Calculate MSE from the model
mse = np.sum((y - y_pred)**2) / dof

# Prepare grid for prediction
x_grid = np.linspace(0.25, 0.75, 100).reshape(-1, 1)

# Calculate predictions for the grid
y_grid_pred = model.predict(x_grid)

# Calculate prediction intervals
# We need the leverage values which depend on the X values
# For simple linear regression, this can be calculated as:
x_mean = np.mean(X)
x_std = np.std(X, ddof=1)
t_value = stats.t.ppf(0.975, dof)  # 95% prediction interval

# Initialize arrays for lower and upper bounds
lower_bound = np.zeros(len(x_grid))
upper_bound = np.zeros(len(x_grid))

for i, x_val in enumerate(x_grid):
    # Calculate leverage for this x value
    leverage = 1/n + (x_val - x_mean)**2 / (np.sum((X - x_mean)**2))
    
    # Calculate prediction interval
    # Formula: pred ± t * sqrt(MSE * (1 + leverage))
    prediction_error = t_value * np.sqrt(mse * (1 + leverage))
    
    lower_bound[i] = y_grid_pred[i] - prediction_error
    upper_bound[i] = y_grid_pred[i] + prediction_error

# Plot the results
plt.figure(figsize=(12, 8))

# Plot data points
plt.scatter(X, y, alpha=0.6, color='blue', label='Concrete Samples')

# Plot regression line
plt.plot(x_grid, y_grid_pred, color='red', linewidth=2, label=f'Regression Line (R² = {r2:.3f})')

# Plot prediction intervals
plt.fill_between(x_grid.flatten(), lower_bound, upper_bound, 
                 color='red', alpha=0.2, label='95% Prediction Interval')

# Plot settings
plt.title('Concrete Strength vs Water-Cement Ratio with Prediction Intervals', fontsize=14)
plt.xlabel('Water-Cement Ratio', fontsize=12)
plt.ylabel('Compressive Strength (MPa)', fontsize=12)
plt.grid(True, alpha=0.3)
plt.legend(fontsize=12)

# Add equation and RMSE to the plot
equation = f"Strength = {intercept:.2f} - {abs(slope):.2f} × (Water-Cement Ratio)"
plt.text(0.30, 25, equation, fontsize=12, bbox=dict(facecolor='white', alpha=0.8))
plt.text(0.30, 22, f"RMSE = {rmse:.2f} MPa", fontsize=12, bbox=dict(facecolor='white', alpha=0.8))

plt.tight_layout()
plt.show()

# Analysis of prediction intervals at specific points
test_points = np.array([0.35, 0.45, 0.55, 0.65]).reshape(-1, 1)
test_predictions = model.predict(test_points)

print("Analysis of Prediction Intervals at Specific Water-Cement Ratios:")
print("------------------------------------------------------------")
print("W/C Ratio | Predicted Strength | 95% Prediction Interval | Interval Width")
print("------------------------------------------------------------")

for i, x_val in enumerate(test_points):
    # Calculate leverage for this x value
    leverage = 1/n + (x_val - x_mean)**2 / (np.sum((X - x_mean)**2))
    
    # Calculate prediction interval
    prediction_error = t_value * np.sqrt(mse * (1 + leverage))
    
    lower = test_predictions[i] - prediction_error
    upper = test_predictions[i] + prediction_error
    width = upper - lower
    
    print(f"  {x_val[0]:.2f}    |      {test_predictions[i]:.2f} MPa     |   [{lower[0]:.2f}, {upper[0]:.2f}] MPa   |   {width[0]:.2f} MPa")

# Perform bootstrapping to validate prediction intervals
n_bootstrap = 1000
coverage_count = 0

for _ in range(n_bootstrap):
    # Sample with replacement
    indices = np.random.choice(n, n, replace=True)
    X_boot = X.iloc[indices]
    y_boot = y.iloc[indices]
    
    # Fit model to bootstrap sample
    model_boot = LinearRegression()
    model_boot.fit(X_boot, y_boot)
    
    # Make predictions on original data
    y_boot_pred = model_boot.predict(X)
    
    # Calculate if original point falls within prediction interval
    mse_boot = np.sum((y_boot - model_boot.predict(X_boot))**2) / (len(X_boot) - p - 1)
    
    # Check for a specific point (e.g., middle of range)
    test_idx = n // 2
    test_x = X.iloc[test_idx:test_idx+1]
    test_y = y.iloc[test_idx]
    
    leverage_boot = 1/len(X_boot) + ((test_x.values - np.mean(X_boot))**2 / 
                                    (np.sum((X_boot - np.mean(X_boot))**2)))
    
    pred_error_boot = t_value * np.sqrt(mse_boot * (1 + leverage_boot))
    y_pred_boot = model_boot.predict(test_x)
    
    lower_boot = y_pred_boot - pred_error_boot
    upper_boot = y_pred_boot + pred_error_boot
    
    if lower_boot <= test_y <= upper_boot:
        coverage_count += 1

coverage_rate = coverage_count / n_bootstrap
print(f"\nBootstrap Coverage Rate: {coverage_rate:.2%}")
print(f"Expected Coverage Rate: 95%")
print(f"Difference: {abs(coverage_rate - 0.95):.2%}")
