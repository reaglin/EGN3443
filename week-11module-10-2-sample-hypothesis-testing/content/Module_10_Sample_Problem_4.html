Module 10 Sample Problem 4

Problem Statement

An electronics manufacturing company has implemented a new assembly process designed to reduce defect rates in circuit board production. The quality assurance team wants to determine if the new process actually results in lower defect rates compared to the standard process.

Experiment details:

  • Standard process: 5,000 circuit boards produced, 315 with defects
  • New process: 4,500 circuit boards produced, 207 with defects

The engineering team needs to determine:

  1. Is there a statistically significant difference in defect rates between the two processes?
  2. What is the estimated reduction in defect percentage, if any?
  3. What is the practical significance of these findings?

I'll analyze this problem using both a two-proportion z-test and a chi-squared test of independence, implementing the solution in both Python and R.

Statistical Analysis Approach

Hypotheses

For both tests, we'll use the following hypotheses:

  • H₀ (null hypothesis): The defect proportions are equal between the two processes (p₁ = p₂)
  • H₁ (alternative hypothesis): The defect proportions differ between the two processes (p₁ ≠ p₂)

Two-Proportion Z-Test

The two-proportion z-test is appropriate when:

  • We are comparing proportions from two independent groups
  • Both samples are large enough (np ≥ 10 and n(1-p) ≥ 10 for both groups)
  • The samples are independent

Our data meets these conditions:

  • We have two independent processes
  • Sample sizes are large (5,000 and 4,500)
  • The success-failure counts are well above the minimum thresholds

Chi-Squared Test of Independence

The chi-squared test is also suitable for this problem as:

  • We're analyzing categorical data (defective vs. non-defective)
  • We want to test the association between two categorical variables (process type and defect status)
  • Expected frequencies are large enough (>5 in each cell)

Solution in Python (link)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import statsmodels.api as sm
from statsmodels.stats.proportion import proportions_ztest, proportion_confint

# Data setup
process_standard = {'boards': 5000, 'defects': 315}
process_new = {'boards': 4500, 'defects': 207}

# Calculate defect rates
defect_rate_standard = process_standard['defects'] / process_standard['boards']
defect_rate_new = process_new['defects'] / process_new['boards']

print(f"Standard process defect rate: {defect_rate_standard:.4f} ({defect_rate_standard*100:.2f}%)")
print(f"New process defect rate: {defect_rate_new:.4f} ({defect_rate_new*100:.2f}%)")
print(f"Absolute difference: {(defect_rate_standard - defect_rate_new):.4f} ({(defect_rate_standard - defect_rate_new)*100:.2f}%)")
print(f"Relative improvement: {(defect_rate_standard - defect_rate_new)/defect_rate_standard*100:.2f}%")

# Two-proportion z-test
count = np.array([process_standard['defects'], process_new['defects']])
nobs = np.array([process_standard['boards'], process_new['boards']])

z_stat, p_value = proportions_ztest(count, nobs, alternative='two-sided')
print("\nTwo-proportion z-test:")
print(f"z-statistic: {z_stat:.4f}")
print(f"p-value: {p_value:.8f}")

# Calculate confidence interval for the difference in proportions
ci_low, ci_upp = proportion_confint(count[0], nobs[0]) 
ci_low_new, ci_upp_new = proportion_confint(count[1], nobs[1])

print(f"\nConfidence interval for standard process: ({ci_low:.4f}, {ci_upp:.4f})")
print(f"Confidence interval for new process: ({ci_low_new:.4f}, {ci_upp_new:.4f})")

# Manual calculation of confidence interval for the difference
se_diff = np.sqrt(defect_rate_standard*(1-defect_rate_standard)/process_standard['boards'] + 
                  defect_rate_new*(1-defect_rate_new)/process_new['boards'])
diff = defect_rate_standard - defect_rate_new
margin = 1.96 * se_diff
ci_diff_low, ci_diff_upp = diff - margin, diff + margin

print(f"95% CI for difference in proportions: ({ci_diff_low:.4f}, {ci_diff_upp:.4f})")

# Chi-squared test of independence
# Create contingency table
contingency = pd.DataFrame({
    'Defective': [process_standard['defects'], process_new['defects']],
    'Non-Defective': [
        process_standard['boards'] - process_standard['defects'],
        process_new['boards'] - process_new['defects']
    ]
}, index=['Standard Process', 'New Process'])

print("\nContingency table:")
print(contingency)

chi2, p, dof, expected = stats.chi2_contingency(contingency)
print(f"\nChi-squared test:")
print(f"Chi2 value: {chi2:.4f}")
print(f"p-value: {p:.8f}")
print(f"Degrees of freedom: {dof}")
print("\nExpected frequencies:")
print(pd.DataFrame(expected, 
                  columns=['Defective', 'Non-Defective'],
                  index=['Standard Process', 'New Process']))

# Visualizations
# 1. Bar chart of defect rates
plt.figure(figsize=(10, 6))
plt.bar(['Standard Process', 'New Process'], 
        [defect_rate_standard*100, defect_rate_new*100],
        color=['#3a86ff', '#8ac926'])
plt.ylabel('Defect Rate (%)')
plt.title('Comparison of Defect Rates Between Processes')
plt.ylim(0, max(defect_rate_standard, defect_rate_new) * 100 * 1.2)

# Add the actual values on top of bars
for i, rate in enumerate([defect_rate_standard*100, defect_rate_new*100]):
    plt.text(i, rate + 0.2, f"{rate:.2f}%", ha='center')

plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.savefig('defect_rates_comparison.png', dpi=300, bbox_inches='tight')
plt.show()

# 2. Mosaic plot (visualization of contingency table)
plt.figure(figsize=(10, 6))
contingency_pct = contingency.copy()
contingency_pct['Defective'] = contingency_pct['Defective'] / contingency_pct.sum(axis=1) * 100
contingency_pct['Non-Defective'] = contingency_pct['Non-Defective'] / contingency_pct.sum(axis=1) * 100

ax = contingency_pct.plot(kind='bar', stacked=True, figsize=(10, 6), 
                         color=['#e63946', '#457b9d'])
plt.title('Proportion of Defective vs. Non-Defective Boards by Process')
plt.ylabel('Percentage (%)')
plt.ylim(0, 100)
plt.grid(axis='y', linestyle='--', alpha=0.3)

# Add percentage labels
for i, process in enumerate(contingency_pct.index):
    defect_pct = contingency_pct.loc[process, 'Defective']
    non_defect_pct = contingency_pct.loc[process, 'Non-Defective']
    ax.text(i, defect_pct/2, f"{defect_pct:.2f}%", ha='center', color='white')
    ax.text(i, defect_pct + non_defect_pct/2, f"{non_defect_pct:.2f}%", ha='center')
    
plt.savefig('defect_proportions_by_process.png', dpi=300, bbox_inches='tight')
plt.show()

# 3. Confidence interval visualization
plt.figure(figsize=(10, 6))
processes = ['Standard Process', 'New Process', 'Difference']
means = [defect_rate_standard, defect_rate_new, diff]
errors = [(ci_upp-ci_low)/2, (ci_upp_new-ci_low_new)/2, margin]
positions = [1, 2, 3.5]  # Separate the difference plot

plt.errorbar(positions[0], means[0], yerr=errors[0], fmt='s', capsize=10,
             markersize=10, color='#3a86ff', ecolor='black')
plt.errorbar(positions[1], means[1], yerr=errors[1], fmt='s', capsize=10,
             markersize=10, color='#8ac926', ecolor='black')
plt.errorbar(positions[2], means[2], yerr=errors[2], fmt='s', capsize=10,
             markersize=10, color='#e63946', ecolor='black')

plt.axhline(y=0, color='grey', linestyle='--', alpha=0.7)  # Reference line for difference
plt.xticks(positions, processes)
plt.ylabel('Proportion')
plt.title('Defect Rates with 95% Confidence Intervals')
plt.grid(axis='y', linestyle='--', alpha=0.7)

for i, (pos, mean, err) in enumerate(zip(positions, means, errors)):
    plt.text(pos, mean + err + 0.005, f"{mean:.4f}±{err:.4f}", ha='center')

plt.savefig('confidence_intervals.png', dpi=300, bbox_inches='tight')
plt.show()

# Calculate effect size - Phi coefficient
phi = np.sqrt(chi2 / sum(nobs))
print(f"\nEffect size (Phi coefficient): {phi:.4f}")

# Interpretation of effect size
if phi < 0.1:
    effect_interpretation = "negligible"
elif phi < 0.3:
    effect_interpretation = "small"
elif phi < 0.5:
    effect_interpretation = "medium"
else:
    effect_interpretation = "large"
    
print(f"This represents a {effect_interpretation} effect size.")

# Calculate the number needed to treat (NNT)
# In this context: How many circuit boards need to be produced with the new process
# to prevent one defect compared to the standard process
absolute_risk_reduction = defect_rate_standard - defect_rate_new
nnt = 1 / absolute_risk_reduction
print(f"\nNumber Needed to Treat (NNT): {nnt:.2f}")
print(f"Meaning: For every {int(round(nnt))} circuit boards produced with the new process instead of the standard process, approximately one defect is prevented.")

# Load required libraries
library(ggplot2)
library(dplyr)
library(tidyr)
library(gridExtra)
library(knitr)
library(pwr)

# Set up the data
process_standard <- list(boards = 5000, defects = 315)
process_new <- list(boards = 4500, defects = 207)

# Calculate defect rates
defect_rate_standard <- process_standard$defects / process_standard$boards
defect_rate_new <- process_new$defects / process_new$boards

# Print summary statistics
cat("Standard process defect rate:", round(defect_rate_standard, 4), 
    "(", round(defect_rate_standard*100, 2), "%)\n", sep = "")
cat("New process defect rate:", round(defect_rate_new, 4), 
    "(", round(defect_rate_new*100, 2), "%)\n", sep = "")
cat("Absolute difference:", round(defect_rate_standard - defect_rate_new, 4),
    "(", round((defect_rate_standard - defect_rate_new)*100, 2), "%)\n", sep = "")
cat("Relative improvement:", 
    round((defect_rate_standard - defect_rate_new)/defect_rate_standard*100, 2), "%\n", sep = "")

# Two-proportion z-test
prop_test_result <- prop.test(
  x = c(process_standard$defects, process_new$defects),
  n = c(process_standard$boards, process_new$boards),
  alternative = "two.sided",
  correct = FALSE  # No continuity correction
)

cat("\nTwo-proportion z-test:\n")
print(prop_test_result)

# Manual calculation of the z-statistic for verification
p_pooled <- (process_standard$defects + process_new$defects) / 
            (process_standard$boards + process_new$boards)
            
se_diff <- sqrt(p_pooled * (1 - p_pooled) * 
               (1/process_standard$boards + 1/process_new$boards))
               
z_stat <- (defect_rate_standard - defect_rate_new) / se_diff
p_value <- 2 * (1 - pnorm(abs(z_stat)))

cat("\nManual calculation (for verification):\n")
cat("Pooled proportion:", round(p_pooled, 4), "\n")
cat("Standard error of difference:", round(se_diff, 6), "\n")
cat("Z-statistic:", round(z_stat, 4), "\n")
cat("p-value:", format.pval(p_value, digits = 8), "\n")

# Confidence intervals for individual proportions
ci_standard <- binom.test(process_standard$defects, process_standard$boards)$conf.int
ci_new <- binom.test(process_new$defects, process_new$boards)$conf.int

cat("\nConfidence interval for standard process: (", 
    round(ci_standard[1], 4), ", ", round(ci_standard[2], 4), ")\n", sep = "")
cat("Confidence interval for new process: (", 
    round(ci_new[1], 4), ", ", round(ci_new[2], 4), ")\n", sep = "")

# Chi-squared test of independence
# Create contingency table
contingency_table <- matrix(c(
  process_standard$defects, process_new$defects,
  process_standard$boards - process_standard$defects, 
  process_new$boards - process_new$defects
), nrow = 2, byrow = TRUE)

rownames(contingency_table) <- c("Standard Process", "New Process")
colnames(contingency_table) <- c("Defective", "Non-Defective")

cat("\nContingency table:\n")
print(contingency_table)

chi_sq_test <- chisq.test(contingency_table, correct = FALSE)
cat("\nChi-squared test:\n")
print(chi_sq_test)

cat("\nExpected frequencies:\n")
print(chi_sq_test$expected)

# Effect size calculation - Phi coefficient
n_total <- sum(contingency_table)
phi_coef <- sqrt(chi_sq_test$statistic / n_total)
cat("\nEffect size (Phi coefficient):", round(phi_coef, 4), "\n")

# Interpretation of effect size
effect_interpretation <- ifelse(phi_coef < 0.1, "negligible",
                       ifelse(phi_coef < 0.3, "small",
                       ifelse(phi_coef < 0.5, "medium", "large")))
cat("This represents a", effect_interpretation, "effect size.\n")

# Calculate the number needed to treat (NNT)
absolute_risk_reduction <- defect_rate_standard - defect_rate_new
nnt <- 1 / absolute_risk_reduction
cat("\nNumber Needed to Treat (NNT):", round(nnt, 2), "\n")
cat("Meaning: For every", round(nnt), "circuit boards produced with the new process instead of the standard process, approximately one defect is prevented.\n")

# Power analysis
power_result <- pwr.2p2n.test(
  h = ES.h(defect_rate_standard, defect_rate_new),
  n1 = process_standard$boards,
  n2 = process_new$boards,
  sig.level = 0.05
)
cat("\nPower analysis:\n")
cat("Effect size (Cohen's h):", round(ES.h(defect_rate_standard, defect_rate_new), 4), "\n")
cat("Power:", round(power_result$power, 4), "\n")

# Create data frames for plotting
defect_rates <- data.frame(
  Process = c("Standard Process", "New Process"),
  DefectRate = c(defect_rate_standard, defect_rate_new) * 100
)

contingency_df <- as.data.frame(contingency_table)
contingency_df$Process <- rownames(contingency_df)
contingency_long <- contingency_df %>%
  tidyr::pivot_longer(cols = c(Defective, `Non-Defective`), 
                     names_to = "Status", values_to = "Count")

proportions_df <- contingency_df %>%
  mutate(Total = Defective + `Non-Defective`,
         DefectivePct = Defective / Total * 100,
         NonDefectivePct = `Non-Defective` / Total * 100)

proportions_long <- proportions_df %>%
  select(Process, DefectivePct, NonDefectivePct) %>%
  tidyr::pivot_longer(cols = c(DefectivePct, NonDefectivePct), 
                     names_to = "Status", values_to = "Percentage") %>%
  mutate(Status = ifelse(Status == "DefectivePct", "Defective", "Non-Defective"))

# Create CI data for plotting
ci_data <- data.frame(
  Process = c("Standard Process", "New Process", "Difference"),
  Mean = c(defect_rate_standard, defect_rate_new, defect_rate_standard - defect_rate_new),

# 1. Defect rate comparison bar chart
p1 <- ggplot(defect_rates, aes(x = Process, y = DefectRate, fill = Process)) +
