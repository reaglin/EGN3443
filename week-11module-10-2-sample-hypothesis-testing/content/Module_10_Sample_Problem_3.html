Module 10 Sample Problem 3

Problem Statement

An aerospace engineering company is developing a new composite material for aircraft structural components. The durability of these components is critical for flight safety. Two manufacturing processes (Process A and Process B) are being evaluated. Engineers want to determine if one process produces more consistent results than the other.

Engineers subject samples from both processes to standardized stress tests, measuring the number of cycles until failure. They need to determine if there's a significant difference in the variability of durability between the two processes.

Sample Data

  • Process A: 30 samples tested with failure cycles measured
  • Process B: 30 samples tested with failure cycles measured

    This problem will generate data from Python using the following
    process_a = np.random.normal(loc=5000, scale=250, size=30)
    process_b = np.random.normal(loc=4800, scale=400, size=30) 

Analysis Approach

  1. F-test for variance comparison - Appropriate because:
    • We're specifically interested in variability/consistency
    • We have two independent samples
    • We want to test if population variances are equal
    • The data is approximately normally distributed
  2. Hypotheses:
    • H₀: σ²ᴀ = σ²ʙ (The variances of the two processes are equal)
    • H₁: σ²ᴀ ≠ σ²ʙ (The variances of the two processes are different)
  3. Significance level: α = 0.05

Detailed Analysis of the Results

Statistical Findings

Based on the executed code, here's the analysis of our aerospace material durability comparison:

  1. Descriptive Statistics:
    • Process A: Mean ≈ 5000 cycles, SD ≈ 250 cycles
    • Process B: Mean ≈ 4800 cycles, SD ≈ 400 cycles
    • Initial observation shows Process B has higher variance
  2. F-test Results:
    • The F-test statistic is approximately 0.39 (ratio of Process A variance to Process B variance)
    • p-value < 0.05 (significant)
    • We reject the null hypothesis that the variances are equal
    • Process B has significantly higher variance than Process A
  3. Normality Check:
    • QQ plots show both processes follow approximately normal distributions
    • The normality assumption for the F-test is reasonably met
  4. Engineering Significance:
    • Process A has a coefficient of variation (CV) of approximately 5%
    • Process B has a CV of approximately 8.3%
    • Process A provides more consistent results relative to its mean

Appropriateness of F-test for This Application

The F-test was an appropriate choice for this engineering problem for several reasons:

  1. Focus on Variability: In aerospace manufacturing, consistency is crucial for safety. The F-test directly addresses whether one process produces more consistent results than another.
  2. Assumptions Met:
    • Both samples are independent
    • Data from both processes are approximately normally distributed (verified through QQ plots)
    • Sample sizes are equal (30 each), giving balanced statistical power
  3. Engineering Context:
    • In aerospace manufacturing, lower variability often takes precedence over higher mean values
    • The F-test allows engineers to quantify and compare this critical quality characteristic
  4. Statistical Power: With 30 samples per process, the test has sufficient power to detect meaningful differences in variance.

Engineering Implications

  1. Quality Control: Process A demonstrates significantly lower variability, which is crucial for aerospace components where consistent performance is essential for safety.
  2. Manufacturing Decision: Despite Process B potentially achieving higher durability in some cases (as shown in the distribution's tail), Process A's consistency makes it more suitable for safety-critical components.
  3. Risk Assessment: The higher variability in Process B indicates greater unpredictability in component performance, representing an increased risk factor.
  4. Economic Considerations: More consistent manufacturing processes typically result in:
    • Lower scrap rates
    • Reduced quality control costs
    • Fewer field failures and warranty claims
    • Better predictability in maintenance scheduling

Limitations and Considerations

  1. Alternative Tests: While the F-test is appropriate, we also included Levene's test which is more robust to minor departures from normality.
  2. Sample Size: While 30 samples per process is sufficient, larger samples would provide even more reliable estimates of variability.
  3. Practical Significance: Statistical significance doesn't always equal practical significance. Engineers should determine if the observed difference in variability has meaningful implications for component reliability.
  4. Further Investigation: If Process B has a higher mean durability, engineers might investigate whether modifications to Process B could reduce its variability while maintaining its higher average performance.

Conclusion

Based on the F-test analysis, Process A demonstrates significantly lower variability in durability cycles compared to Process B. In aerospace applications, this consistency is critical for safety and reliability. Therefore, Process A would be the recommended manufacturing process for these components, as it provides more predictable performance characteristics.

The statistical methodology was appropriate for this engineering application, and both Python and R implementations provided consistent results with comprehensive visualizations to support the engineering decision-making process.

# Perform F-test for variance comparison
f_value = np.var(process_a, ddof=1) / np.var(process_b, ddof=1)
dfn, dfd = len(process_a) - 1, len(process_b) - 1  # Degrees of freedom

# Calculate p-value (two-tailed test)
if f_value > 1:
    p_value = 2 * (1 - stats.f.cdf(f_value, dfn, dfd))
else:
    p_value = 2 * stats.f.cdf(f_value, dfn, dfd)

# Alternative calculation using scipy.stats directly
f_stat, p_value_scipy = stats.levene(process_a, process_b)

print("\nF-test Results:")
print(f"F-value: {f_value:.4f}")
print(f"Degrees of freedom: ({dfn}, {dfd})")
print(f"P-value: {p_value:.4f}")
print(f"Significance level: 0.05")

# Interpretation
alpha = 0.05
print("\nInterpretation:")
if p_value < alpha:
    print(f"The p-value ({p_value:.4f}) is less than the significance level ({alpha}).")
    print("Reject the null hypothesis.")
    print("There is a statistically significant difference in the variances between Process A and Process B.")
    if np.var(process_a, ddof=1) > np.var(process_b, ddof=1):
        print("Process A has significantly higher variance than Process B.")
    else:
        print("Process B has significantly higher variance than Process A.")
else:
    print(f"The p-value ({p_value:.4f}) is greater than the significance level ({alpha}).")
    print("Fail to reject the null hypothesis.")
    print("There is no statistically significant difference in the variances between Process A and Process B.")

# Compute confidence intervals for the ratio of variances
f_critical_upper = stats.f.ppf(1 - alpha/2, dfn, dfd)
f_critical_lower = stats.f.ppf(alpha/2, dfn, dfd)

ratio = np.var(process_a, ddof=1) / np.var(process_b, ddof=1)
ci_lower = ratio / f_critical_upper
ci_upper = ratio / f_critical_lower

print("\nConfidence Interval for the Ratio of Variances (Process A / Process B):")
print(f"95% CI: ({ci_lower:.4f}, {ci_upper:.4f})")

# Power analysis
def power_analysis(var_ratio, n1, n2, alpha=0.05, num_simulations=10000):
    """Simulate the power of the F-test for detecting a difference in variances."""
    reject_count = 0
    
    for _ in range(num_simulations):
        # Generate samples under the alternative hypothesis
        sample1 = np.random.normal(0, 1, size=n1)
        sample2 = np.random.normal(0, np.sqrt(var_ratio), size=n2)
        
        # Calculate F-statistic
        f_value = np.var(sample1, ddof=1) / np.var(sample2, ddof=1)
        
        # Calculate p-value
        if f_value > 1:
            p_value = 2 * (1 - stats.f.cdf(f_value, n1-1, n2-1))
        else:
            p_value = 2 * stats.f.cdf(f_value, n1-1, n2-1)
        
        if p_value < alpha:
            reject_count += 1
    
    return reject_count / num_simulations

# True ratio of variances in our data
true_ratio = np.var(process_a, ddof=1) / np.var(process_b, ddof=1)
power = power_analysis(true_ratio, len(process_a), len(process_b))

print("\nPower Analysis:")
print(f"Estimated power for detecting the observed ratio of variances: {power:.4f}")
print("(Power is the probability of correctly rejecting the null hypothesis when it is false)")

# Engineering significance
print("\nEngineering Significance:")
print(f"Coefficient of Variation (CV) for Process A: {np.std(process_a, ddof=1)/np.mean(process_a)*100:.2f}%")
print(f"Coefficient of Variation (CV) for Process B: {np.std(process_b, ddof=1)/np.mean(process_b)*100:.2f}%")

if np.std(process_a, ddof=1)/np.mean(process_a) < np.std(process_b, ddof=1)/np.mean(process_b):
    print("Process A provides more consistent results relative to its mean.")
else:
    print("Process B provides more consistent results relative to its mean.")

# Power analysis function
power_f_test <- function(var_ratio, n1, n2, alpha = 0.05, num_simulations = 10000) {
  reject_count <- 0
  
  for (i in 1:num_simulations) {
    # Generate samples under the alternative hypothesis
    sample1 <- rnorm(n1, 0, 1)
    sample2 <- rnorm(n2, 0, sqrt(var_ratio))
    
    # Perform F-test
    f_test_result <- var.test(sample1, sample2)
    
    if (f_test_result$p.value < alpha) {
      reject_count <- reject_count + 1
    }
  }
  
  return(reject_count / num_simulations)
}
