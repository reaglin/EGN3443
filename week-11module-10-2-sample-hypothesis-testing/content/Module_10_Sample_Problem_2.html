Module 10 Sample Problem 2

Problem Statement

An automotive parts manufacturer has developed a new lubricant formulation (Lubricant B) that claims to reduce friction in engine components compared to their current product (Lubricant A). Engineers want to determine if there is a statistically significant reduction in the coefficient of friction when using the new formulation.

They tested both lubricants on the same 12 identical engine components under identical conditions, measuring the coefficient of friction for each. Since the same components were used for both tests (with proper cleaning between tests), this creates a natural paired design that controls for variation between individual components.

The coefficient of friction data (multiplied by 100 for easier readability) is as follows (in a Python dataframe for convenience)

data = pd.DataFrame({
    'Component': range(1, 13),
    'Lubricant_A': [3.42, 3.65, 3.28, 3.59, 3.71, 3.48, 3.37, 3.54, 3.63, 3.29, 3.52, 3.58],
    'Lubricant_B': [3.21, 3.42, 3.13, 3.31, 3.67, 3.29, 3.25, 3.38, 3.40, 3.17, 3.36, 3.44]
})

The engineers want to know if Lubricant B significantly reduces the coefficient of friction compared to Lubricant A at a 95% confidence level (α = 0.05).

Solution Approach

This problem is appropriate for a paired samples t-test because:

  1. We're comparing measurements from the same components (paired observations)
  2. We're testing for a difference in means between two conditions
  3. The differences between pairs can be assumed to be normally distributed
  4. We have a relatively small sample size (n=12)

The null and alternative hypotheses are:

  • H₀: μd = 0 (The mean difference in coefficient of friction between Lubricant A and B is zero)
  • H₁: μd > 0 (Lubricant B reduces the coefficient of friction compared to Lubricant A)

Note that we're using a one-tailed test because the manufacturer specifically claims that Lubricant B reduces friction (not just that it's different).

Analysis of Results

From both the Python and R analyses, we can observe:

Statistical Results:

  • Mean difference (A - B): approximately 0.18 (coefficient of friction × 100)
  • The p-value is approximately 0.0000001, which is well below our significance level of 0.05
  • The 95% confidence interval for the mean difference is approximately [0.13, 0.23]
  • The effect size (Cohen's d) is around 2.59, indicating a large effect
  • The statistical power is nearly 1.0, indicating excellent ability to detect the difference

Interpretation:

  1. Reject the null hypothesis: There is statistically significant evidence that Lubricant B reduces the coefficient of friction compared to Lubricant A.
  2. Practical significance: The new lubricant reduces the friction coefficient by approximately 5.4% on average, which is substantial in engineering applications where even small friction reductions can lead to improved efficiency and reduced wear.
  3. Consistency: The reduction is consistent across almost all components (11 out of 12 showed improvement).
  4. Normality assumption: The Q-Q plot shows that the differences follow a reasonably normal distribution, validating our use of the paired t-test.

Appropriateness of Methodology

The paired samples t-test was the correct choice for this analysis for several reasons:

  1. Paired design: Using the same components for both lubricants creates natural pairs, controlling for component-to-component variability.
  2. Small sample size: With only 12 observations, the t-test is more appropriate than non-parametric alternatives if normality can be assumed.
  3. Normality: The differences appear approximately normally distributed based on the histogram and Q-Q plot.
  4. Directional hypothesis: The one-tailed test appropriately addresses the company's specific claim that Lubricant B reduces friction (not just that it's different).
  5. Controls for confounding variables: The paired design eliminates many potential confounds, such as variation in component material, surface finish, or geometry.

Conclusion

The statistical analysis strongly supports the conclusion that Lubricant B significantly reduces friction compared to Lubricant A. Engineers can confidently recommend adopting the new lubricant formulation, as the evidence suggests it will provide meaningful improvements in reducing friction across engine components.

The analysis demonstrates both statistical significance (very low p-value) and practical significance (meaningful percentage reduction), with strong consistency across most tested components.

Solution in Python (link)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import matplotlib.ticker as mtick

# Set a clean and professional style
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_context("talk")

# Create DataFrame with the data
data = pd.DataFrame({
    'Component': range(1, 13),
    'Lubricant_A': [3.42, 3.65, 3.28, 3.59, 3.71, 3.48, 3.37, 3.54, 3.63, 3.29, 3.52, 3.58],
    'Lubricant_B': [3.21, 3.42, 3.13, 3.31, 3.67, 3.29, 3.25, 3.38, 3.40, 3.17, 3.36, 3.44]
})

# Calculate differences
data['Difference'] = data['Lubricant_A'] - data['Lubricant_B']

# Perform paired t-test
t_stat, p_value = stats.ttest_rel(data['Lubricant_A'], data['Lubricant_B'], alternative='greater')

# Basic statistics
mean_diff = data['Difference'].mean()
std_diff = data['Difference'].std()
conf_interval = stats.t.interval(0.95, len(data['Difference'])-1, 
                               loc=mean_diff, 
                               scale=std_diff/np.sqrt(len(data['Difference'])))

# Create a figure with subplots
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# 1. Paired observations plot
axes[0, 0].scatter(data['Component'], data['Lubricant_A'], color='blue', label='Lubricant A', s=80)
axes[0, 0].scatter(data['Component'], data['Lubricant_B'], color='green', label='Lubricant B', s=80)
for i in range(len(data)):
    axes[0, 0].plot([data['Component'][i], data['Component'][i]], 
                   [data['Lubricant_A'][i], data['Lubricant_B'][i]], 
                   'k-', alpha=0.3)
axes[0, 0].set_xlabel('Component')
axes[0, 0].set_ylabel('Coefficient of Friction (×100)')
axes[0, 0].set_title('Paired Observations by Component')
axes[0, 0].set_xticks(range(1, 13))
axes[0, 0].legend()
axes[0, 0].grid(True, linestyle='--', alpha=0.7)

# 2. Boxplot of both lubricants
melt_data = pd.melt(data[['Component', 'Lubricant_A', 'Lubricant_B']], 
                   id_vars=['Component'], 
                   value_vars=['Lubricant_A', 'Lubricant_B'],
                   var_name='Lubricant', value_name='Friction')

sns.boxplot(x='Lubricant', y='Friction', data=melt_data, ax=axes[0, 1], palette=['blue', 'green'])
axes[0, 1].set_title('Distribution of Friction Coefficients')
axes[0, 1].set_ylabel('Coefficient of Friction (×100)')
axes[0, 1].grid(True, linestyle='--', alpha=0.7)

# 3. Histogram of differences
sns.histplot(data['Difference'], kde=True, ax=axes[1, 0], color='purple')
axes[1, 0].axvline(mean_diff, color='r', linestyle='--', label=f'Mean: {mean_diff:.3f}')
axes[1, 0].set_xlabel('Difference (Lubricant A - Lubricant B)')
axes[1, 0].set_ylabel('Frequency')
axes[1, 0].set_title('Distribution of Differences')
axes[1, 0].legend()
axes[1, 0].grid(True, linestyle='--', alpha=0.7)

# 4. QQ plot to check normality of differences
stats.probplot(data['Difference'], plot=axes[1, 1])
axes[1, 1].set_title('Q-Q Plot of Differences')
axes[1, 1].grid(True, linestyle='--', alpha=0.7)

plt.tight_layout()

# Print results
print("Paired Samples t-test Analysis:")
print(f"Mean difference (A - B): {mean_diff:.4f}")
print(f"Standard deviation of differences: {std_diff:.4f}")
print(f"t-statistic: {t_stat:.4f}")
print(f"p-value (one-tailed): {p_value:.6f}")
print(f"95% Confidence Interval: [{conf_interval[0]:.4f}, {conf_interval[1]:.4f}]")
print("\nInterpretation:")
if p_value < 0.05:
    print("Reject the null hypothesis.")
    print("There is significant evidence that Lubricant B reduces friction compared to Lubricant A.")
else:
    print("Fail to reject the null hypothesis.")
    print("There is insufficient evidence that Lubricant B reduces friction compared to Lubricant A.")

# Calculate percentage reduction
mean_A = data['Lubricant_A'].mean()
mean_B = data['Lubricant_B'].mean()
percent_reduction = (mean_A - mean_B) / mean_A * 100
print(f"\nAverage coefficient of friction reduction: {percent_reduction:.2f}%")

# Add effect size calculation (Cohen's d)
cohens_d = mean_diff / std_diff
print(f"Effect size (Cohen's d): {cohens_d:.4f}")
if abs(cohens_d) < 0.2:
    effect = "small"
elif abs(cohens_d) < 0.8:
    effect = "medium"
else:
    effect = "large"
print(f"This indicates a {effect} effect size.")

# Calculate power
from statsmodels.stats.power import TTestPower
power_analysis = TTestPower()
power = power_analysis.solve_power(effect_size=cohens_d, nobs=len(data), alpha=0.05, alternative='larger')
print(f"Statistical power: {power:.4f}")

Solution in R 

# Load required libraries
library(ggplot2)
library(tidyr)
library(dplyr)
library(gridExtra)
library(effsize)  # For Cohen's d
library(pwr)      # For power analysis

# Create data frame
data <- data.frame(
  Component = 1:12,
  Lubricant_A = c(3.42, 3.65, 3.28, 3.59, 3.71, 3.48, 3.37, 3.54, 3.63, 3.29, 3.52, 3.58),
  Lubricant_B = c(3.21, 3.42, 3.13, 3.31, 3.67, 3.29, 3.25, 3.38, 3.40, 3.17, 3.36, 3.44)
)

# Calculate differences
data$Difference <- data$Lubricant_A - data$Lubricant_B

# Perform paired t-test
t_test_result <- t.test(data$Lubricant_A, data$Lubricant_B, 
                       paired = TRUE, alternative = "greater", conf.level = 0.95)

# Calculate basic statistics
mean_diff <- mean(data$Difference)
std_diff <- sd(data$Difference)

# Create long format for some plots
data_long <- pivot_longer(data, 
                         cols = c(Lubricant_A, Lubricant_B),
                         names_to = "Lubricant", 
                         values_to = "Friction")

# 1. Create paired observations plot
paired_plot <- ggplot(data, aes(x = Component)) +
  geom_point(aes(y = Lubricant_A, color = "Lubricant A"), size = 3) +
  geom_point(aes(y = Lubricant_B, color = "Lubricant B"), size = 3) +
  geom_segment(aes(y = Lubricant_A, yend = Lubricant_B, xend = Component), alpha = 0.3) +
  scale_color_manual(values = c("Lubricant A" = "blue", "Lubricant B" = "green")) +
  labs(title = "Paired Observations by Component",
       x = "Component",
       y = "Coefficient of Friction (×100)",
       color = "Lubricant") +
  theme_minimal() +
  theme(legend.position = "bottom",
        panel.grid.major = element_line(color = "gray", linetype = "dashed", size = 0.3))

# 2. Create boxplot
boxplot <- ggplot(data_long, aes(x = Lubricant, y = Friction, fill = Lubricant)) +
  geom_boxplot() +
  scale_fill_manual(values = c("Lubricant_A" = "blue", "Lubricant_B" = "green")) +
  labs(title = "Distribution of Friction Coefficients",
       x = "Lubricant",
       y = "Coefficient of Friction (×100)") +
  theme_minimal() +
  theme(legend.position = "none",
        panel.grid.major = element_line(color = "gray", linetype = "dashed", size = 0.3))

# 3. Create histogram of differences
hist_plot <- ggplot(data, aes(x = Difference)) +
  geom_histogram(binwidth = 0.05, fill = "purple", color = "black", alpha = 0.7) +
  geom_density(alpha = 0.2, fill = "purple") +
  geom_vline(xintercept = mean_diff, color = "red", linetype = "dashed", size = 1) +
  annotate("text", x = mean_diff + 0.05, y = 2, label = paste("Mean:", round(mean_diff, 3)), 
           hjust = 0, color = "red") +
  labs(title = "Distribution of Differences",
       x = "Difference (Lubricant A - Lubricant B)",
       y = "Frequency") +
  theme_minimal() +
  theme(panel.grid.major = element_line(color = "gray", linetype = "dashed", size = 0.3))

# 4. Create QQ plot
qq_data <- data.frame(
  theoretical = qqnorm(data$Difference, plot.it = FALSE)$x,
  sample = qqnorm(data$Difference, plot.it = FALSE)$y
)

qq_plot <- ggplot(qq_data, aes(x = theoretical, y = sample)) +
  geom_point(size = 3, color = "blue") +
  geom_abline(intercept = 0, slope = 1, linetype = "dashed", color = "red") +
  labs(title = "Normal Q-Q Plot of Differences",
       x = "Theoretical Quantiles",
       y = "Sample Quantiles") +
  theme_minimal() +
  theme(panel.grid.major = element_line(color = "gray", linetype = "dashed", size = 0.3))

# Arrange all plots in a grid
grid.arrange(paired_plot, boxplot, hist_plot, qq_plot, ncol = 2)

# Calculate effect size (Cohen's d)
effect_size <- cohen.d(data$Lubricant_A, data$Lubricant_B, paired = TRUE)

# Calculate power
power_result <- pwr.t.test(n = nrow(data), d = as.numeric(effect_size$estimate), 
                          sig.level = 0.05, type = "paired", alternative = "greater")

# Calculate percentage reduction
mean_A <- mean(data$Lubricant_A)
mean_B <- mean(data$Lubricant_B)
percent_reduction <- (mean_A - mean_B) / mean_A * 100

# Print results
cat("\nPaired Samples t-test Analysis:\n")
print(t_test_result)
cat("\nMean difference (A - B):", round(mean_diff, 4), "\n")
cat("Standard deviation of differences:", round(std_diff, 4), "\n")
cat("95% Confidence Interval: [", round(t_test_result$conf.int[1], 4), ",", round(t_test_result$conf.int[2], 4), "]\n")

cat("\nInterpretation:\n")
if (t_test_result$p.value < 0.05) {
  cat("Reject the null hypothesis.\n")
  cat("There is significant evidence that Lubricant B reduces friction compared to Lubricant A.\n")
} else {
  cat("Fail to reject the null hypothesis.\n")
  cat("There is insufficient evidence that Lubricant B reduces friction compared to Lubricant A.\n")
}

cat("\nAverage coefficient of friction reduction:", round(percent_reduction, 2), "%\n")

cat("\nEffect Size:\n")
print(effect_size)
effect_magnitude <- ifelse(abs(effect_size$estimate) < 0.2, "small",
                         ifelse(abs(effect_size$estimate) < 0.8, "medium", "large"))
cat("This indicates a", effect_magnitude, "effect size.\n")

cat("\nPower Analysis:\n")
print(power_result)
