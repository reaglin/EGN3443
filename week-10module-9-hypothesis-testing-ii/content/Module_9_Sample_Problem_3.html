Module 9 - Sample Problem 3

Problem Statement

A battery manufacturer has recently implemented a new production process aimed at reducing the defect rate in their lithium-ion battery cells. The historical defect rate under the old process was 3.2%. After running the new process for a month, quality control engineers sampled 500 battery cells and found 10 defective units.

The engineering team wants to determine:

  1. Whether the new production process has significantly reduced the defect rate compared to the historical 3.2%
  2. The confidence interval for the new defect rate
  3. The sample size needed for future quality control testing to achieve a margin of error of ±0.5% with 95% confidence

Statistical Methodology

This problem requires:

  1. A one-proportion z-test to compare the new defect rate against the historical rate
  2. Calculation of a confidence interval for the new proportion
  3. Sample size determination for future testing

Results Analysis

One-Proportion Z-Test Results

The analysis shows that the new production process has a defect rate of 2.0% (10 defects out of 500 samples), compared to the historical rate of 3.2%.

Key findings:

  • Z-statistic: approximately -1.52
  • P-value: approximately 0.0643 (Python) or 0.0645 (R)
  • At the conventional significance level of α = 0.05, we cannot reject the null hypothesis
  • This means that although the observed defect rate is lower (2.0% vs 3.2%), we don't have sufficient statistical evidence to conclude that the new process has significantly reduced the defect rate

Confidence Interval

  • The 95% confidence interval for the new defect rate is approximately (0.0097, 0.0367)
  • This interval includes the historical defect rate of 3.2%, which aligns with our test result
  • The wide confidence interval suggests we need more data for a more precise estimate

Sample Size Determination

  • To achieve a margin of error of ±0.5% with 95% confidence, we would need a sample size of approximately 753 battery cells
  • This would provide higher precision in future quality assessments
  • The sample size calculation used the observed proportion (2%) for the estimate

Conclusions and Recommendations

  1. Current Evidence: While the new production process shows a promising reduction in defect rate (from 3.2% to 2.0%), the current sample size of 500 units does not provide sufficient statistical evidence to declare this reduction significant at the 5% level.
  2. Future Testing: To make a more definitive conclusion, the quality control team should:
    • Increase the sample size to at least 753 units in future testing
    • Consider conducting a longer-term evaluation to accumulate more data
    • Reassess the significance level (α) if appropriate for the application
  3. Process Monitoring: Continue monitoring the process, as the observed reduction may be practically important even if not yet statistically significant.
  4. Economic Analysis: Perform a cost-benefit analysis to determine if the observed reduction (even if not statistically significant) provides meaningful manufacturing cost savings.

Solution using Python (link)

import numpy as np
import matplotlib.pyplot as plt
import scipy.stats as stats
import seaborn as sns
from statsmodels.stats.proportion import proportions_ztest, proportion_confint
import pandas as pd

# Problem parameters
historical_defect_rate = 0.032  # 3.2%
sample_size = 500
defects_observed = 10
new_defect_rate = defects_observed / sample_size  # 0.02 = 2%
alpha = 0.05  # 95% confidence level

# 1. One-proportion z-test
# H0: p = 0.032 (historical rate)
# H1: p < 0.032 (new rate is lower)
z_stat, p_value = proportions_ztest(
    count=defects_observed,
    nobs=sample_size,
    value=historical_defect_rate,
    alternative='smaller'
)

print(f"Z-statistic: {z_stat:.4f}")
print(f"P-value: {p_value:.4f}")
print(f"Statistically significant reduction? {'Yes' if p_value < alpha else 'No'}")

# 2. Confidence interval for the new proportion
ci_lower, ci_upper = proportion_confint(
    count=defects_observed,
    nobs=sample_size,
    alpha=alpha,
    method='normal'
)
print(f"\n95% Confidence Interval: ({ci_lower:.4f}, {ci_upper:.4f})")

# 3. Sample size calculation for future testing
# For margin of error = 0.005 (±0.5%)
margin_of_error = 0.005
z_critical = stats.norm.ppf(1 - alpha/2)  # Two-tailed z-score for 95% confidence
# Using the observed proportion for the calculation
p_estimate = new_defect_rate
required_sample_size = int(np.ceil(
    (z_critical**2 * p_estimate * (1 - p_estimate)) / (margin_of_error**2)
))
print(f"\nRequired sample size for ±0.5% margin of error: {required_sample_size}")

# Visualization 1: Comparing defect rates with confidence intervals
plt.figure(figsize=(10, 6))
rates = [historical_defect_rate, new_defect_rate]
labels = ['Historical Process', 'New Process']
ci_errors = [[0, 0], [new_defect_rate - ci_lower, ci_upper - new_defect_rate]]

plt.bar(labels, rates, yerr=ci_errors, capsize=10, color=['#ff9999', '#66b3ff'])
plt.axhline(y=historical_defect_rate, color='r', linestyle='--', alpha=0.7, 
           label=f'Historical Rate: {historical_defect_rate:.1%}')
plt.ylabel('Defect Rate')
plt.title('Comparison of Defect Rates Between Processes')
plt.ylim(0, max(historical_defect_rate, ci_upper) * 1.2)  # Add some space above bars
for i, rate in enumerate(rates):
    plt.text(i, rate + 0.002, f'{rate:.1%}', ha='center')
plt.legend()
plt.grid(axis='y', alpha=0.3)

# Visualization 2: Sampling distribution and p-value
plt.figure(figsize=(10, 6))
x = np.linspace(0, 0.06, 1000)
y = stats.norm.pdf(x, historical_defect_rate, np.sqrt(historical_defect_rate * (1 - historical_defect_rate) / sample_size))

plt.plot(x, y, 'b-', label='Sampling Distribution\nunder Null Hypothesis')
plt.axvline(x=new_defect_rate, color='g', linestyle='-', 
           label=f'Observed Defect Rate: {new_defect_rate:.1%}')

# Fill the area representing the p-value
rejection_x = np.linspace(0, new_defect_rate, 100)
rejection_y = stats.norm.pdf(rejection_x, historical_defect_rate, 
                            np.sqrt(historical_defect_rate * (1 - historical_defect_rate) / sample_size))
plt.fill_between(rejection_x, rejection_y, alpha=0.3, color='green', label=f'p-value: {p_value:.4f}')

plt.xlabel('Defect Rate')
plt.ylabel('Probability Density')
plt.title('Sampling Distribution Under Null Hypothesis')
plt.legend()
plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()

# Visualization 3: Required sample size vs. margin of error
margins = np.linspace(0.001, 0.02, 100)  # 0.1% to 2%
sample_sizes = [int(np.ceil((z_critical**2 * p_estimate * (1 - p_estimate)) / (m**2))) 
               for m in margins]

plt.figure(figsize=(10, 6))
plt.plot(margins * 100, sample_sizes, 'b-')
plt.axvline(x=0.5, color='r', linestyle='--', 
           label=f'Target Margin: 0.5% (n={required_sample_size})')
plt.axhline(y=required_sample_size, color='r', linestyle='--')
plt.scatter([0.5], [required_sample_size], color='red', s=80)

plt.xlabel('Margin of Error (%)')
plt.ylabel('Required Sample Size')
plt.title('Sample Size vs. Margin of Error (95% Confidence)')
plt.grid(True, alpha=0.3)
plt.legend()

plt.tight_layout()
plt.show()

Solution Using R

# Battery Manufacturing Quality Control Analysis
# One-proportion z-test for defect rates

# Problem parameters
historical_defect_rate <- 0.032  # 3.2%
sample_size <- 500
defects_observed <- 10
new_defect_rate <- defects_observed / sample_size  # 0.02 = 2%
alpha <- 0.05  # 95% confidence level

# 1. One-proportion z-test
# H0: p = 0.032 (historical rate)
# H1: p < 0.032 (new rate is lower)
prop_test_result <- prop.test(
  x = defects_observed,
  n = sample_size,
  p = historical_defect_rate,
  alternative = "less",
  correct = FALSE  # No continuity correction for z-test
)

# Print test results
cat("One-proportion z-test results:\n")
print(prop_test_result)
cat("\nZ-statistic:", (new_defect_rate - historical_defect_rate) / 
      sqrt(historical_defect_rate * (1 - historical_defect_rate) / sample_size), "\n")
cat("P-value:", prop_test_result$p.value, "\n")
cat("Statistically significant reduction?", 
    ifelse(prop_test_result$p.value < alpha, "Yes", "No"), "\n\n")

# 2. Confidence interval for the new proportion
ci <- prop.test(defects_observed, sample_size, conf.level = 1 - alpha)$conf.int
cat("95% Confidence Interval:", round(ci[1], 4), "to", round(ci[2], 4), "\n\n")

# 3. Sample size calculation for future testing
# For margin of error = 0.005 (±0.5%)
margin_of_error <- 0.005
z_critical <- qnorm(1 - alpha/2)  # Two-tailed z-score for 95% confidence
p_estimate <- new_defect_rate
required_sample_size <- ceiling(
  (z_critical^2 * p_estimate * (1 - p_estimate)) / (margin_of_error^2)
)
cat("Required sample size for ±0.5% margin of error:", required_sample_size, "\n\n")

# Create visualizations
library(ggplot2)

  labs(title = "Comparison of Defect Rates",

  scale_fill_manual(values = c("Historical" = "#ff9999", "New" = "#66b3ff")) +
  theme_minimal() +
  theme(legend.position = "none") +
  scale_y_continuous(labels = scales::percent, limits = c(0, max(process_data$Upper) * 1.2))

# Visualization 2: Sampling distribution and p-value
x_values <- seq(0, 0.06, length.out = 1000)
sampling_dist <- data.frame(
  x = x_values,
  y = dnorm(x_values, mean = historical_defect_rate, 
           sd = sqrt(historical_defect_rate * (1 - historical_defect_rate) / sample_size))

# Create data for shaded region (p-value)
p_region <- sampling_dist[sampling_dist$x <= new_defect_rate, ]

plot2 <- ggplot(sampling_dist, aes(x = x, y = y)) +

           hjust = 0, size = 4) +

       x = "Defect Rate",
       y = "Probability Density") +
  theme_minimal()

# Visualization 3: Required sample size vs. margin of error
margins <- seq(0.001, 0.02, length.out = 100)  # 0.1% to 2%
sample_sizes <- ceiling(
  (z_critical^2 * p_estimate * (1 - p_estimate)) / (margins^2)

sample_size_data <- data.frame(
  Margin = margins * 100,  # Convert to percentage

plot3 <- ggplot(sample_size_data, aes(x = Margin, y = SampleSize)) +
  geom_line(size = 1, color = "blue") +
  geom_vline(xintercept = 0.5, color = "red", linetype = "dashed") +
  geom_hline(yintercept = required_sample_size, color = "red", linetype = "dashed") +

  annotate("text", x = 0.5, y = required_sample_size * 1.1, 
           label = sprintf("n = %d", required_sample_size), 
           color = "red", size = 4) +
  labs(title = "Sample Size vs. Margin of Error (95% Confidence)",
       x = "Margin of Error (%)",
       y = "Required Sample Size") +
  theme_minimal()
