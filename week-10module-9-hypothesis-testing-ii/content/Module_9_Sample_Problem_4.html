Module 9 Sample Problem 4

Problem Statement

An aerospace manufacturing company produces titanium alloy components for aircraft engines. Quality engineers need to ensure that the tensile strength of these components has consistent variance across different manufacturing batches, as excessive variability could lead to safety concerns.

The quality team collected tensile strength measurements (in MPa) from samples of 25 components from each of three manufacturing batches. They want to determine:

  1. If the variance of tensile strength in Batch A is significantly different from a historically accepted variance of 225 MPa²
  2. If the variances of tensile strength across all three batches are homogeneous

Statistical Framework

For these questions, chi-squared tests for variance are appropriate:

  • For comparing a sample variance to a known population variance (Question 1)
  • For testing homogeneity of variances across multiple samples (Question 2)

Analysis and Methodology

Statistical Framework Explanation

Chi-Squared Test for a Single Variance

When comparing a sample variance to a known variance (like our historical reference), we use the chi-squared test statistic:

χ² = (n-1)s²/σ²

Where:

  • n = sample size
  • s² = sample variance
  • σ² = known or reference variance

Under the null hypothesis (H₀: σ² = σ₀²), this statistic follows a chi-squared distribution with n-1 degrees of freedom.

Tests for Homogeneity of Variances (Multiple Samples)

For comparing variances across multiple samples, we implemented:

  1. Bartlett's Test: Tests if k samples have equal variances
    • Sensitive to normality assumptions
    • Appropriate when data is normally distributed
  2. Levene's Test/Fligner-Killeen Test: Alternative tests that are more robust against non-normality

Interpreting the Results

For our aerospace example:

Test 1: Single Variance Test

  • Compares Batch A's variance against the historical standard of 225 MPa²
  • The chi-squared statistic and p-value determine if the difference is statistically significant
  • If p-value < α (typically 0.05), we reject the null hypothesis that the variance equals the historical value

Test 2: Homogeneity of Variances

  • Tests whether all three batches have equal variances
  • A significant result (p-value < α) indicates at least one batch has a different variance
  • This is crucial for production consistency and quality control

Engineering Implications

  1. Safety Considerations: Inconsistent variance could indicate process instability that might compromise the structural integrity of aerospace components
  2. Manufacturing Process Control:
    • Higher than expected variance → process may need tighter controls
    • Lower than expected variance → potentially improved process stability
  3. Decision Framework:
    • If variances are homogeneous → production is consistent across batches
    • If variances differ → need to investigate specific batches and root causes

Visualizations Explained

The code generates four key visualizations:

  1. Boxplots: Show the spread and central tendency of each batch
    • Longer boxes indicate greater variability
  2. Density/Histogram Plots: Illustrate the shape of distributions
    • Width of distribution indicates variance
  3. Variance Comparison Chart: Directly compares sample variances to historical reference
    • Visual indicator of which batches exceed acceptable variance
  4. Q-Q Plot: Assesses normality assumption
    • Points following the diagonal line suggest normally distributed data
    • Important for validating the chi-squared test assumptions

Methodological Considerations

  1. Assumptions:
    • Chi-squared tests assume normally distributed data
    • Sample size considerations (n=25 per batch is generally adequate)
  2. Two-Tailed vs. One-Tailed Tests:
    • Two-tailed tests detect variance that's either higher or lower than reference
    • One-tailed tests might be appropriate if only concerned about excessive variance

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import scipy.stats as stats
import seaborn as sns

# Set random seed for reproducibility
np.random.seed(42)

# Generate sample data for three batches
# Batch A - slightly higher variance than historical
batch_A = np.random.normal(loc=950, scale=18, size=25)
# Batch B - similar variance to historical
batch_B = np.random.normal(loc=945, scale=15, size=25)
# Batch C - significantly higher variance
batch_C = np.random.normal(loc=955, scale=22, size=25)

# Create a DataFrame for better analysis
df = pd.DataFrame({
    'Batch A': batch_A,
    'Batch B': batch_B,
    'Batch C': batch_C
})

# Calculate basic statistics
stats_summary = pd.DataFrame({
    'Mean': [batch_A.mean(), batch_B.mean(), batch_C.mean()],
    'Variance': [batch_A.var(), batch_B.var(), batch_C.var()],
    'Std Dev': [batch_A.std(), batch_B.std(), batch_C.std()]
}, index=['Batch A', 'Batch B', 'Batch C'])

print("Summary Statistics:")
print(stats_summary)

# Test 1: Compare Batch A variance to historical variance
def chi_squared_variance_test(data, pop_var):
    n = len(data)
    sample_var = np.var(data, ddof=1)
    chi_stat = (n - 1) * sample_var / pop_var
    p_val_lower = stats.chi2.cdf(chi_stat, n - 1)
    p_val_upper = 1 - p_val_lower
    p_val_two_sided = 2 * min(p_val_lower, p_val_upper)
    
    return {
        'n': n,
        'sample_variance': sample_var,
        'population_variance': pop_var,
        'chi_squared_statistic': chi_stat,
        'degrees_of_freedom': n - 1,
        'p_value_lower_tail': p_val_lower,
        'p_value_upper_tail': p_val_upper,
        'p_value_two_sided': p_val_two_sided
    }

# Historical variance value
historical_variance = 225

# Perform chi-squared test for Batch A vs historical variance
print("\nTest 1: Chi-squared test for Batch A variance vs historical variance")
chi_squared_result = chi_squared_variance_test(batch_A, historical_variance)

for key, value in chi_squared_result.items():
    print(f"{key}: {value}")

# Interpretation
alpha = 0.05
if chi_squared_result['p_value_two_sided'] < alpha:
    print(f"\nAt α = {alpha}, we reject the null hypothesis.")
    print("The variance of Batch A is significantly different from the historical variance.")
else:
    print(f"\nAt α = {alpha}, we fail to reject the null hypothesis.")
    print("There is no significant evidence that the variance of Batch A differs from the historical variance.")

# Test 2: Homogeneity of variances across all three batches (Bartlett's test)
bartlett_stat, bartlett_pval = stats.bartlett(batch_A, batch_B, batch_C)

print("\nTest 2: Bartlett's test for homogeneity of variances")
print(f"Bartlett's statistic: {bartlett_stat}")
print(f"p-value: {bartlett_pval}")

if bartlett_pval < alpha:
    print(f"\nAt α = {alpha}, we reject the null hypothesis.")
    print("The variances across the three batches are not homogeneous.")
else:
    print(f"\nAt α = {alpha}, we fail to reject the null hypothesis.")
    print("There is no significant evidence that the variances differ across the three batches.")

# Alternative test: Levene's test (more robust against non-normality)
levene_stat, levene_pval = stats.levene(batch_A, batch_B, batch_C)

print("\nAdditional Test: Levene's test for homogeneity of variances")
print(f"Levene's statistic: {levene_stat}")
print(f"p-value: {levene_pval}")

if levene_pval < alpha:
    print(f"\nAt α = {alpha}, we reject the null hypothesis.")
    print("The variances across the three batches are not homogeneous.")
else:
    print(f"\nAt α = {alpha}, we fail to reject the null hypothesis.")
    print("There is no significant evidence that the variances differ across the three batches.")

# Visualizations
plt.figure(figsize=(12, 8))

# 1. Boxplot to visualize distribution and spread
plt.subplot(2, 2, 1)
sns.boxplot(data=df)
plt.title('Tensile Strength by Batch')
plt.ylabel('Tensile Strength (MPa)')

# 2. Histograms for each batch
plt.subplot(2, 2, 2)
for column in df.columns:
    sns.histplot(df[column], kde=True, stat="density", label=column, alpha=0.4)
plt.title('Distribution of Tensile Strength')
plt.xlabel('Tensile Strength (MPa)')
plt.legend()

# 3. Variance Comparison
plt.subplot(2, 2, 3)
batch_vars = stats_summary['Variance']
plt.bar(batch_vars.index, batch_vars.values)
plt.axhline(y=historical_variance, color='r', linestyle='--', label='Historical Variance')
plt.title('Sample Variances vs Historical Variance')
plt.ylabel('Variance (MPa²)')
plt.legend()

# 4. QQ Plot for Batch A (to check normality assumption)
plt.subplot(2, 2, 4)
stats.probplot(batch_A, dist="norm", plot=plt)
plt.title('Q-Q Plot for Batch A')

plt.tight_layout()
plt.show()

summary_stats <- data.frame(
  Batch = c("Batch A", "Batch B", "Batch C"),
  Mean = c(mean(batch_A), mean(batch_B), mean(batch_C)),
  Variance = c(var(batch_A), var(batch_B), var(batch_C)),
  StdDev = c(sd(batch_A), sd(batch_B), sd(batch_C))
)

# Display summary statistics
print("Summary Statistics:")
print(summary_stats)

# Test 1: Chi-squared test for Batch A variance against historical variance
historical_variance <- 225
n_A <- length(batch_A)
sample_var_A <- var(batch_A)
chi_stat <- (n_A - 1) * sample_var_A / historical_variance
dof <- n_A - 1

# Calculate p-values
p_val_lower <- pchisq(chi_stat, dof)
p_val_upper <- 1 - p_val_lower
p_val_two_sided <- 2 * min(p_val_lower, p_val_upper)

# Display results
cat("\nTest 1: Chi-squared test for Batch A variance vs historical variance\n")
cat("Sample size:", n_A, "\n")
cat("Sample variance:", sample_var_A, "\n")
cat("Historical variance:", historical_variance, "\n")
cat("Chi-squared statistic:", chi_stat, "\n")
cat("Degrees of freedom:", dof, "\n")
cat("p-value (two-sided):", p_val_two_sided, "\n")

# Interpretation
alpha <- 0.05
if (p_val_two_sided < alpha) {

  cat("The variance of Batch A is significantly different from the historical variance.\n")
