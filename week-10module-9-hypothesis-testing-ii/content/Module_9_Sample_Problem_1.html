Module 9 Sample Problem 1

Problem Statement

An automotive parts manufacturer produces piston rings with a target diameter of 74.0 mm. The manufacturing process is known to produce rings with a standard deviation of 0.05 mm. The quality control team randomly samples 36 piston rings from a recent production batch and measures their diameters, finding a sample mean of 74.02 mm.

The engineering team needs to determine if this batch significantly deviates from the target specification (74.0 mm). They decide to use a Z test with a significance level of α = 0.05 to make this determination.

Statistical Hypothesis

  • Null hypothesis (H₀): μ = 74.0 mm (the mean diameter equals the target specification)
  • Alternative hypothesis (H₁): μ ≠ 74.0 mm (the mean diameter differs from the target specification)

Results Analysis

Let's analyze the results from our hypothesis test:

Statistical Results

  • Z-score: 2.4000
  • p-value: 0.0164
  • Critical Z value (α=0.05): ±1.9600
  • 95% Confidence Interval: [74.0033, 74.0367] mm
  • Effect size (Cohen's d): 0.4000

Interpretation

  1. Hypothesis Test Decision: Since |Z| = 2.4 > 1.96 (critical value) and p-value = 0.0164 < 0.05 (significance level), we reject the null hypothesis. This means there is statistically significant evidence that the mean piston ring diameter differs from the target specification of 74.0 mm.
  2. Confidence Interval: The 95% confidence interval (74.0033 mm to 74.0367 mm) does not include the target value of 74.0 mm, confirming our decision to reject the null hypothesis.
  3. Effect Size: Cohen's d = 0.4 indicates a medium practical significance. While statistically significant, the actual difference (0.02 mm) represents 0.4 standard deviations, which may or may not be practically important in the context of the application.

Engineering Implications

Even though the test detects a statistically significant difference, the engineering team must consider:

  1. Practical Significance: Is a 0.02 mm deviation from specification practically important for the function of the piston rings?
  2. Production Consequences: Should production parameters be adjusted, or is this deviation within acceptable tolerance limits?
  3. Quality Control: Does this finding suggest a systematic drift in the production process that needs correction?

Methodology Analysis

Z Test Appropriateness

The Z test was appropriate for this problem because:

  1. Known Population Standard Deviation: We knew σ = 0.05 mm from historical data or process specifications.
  2. Adequate Sample Size: n = 36 is sufficiently large for the Central Limit Theorem to apply.
  3. Measurement Scale: The data is continuous and measured on a ratio scale.
  4. Distribution Assumption: We assumed the piston ring diameters follow a normal distribution, which is reasonable for manufacturing processes.

Limitations

  1. Population Standard Deviation: The Z test assumes we know the true population standard deviation. If this value is estimated or outdated, results could be misleading.
  2. Normality: If the actual distribution of piston ring diameters is not normal, the Z test might not be appropriate, especially with smaller sample sizes.
  3. Power Analysis: The analysis does not include a power calculation to determine the probability of detecting a specific deviation if it exists.

Conclusion

The quality control team has statistical evidence that the recent batch of piston rings has a mean diameter (74.02 mm) that deviates from the target specification (74.0 mm). While statistically significant, engineering judgment is required to determine if this 0.02 mm difference warrants process adjustments or if it falls within acceptable operational tolerances.

This example illustrates how the Z test can be applied in engineering quality control to make data-driven decisions about manufacturing processes. Both the Python and R implementations provide comprehensive analysis tools and visualizations to help engineering teams interpret statistical results in practical contexts.

Solution in Python (link) 

import numpy as np
import matplotlib.pyplot as plt
import scipy.stats as stats
from matplotlib.patches import Polygon

# Problem parameters
target_mean = 74.0    # Target diameter (mm)
sample_mean = 74.02   # Observed sample mean (mm)
known_std = 0.05      # Known standard deviation (mm)
sample_size = 36      # Sample size

# Calculate Z statistic
z_score = (sample_mean - target_mean) / (known_std / np.sqrt(sample_size))
print(f"Z score: {z_score:.4f}")

# Calculate p-value (two-tailed test)
p_value = 2 * (1 - stats.norm.cdf(abs(z_score)))
print(f"P-value: {p_value:.4f}")

# Critical values for alpha = 0.05 (two-tailed)
critical_z = stats.norm.ppf(1 - 0.05/2)
print(f"Critical Z value (two-tailed, alpha=0.05): ±{critical_z:.4f}")

# Decision
alpha = 0.05
if p_value < alpha:
    decision = "Reject the null hypothesis"
    conclusion = "The batch significantly deviates from the target specification."
else:
    decision = "Fail to reject the null hypothesis"
    conclusion = "There is not enough evidence to conclude that the batch deviates from the target specification."

print(f"Decision: {decision}")
print(f"Conclusion: {conclusion}")

# Visualization
plt.figure(figsize=(12, 6))

# Normal distribution curve
x = np.linspace(-4, 4, 1000)
y = stats.norm.pdf(x, 0, 1)
plt.plot(x, y, 'b-', linewidth=2, label='Standard Normal Distribution')

# Fill rejection regions
x_fill_right = np.linspace(critical_z, 4, 100)
y_fill_right = stats.norm.pdf(x_fill_right, 0, 1)
plt.fill_between(x_fill_right, y_fill_right, alpha=0.3, color='red')

x_fill_left = np.linspace(-4, -critical_z, 100)
y_fill_left = stats.norm.pdf(x_fill_left, 0, 1)
plt.fill_between(x_fill_left, y_fill_left, alpha=0.3, color='red', label='Rejection Region (α=0.05)')

# Mark Z score
plt.axvline(x=z_score, color='green', linestyle='--', linewidth=2, label=f'Observed Z={z_score:.4f}')
plt.axvline(x=critical_z, color='red', linestyle=':', linewidth=1.5, label=f'Critical Z=±{critical_z:.4f}')
plt.axvline(x=-critical_z, color='red', linestyle=':', linewidth=1.5)

plt.title('Z Test Analysis for Piston Ring Diameters', fontsize=15)
plt.xlabel('Z Score', fontsize=12)
plt.ylabel('Probability Density', fontsize=12)
plt.grid(True, alpha=0.3)
plt.legend()

# Add annotations
plt.annotate(f'p-value (two-tailed): {p_value:.4f}', xy=(0.02, 0.12), xycoords='axes fraction', fontsize=12)
plt.annotate(f'Decision: {decision}', xy=(0.02, 0.08), xycoords='axes fraction', fontsize=12)
plt.tight_layout()

# Create a second plot showing the actual measurements distribution
plt.figure(figsize=(10, 5))

# Simulate the data based on sample statistics
np.random.seed(42)  # For reproducibility
simulated_data = np.random.normal(sample_mean, known_std, size=1000)

plt.hist(simulated_data, bins=30, alpha=0.7, color='skyblue', edgecolor='black')
plt.axvline(x=target_mean, color='red', linestyle='-', linewidth=2, label=f'Target Spec: {target_mean} mm')
plt.axvline(x=sample_mean, color='green', linestyle='--', linewidth=2, label=f'Sample Mean: {sample_mean} mm')

# Add confidence interval
margin_error = critical_z * (known_std / np.sqrt(sample_size))
ci_lower = sample_mean - margin_error
ci_upper = sample_mean + margin_error
plt.axvspan(ci_lower, ci_upper, alpha=0.2, color='green', label=f'95% CI: [{ci_lower:.3f}, {ci_upper:.3f}]')

plt.title('Distribution of Piston Ring Diameters', fontsize=15)
plt.xlabel('Diameter (mm)', fontsize=12)
plt.ylabel('Frequency', fontsize=12)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()

plt.show()

# Print confidence interval
print(f"95% Confidence Interval: [{ci_lower:.4f}, {ci_upper:.4f}] mm")

# Calculate effect size (standardized mean difference)
effect_size = (sample_mean - target_mean) / known_std
print(f"Effect size (Cohen's d): {effect_size:.4f}")

Solution in R

# Z-test implementation in R for the piston ring problem

# Problem parameters
target_mean <- 74.0   # Target diameter (mm)
sample_mean <- 74.02  # Observed sample mean (mm)
known_std <- 0.05     # Known standard deviation (mm)
sample_size <- 36     # Sample size
alpha <- 0.05         # Significance level

# Calculate Z statistic
z_score <- (sample_mean - target_mean) / (known_std / sqrt(sample_size))
cat("Z score:", round(z_score, 4), "\n")

# Calculate p-value (two-tailed test)
p_value <- 2 * (1 - pnorm(abs(z_score)))
cat("P-value:", round(p_value, 4), "\n")

# Critical values for alpha = 0.05 (two-tailed)
critical_z <- qnorm(1 - alpha/2)
cat("Critical Z value (two-tailed, alpha=0.05): ±", round(critical_z, 4), "\n")

# Decision
if (p_value < alpha) {
  decision <- "Reject the null hypothesis"
  conclusion <- "The batch significantly deviates from the target specification."
} else {
  decision <- "Fail to reject the null hypothesis"
  conclusion <- "There is not enough evidence to conclude that the batch deviates from the target specification."
}

cat("Decision:", decision, "\n")
cat("Conclusion:", conclusion, "\n")

# Calculate confidence interval
margin_error <- critical_z * (known_std / sqrt(sample_size))
ci_lower <- sample_mean - margin_error
ci_upper <- sample_mean + margin_error
cat("95% Confidence Interval:", round(ci_lower, 4), "to", round(ci_upper, 4), "mm\n")

# Calculate effect size (Cohen's d)
effect_size <- (sample_mean - target_mean) / known_std
cat("Effect size (Cohen's d):", round(effect_size, 4), "\n")

# Create visualizations
library(ggplot2)

# Visualization 1: Standard normal distribution with rejection regions
z_values <- seq(-4, 4, length.out = 1000)
norm_density <- dnorm(z_values)

normal_dist_df <- data.frame(z = z_values, density = norm_density)

# Create the plot
p1 <- ggplot(normal_dist_df, aes(x = z, y = density)) +
  geom_line(size = 1, color = "blue") +
  
  # Add rejection regions
  geom_area(data = subset(normal_dist_df, z <= -critical_z), 
            aes(x = z, y = density), fill = "red", alpha = 0.3) +
  geom_area(data = subset(normal_dist_df, z >= critical_z), 
            aes(x = z, y = density), fill = "red", alpha = 0.3) +
  
  # Add vertical lines
  geom_vline(xintercept = z_score, color = "green", linetype = "dashed", size = 1) +
  geom_vline(xintercept = c(-critical_z, critical_z), color = "red", linetype = "dotted", size = 1) +
  
  # Labels and annotations
  labs(title = "Z Test Analysis for Piston Ring Diameters",
       x = "Z Score",
       y = "Probability Density") +
  annotate("text", x = z_score, y = 0.05, label = paste("Z =", round(z_score, 4)), color = "green", vjust = -1) +
  annotate("text", x = critical_z, y = 0.05, label = paste("Critical Z =", round(critical_z, 4)), color = "red", vjust = -1) +
  annotate("text", x = -2, y = 0.3, label = paste("p-value =", round(p_value, 4)), size = 4) +
  annotate("text", x = -2, y = 0.25, label = decision, size = 4) +
  theme_minimal() +
  theme(panel.grid.minor = element_blank(),
        plot.title = element_text(size = 16, face = "bold"),
        axis.title = element_text(size = 12))

print(p1)

# Visualization 2: Simulated data distribution
set.seed(42)  # For reproducibility
simulated_data <- rnorm(1000, mean = sample_mean, sd = known_std)
sim_data_df <- data.frame(diameter = simulated_data)

p2 <- ggplot(sim_data_df, aes(x = diameter)) +
  geom_histogram(bins = 30, fill = "skyblue", color = "black", alpha = 0.7) +
  geom_vline(xintercept = target_mean, color = "red", size = 1) +
  geom_vline(xintercept = sample_mean, color = "green", linetype = "dashed", size = 1) +
  
  # Add confidence interval
  geom_rect(aes(xmin = ci_lower, xmax = ci_upper, ymin = 0, ymax = Inf), 
            fill = "green", alpha = 0.2) +
  
  # Labels and annotations
  labs(title = "Distribution of Piston Ring Diameters",
       x = "Diameter (mm)",
       y = "Frequency") +
  annotate("text", x = target_mean, y = 70, label = paste("Target =", target_mean), color = "red", vjust = -1) +
  annotate("text", x = sample_mean, y = 80, label = paste("Sample Mean =", sample_mean), color = "green", vjust = -1) +
  annotate("text", x = ci_lower + (ci_upper - ci_lower)/2, y = 90, 
           label = paste("95% CI: [", round(ci_lower, 3), ", ", round(ci_upper, 3), "]", sep = ""), 
           color = "darkgreen", vjust = -1) +
  theme_minimal() +
  theme(panel.grid.minor = element_blank(),
        plot.title = element_text(size = 16, face = "bold"),
        axis.title = element_text(size = 12))

print(p2)

# Formal Z-test using BSDA package (if available)
if (requireNamespace("BSDA", quietly = TRUE)) {
  library(BSDA)
  z_test_result <- BSDA::z.test(x = sample_mean, sigma.x = known_std, n.x = sample_size, 
                                mu = target_mean, alternative = "two.sided")
  print(z_test_result)
}
