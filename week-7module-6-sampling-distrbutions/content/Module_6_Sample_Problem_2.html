Problem 2: Electronic Component Lifetime Testing

Problem Statement

An electronics manufacturer is testing the lifetime of a new type of LED. Based on previous models, they expect the lifetime to be normally distributed with a mean of 10,000 hours and a standard deviation of 1,500 hours. The quality control team needs to establish testing protocols to verify the mean lifetime with statistical confidence.

Tasks:

  1. If 16 LEDs are tested to failure, describe the sampling distribution of the sample mean lifetime.

  2. Calculate the standard error for a sample of size n=16.

  3. If a sample of 16 LEDs has a mean lifetime of 9,700 hours, construct a 90% confidence interval for the true mean lifetime.

  4. The product specification requires the mean lifetime to be at least 9,500 hours. Using the sample mean from part 3, can the team be 95% confident that the specification is met?

  5. How many LEDs should be tested to estimate the mean lifetime with a margin of error of ±300 hours at a 95% confidence level?

Solution

1. Sampling Distribution for n=16

Since the original population follows a normal distribution, the sampling distribution of the sample mean will also be normal for any sample size (not just because of the Central Limit Theorem, but because of the properties of normal distributions).

The sampling distribution will have:

  • Mean = population mean = 10,000 hours

  • Standard error = population standard deviation / √n = 1,500 / √16 = 375 hours

2. Standard Error Calculation

Standard Error = σ / √n = 1,500 / √16 = 375 hours

3. 90% Confidence Interval with mean=9,700 hours

For a 90% confidence interval, we use the formula: CI = x̄ ± (z* × SE)

Where:

  • x̄ is the sample mean (9,700 hours)

  • z* is the critical z-value for 90% confidence (1.645)

  • SE is the standard error (375 hours)

CI = 9,700 ± (1.645 × 375) CI = 9,700 ± 617.19 CI = [9,082.81 hours, 10,317.19 hours]

4. 95% Confidence for Meeting Specification

To determine if we can be 95% confident that the mean lifetime is at least 9,500 hours, we need to test whether 9,500 hours is included in the 95% confidence interval.

For a 95% confidence interval: CI = x̄ ± (z* × SE) CI = 9,700 ± (1.96 × 375) CI = 9,700 ± 735 CI = [8,965 hours, 10,435 hours]

Since 9,500 hours is within this interval, we cannot be 95% confident that the mean lifetime exceeds 9,500 hours. The specification might or might not be met.

We can also approach this as a one-sided hypothesis test: H0: μ ≤ 9,500 H1: μ > 9,500

Test statistic: z = (x̄ - μ₀) / SE = (9,700 - 9,500) / 375 = 0.533

For 95% confidence in a one-sided test, the critical z-value is 1.645. Since 0.533 < 1.645, we fail to reject H₀, meaning we cannot be 95% confident that the specification is met.

5. Sample Size Determination

To determine the required sample size for a specific margin of error, we use: n = (z* × σ / E)²

Where:

  • z* is the critical z-value for 95% confidence (1.96)

  • σ is the population standard deviation (1,500 hours)

  • E is the desired margin of error (300 hours)

n = (1.96 × 1,500 / 300)² = (9.8)² = 96.04

The manufacturer should test at least 97 LEDs to achieve the desired precision.

Python Solution (link)

import numpy as np

import matplotlib.pyplot as plt

import scipy.stats as stats

import seaborn as sns

# Set random seed for reproducibility

np.random.seed(43)

# Population parameters

population_mean = 10000

population_std = 1500

# Create a normal distribution

population = np.random.normal(population_mean, population_std, size=100000)

# Function to simulate sampling distribution

def sample_distribution(population, sample_size, n_samples):

    sample_means = []

    for _ in range(n_samples):

        sample = np.random.choice(population, size=sample_size, replace=True)

        sample_means.append(np.mean(sample))

    return np.array(sample_means)

# Calculate sampling distributions

n_samples = 10000

sample_means_16 = sample_distribution(population, 16, n_samples)

# Calculate standard error

se_16 = np.std(sample_means_16)

se_16_theoretical = population_std / np.sqrt(16)

# Calculate 90% confidence interval for n=16 with mean=9700

sample_mean = 9700

z_critical_90 = 1.645

margin_error_90 = z_critical_90 * se_16_theoretical

ci_90_lower = sample_mean - margin_error_90

ci_90_upper = sample_mean + margin_error_90

# Calculate 95% confidence interval

z_critical_95 = 1.96

margin_error_95 = z_critical_95 * se_16_theoretical

ci_95_lower = sample_mean - margin_error_95

ci_95_upper = sample_mean + margin_error_95

# One-sided hypothesis test for specification

spec_limit = 9500

z_score = (sample_mean - spec_limit) / se_16_theoretical

p_value_one_sided = 1 - stats.norm.cdf(z_score)

# Sample size determination

desired_margin = 300

required_n = int(np.ceil((z_critical_95 * population_std / desired_margin) ** 2))

# Visualization

plt.figure(figsize=(18, 12))

# 1. Original Population Distribution

plt.subplot(2, 2, 1)

sns.histplot(population, kde=True, color='skyblue')

plt.axvline(population_mean, color='red', linestyle='--', label=f'Mean = {population_mean}')

plt.title('LED Lifetime Distribution (Normal)')

plt.xlabel('Lifetime (hours)')

plt.ylabel('Frequency')

plt.legend()

# 2. Sampling Distribution (n=16)

plt.subplot(2, 2, 2)

sns.histplot(sample_means_16, kde=True, color='green')

plt.axvline(np.mean(sample_means_16), color='red', linestyle='--', 

            label=f'Mean = {np.mean(sample_means_16):.1f}')

plt.title(f'Sampling Distribution (n=16)\nSE (Observed): {se_16:.1f}, SE (Theoretical): {se_16_theoretical:.1f}')

plt.xlabel('Sample Mean Lifetime (hours)')

plt.ylabel('Frequency')

plt.legend()

# 3. Confidence Intervals Visualization

plt.subplot(2, 2, 3)

x = np.linspace(sample_mean - 4*se_16_theoretical, sample_mean + 4*se_16_theoretical, 1000)

y = stats.norm.pdf(x, sample_mean, se_16_theoretical)

plt.plot(x, y, color='darkblue')

plt.fill_between(x, y, where=(x >= ci_90_lower) & (x <= ci_90_upper), alpha=0.3, color='green')

plt.fill_between(x, y, where=(x >= ci_95_lower) & (x <= ci_95_upper), alpha=0.15, color='blue')

plt.axvline(sample_mean, color='red', linestyle='--', label=f'Sample Mean = {sample_mean}')

plt.axvline(ci_90_lower, color='green', linestyle=':', label=f'90% CI: [{ci_90_lower:.1f}, {ci_90_upper:.1f}]')

plt.axvline(ci_90_upper, color='green', linestyle=':')

plt.axvline(ci_95_lower, color='blue', linestyle='-.', label=f'95% CI: [{ci_95_lower:.1f}, {ci_95_upper:.1f}]')

plt.axvline(ci_95_upper, color='blue', linestyle='-.')

plt.title('90% and 95% Confidence Intervals')

plt.xlabel('LED Lifetime (hours)')

plt.ylabel('Probability Density')

plt.legend()

# 4. Specification Test Visualization

plt.subplot(2, 2, 4)

x_spec = np.linspace(8500, 11000, 1000)

y_spec = stats.norm.pdf(x_spec, sample_mean, se_16_theoretical)

plt.plot(x_spec, y_spec, color='darkblue')

plt.fill_between(x_spec, y_spec, where=(x_spec <= spec_limit), alpha=0.3, color='red')

plt.fill_between(x_spec, y_spec, where=(x_spec > spec_limit), alpha=0.3, color='green')

plt.axvline(sample_mean, color='blue', linestyle='--', label=f'Sample Mean = {sample_mean}')

plt.axvline(spec_limit, color='red', linestyle='-', label=f'Specification: {spec_limit}')

plt.title(f'Testing Specification (μ > 9500)\nz-score = {z_score:.2f}, p-value = {p_value_one_sided:.3f}')

plt.xlabel('LED Lifetime (hours)')

plt.ylabel('Probability Density')

plt.legend()

plt.tight_layout()

plt.show()

print(f"Observed Standard Error (n=16): {se_16:.1f} hours")

print(f"Theoretical Standard Error (n=16): {se_16_theoretical:.1f} hours")

print(f"90% Confidence Interval: [{ci_90_lower:.1f}, {ci_90_upper:.1f}] hours")

print(f"95% Confidence Interval: [{ci_95_lower:.1f}, {ci_95_upper:.1f}] hours")

print(f"One-sided test (μ > 9500): z = {z_score:.2f}, p-value = {p_value_one_sided:.3f}")

if p_value_one_sided < 0.05:

    print("We can be 95% confident that the specification is met.")

else:

    print("We cannot be 95% confident that the specification is met.")

print(f"Required sample size for ±300 hours margin of error: {required_n}")
