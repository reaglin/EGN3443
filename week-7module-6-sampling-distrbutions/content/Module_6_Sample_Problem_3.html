Module 6 Problem 3: Network Latency Monitoring

Problem Statement

A telecommunications engineer is monitoring network latency (ping times) for a critical application. Historical data suggests that the latency is not normally distributed but has a mean of 45 ms and a standard deviation of 12 ms. The engineer needs to establish monitoring thresholds and reporting confidence intervals.

Tasks:

  1. If the engineer collects samples of size n=50 ping times, describe the sampling distribution of the sample mean latency.

  2. Calculate the standard error for a sample of size n=50.

  3. If a sample of 50 ping measurements has a mean of 48 ms, construct a 99% confidence interval for the true mean latency.

  4. The service level agreement (SLA) requires the mean latency to be below 50 ms. Using the sample from part 3, can the engineer be 99% confident that the SLA is being met?

  5. How many ping measurements should be collected to estimate the mean latency with a margin of error of ±2 ms at a 99% confidence level?

Solution

1. Sampling Distribution for n=50

According to the Central Limit Theorem, even though the original population (network latency) is not normally distributed, the sampling distribution of the sample mean will approximately follow a normal distribution when the sample size is sufficiently large. With n=50, we can confidently apply the Central Limit Theorem.

The sampling distribution will have:

  • Mean = population mean = 45 ms

  • Standard error = population standard deviation / √n = 12 / √50 = 1.697 ms

2. Standard Error Calculation

Standard Error = σ / √n = 12 / √50 = 1.697 ms

3. 99% Confidence Interval with mean=48 ms

For a 99% confidence interval, we use the formula: CI = x̄ ± (z* × SE)

Where:

  • x̄ is the sample mean (48 ms)

  • z* is the critical z-value for 99% confidence (2.576)

  • SE is the standard error (1.697 ms)

CI = 48 ± (2.576 × 1.697) CI = 48 ± 4.37 CI = [43.63 ms, 52.37 ms]

4. 99% Confidence for Meeting SLA

To determine if we can be 99% confident that the mean latency is below 50 ms (meeting the SLA), we need to test whether 50 ms is included in the 99% confidence interval.

Since 50 ms is within the 99% confidence interval [43.63 ms, 52.37 ms], we cannot be 99% confident that the SLA requirement (mean latency < 50 ms) is being met.

We can also approach this as a one-sided hypothesis test: H0: μ ≥ 50 ms H1: μ < 50 ms

Test statistic: z = (x̄ - μ₀) / SE = (48 - 50) / 1.697 = -1.18

For 99% confidence in a one-sided test, the critical z-value is -2.326. Since -1.18 > -2.326, we fail to reject H₀, meaning we cannot be 99% confident that the SLA is being met.

5. Sample Size Determination

To determine the required sample size for a specific margin of error, we use: n = (z* × σ / E)²

Where:

  • z* is the critical z-value for 99% confidence (2.576)

  • σ is the population standard deviation (12 ms)

  • E is the desired margin of error (2 ms)

n = (2.576 × 12 / 2)² = (15.456)² = 238.89

The engineer should collect at least 239 ping measurements to achieve the desired precision.

Python Solution (link)

import numpy as np

import matplotlib.pyplot as plt

import scipy.stats as stats

import seaborn as sns

# Set random seed for reproducibility

np.random.seed(44)

# Population parameters

population_mean = 45

population_std = 12

# Create a non-normal distribution (using a right-skewed distribution)

# Using a chi-square distribution shifted to match our mean

df = 10  # Degrees of freedom for chi-square

population = np.random.chisquare(df, size=100000)

# Adjust to match our target parameters

population = population * (population_std / np.std(population))

population = population + (population_mean - np.mean(population))

# Function to simulate sampling distribution

def sample_distribution(population, sample_size, n_samples):

    sample_means = []

    for _ in range(n_samples):

        sample = np.random.choice(population, size=sample_size, replace=True)

        sample_means.append(np.mean(sample))

    return np.array(sample_means)

# Calculate sampling distributions

n_samples = 10000

sample_means_50 = sample_distribution(population, 50, n_samples)

# Calculate standard error

se_50 = np.std(sample_means_50)

se_50_theoretical = population_std / np.sqrt(50)

# Calculate 99% confidence interval for n=50 with mean=48

sample_mean = 48

z_critical_99 = 2.576

margin_error_99 = z_critical_99 * se_50_theoretical

ci_99_lower = sample_mean - margin_error_99

ci_99_upper = sample_mean + margin_error_99

# One-sided hypothesis test for SLA

sla_limit = 50

z_score = (sample_mean - sla_limit) / se_50_theoretical

p_value_one_sided = stats.norm.cdf(z_score)  # One-sided test (lower tail)

# Sample size determination

desired_margin = 2

required_n = int(np.ceil((z_critical_99 * population_std / desired_margin) ** 2))

# Visualization

plt.figure(figsize=(18, 12))

# 1. Original Population Distribution

plt.subplot(2, 2, 1)

sns.histplot(population, kde=True, color='skyblue')

plt.axvline(population_mean, color='red', linestyle='--', label=f'Mean = {population_mean}')

plt.title('Network Latency Distribution (Non-Normal)')

plt.xlabel('Latency (ms)')

plt.ylabel('Frequency')

plt.legend()

# 2. Sampling Distribution (n=50)

plt.subplot(2, 2, 2)

sns.histplot(sample_means_50, kde=True, color='green')

plt.axvline(np.mean(sample_means_50), color='red', linestyle='--', 

            label=f'Mean = {np.mean(sample_means_50):.1f}')

plt.title(f'Sampling Distribution (n=50)\nSE (Observed): {se_50:.3f}, SE (Theoretical): {se_50_theoretical:.3f}')

plt.xlabel('Sample Mean Latency (ms)')

plt.ylabel('Frequency')

plt.legend()

# 3. 99% Confidence Interval

plt.subplot(2, 2, 3)

x = np.linspace(sample_mean - 4*se_50_theoretical, sample_mean + 4*se_50_theoretical, 1000)

y = stats.norm.pdf(x, sample_mean, se_50_theoretical)

plt.plot(x, y, color='darkblue')

plt.fill_between(x, y, where=(x >= ci_99_lower) & (x <= ci_99_upper), alpha=0.3, color='green')

plt.axvline(sample_mean, color='red', linestyle='--', label=f'Sample Mean = {sample_mean}')

plt.axvline(ci_99_lower, color='green', linestyle=':', label=f'99% CI Lower: {ci_99_lower:.2f}')

plt.axvline(ci_99_upper, color='green', linestyle=':', label=f'99% CI Upper: {ci_99_upper:.2f}')

plt.title('99% Confidence Interval')

plt.xlabel('Network Latency (ms)')

plt.ylabel('Probability Density')

plt.legend()

# 4. SLA Test Visualization

plt.subplot(2, 2, 4)

x_sla = np.linspace(40, 55, 1000)

y_sla = stats.norm.pdf(x_sla, sample_mean, se_50_theoretical)

plt.plot(x_sla, y_sla, color='darkblue')

plt.fill_between(x_sla, y_sla, where=(x_sla < sla_limit), alpha=0.3, color='green')

plt.fill_between(x_sla, y_sla, where=(x_sla >= sla_limit), alpha=0.3, color='red')

plt.axvline(sample_mean, color='blue', linestyle='--', label=f'Sample Mean = {sample_mean}')

plt.axvline(sla_limit, color='red', linestyle='-', label=f'SLA Limit: {sla_limit}')

plt.title(f'Testing SLA (μ < 50 ms)\nz-score = {z_score:.2f}, p-value = {p_value_one_sided:.3f}')

plt.xlabel('Network Latency (ms)')

plt.ylabel('Probability Density')

plt.legend()

plt.tight_layout()

plt.show()

print(f"Observed Standard Error (n=50): {se_50:.3f} ms")

print(f"Theoretical Standard Error (n=50): {se_50_theoretical:.3f} ms")

print(f"99% Confidence Interval: [{ci_99_lower:.2f}, {ci_99_upper:.2f}] ms")

print(f"One-sided test (μ < 50 ms): z = {z_score:.2f}, p-value = {p_value_one_sided:.3f}")

if p_value_one_sided < 0.01:

    print("We can be 99% confident that the SLA is being met.")

else:

    print("We cannot be 99% confident that the SLA is being met.")

print(f"Required sample size for ±2 ms margin of error: {required_n}")

R Solution

library(ggplot2)

library(gridExtra)

library(dplyr)

# Set random seed for reproducibility

set.seed(44)

# Population parameters

population_mean <- 45

population_std <- 12

# Create a non-normal distribution (using a right-skewed distribution)

# Using a chi-square distribution shifted to match our mean

df <- 10  # Degrees of freedom for chi-square

population <- rchisq(100000, df=df)

# Adjust to match our target parameters  

population <- population * (population_std / sd(population))

population <- population + (population_mean - mean(population))

# Function to simulate sampling distribution

sample_distribution <- function(population, sample_size, n_samples) {

  sample_means <- numeric(n_samples)

  for (i in 1:n_samples) {

    sample <- sample(population, size=sample_size, replace=TRUE)

    sample_means[i] <- mean(sample)

  }

  return(sample_means)

}

# Calculate sampling distributions

n_samples <- 10000

sample_means_50 <- sample_distribution(population, 50, n_samples)

# Calculate standard error

se_50 <- sd(sample_means_50)

se_50_theoretical <- population_std / sqrt(50)

# Calculate 99% confidence interval for n=50 with mean=48

sample_mean <- 48

z_critical_99 <- 2.576

margin_error_99 <- z_critical_99 * se_50_theoretical

ci_99_lower <- sample_mean - margin_error_99

ci_99_upper <- sample_mean + margin_error_99

# One-sided hypothesis test for SLA

sla_limit <- 50

z_score <- (sample_mean - sla_limit) / se_50_theoretical

p_value_one_sided <- pnorm(z_score)  # One-sided test (lower tail)

# Sample size determination

desired_margin <- 2

required_n <- ceiling((z_critical_99 * population_std / desired_margin)^2)

# Create data frames for plotting

population_df <- data.frame(latency = population)

means_50_df <- data.frame(mean = sample_means_50)

# Visualization

# 1. Original Population Distribution

p1 <- ggplot(population_df, aes(x = latency)) +

  geom_histogram(aes(y=..density..), fill="skyblue", color="black", bins=50) +

  geom_density(alpha=0.2, fill="blue") +

  geom_vline(xintercept = population_mean, color="red", linetype="dashed") +

  annotate("text", x = population_mean + 5, y = 0.04, 

           label = paste("Mean =", population_mean), color="red") +

  labs(title = "Network Latency Distribution (Non-Normal)",

       x = "Latency (ms)", y = "Density") +

  theme_minimal()

# 2. Sampling Distribution (n=50)

p2 <- ggplot(means_50_df, aes(x = mean)) +

  geom_histogram(aes(y=..density..), fill="green", color="black", bins=40) +

  geom_density(alpha=0.2, fill="darkgreen") +

  geom_vline(xintercept = mean(sample_means_50), color="red", linetype="dashed") +

  annotate("text", x = mean(sample_means_50) + 1.5, y = 0.25, 

           label = paste("Mean =", round(mean(sample_means_50), 1)), color="red") +

  labs(title = paste("Sampling Distribution (n=50)\nSE (Observed):", round(se_50, 3), 

                     ", SE (Theoretical):", round(se_50_theoretical, 3)),

       x = "Sample Mean Latency (ms)", y = "Density") +

  theme_minimal()

# 3. 99% Confidence Interval

x_range <- seq(sample_mean - 4*se_50_theoretical, sample_mean + 4*se_50_theoretical, length.out = 1000)

norm_density <- dnorm(x_range, mean = sample_mean, sd = se_50_theoretical)

ci_df <- data.frame(x = x_range, y = norm_density, 

                    in_ci = x_range >= ci_99_lower & x_range <= ci_99_upper)

p3 <- ggplot(ci_df, aes(x = x, y = y)) +

  geom_line(color="darkblue") +

  geom_area(aes(fill = in_ci), alpha=0.3) +

  scale_fill_manual(values = c("white", "green"), guide = "none") +

  geom_vline(xintercept = sample_mean, color="red", linetype="dashed") +

  geom_vline(xintercept = ci_99_lower, color="green", linetype="dotted") +

  geom_vline(xintercept = ci_99_upper, color="green", linetype="dotted") +

  annotate("text", x = sample_mean - 1, y = 0.23, 

           label = paste("Sample Mean =", sample_mean), color="red") +

  annotate("text", x = ci_99_lower - 1, y = 0.18, 

           label = paste("99% CI Lower =", round(ci_99_lower, 2)), color="darkgreen") +

  annotate("text", x = ci_99_upper + 1, y = 0.18, 

           label = paste("99% CI Upper =", round(ci_99_upper, 2)), color="darkgreen") +

  labs(title = "99% Confidence Interval",

       x = "Network Latency (ms)", y = "Probability Density") +

  theme_minimal()

# 4. SLA Test Visualization

x_sla <- seq(40, 55, length.out = 1000)

y_sla <- dnorm(x_sla, mean = sample_mean, sd = se_50_theoretical)

sla_df <- data.frame(x = x_sla, y = y_sla, 

                     meets_sla = x_sla < sla_limit)

p4 <- ggplot(sla_df, aes(x = x, y = y)) +

  geom_line(color="darkblue") +

  geom_area(aes(fill = meets_sla), alpha=0.3) +

  scale_fill_manual(values = c("red", "green"), guide = "none") +

  geom_vline(xintercept = sample_mean, color="blue", linetype="dashed") +

  geom_vline(xintercept = sla_limit, color="red", linetype="solid") +

  annotate("text", x = sample_mean - 1, y = 0.23, 

           label = paste("Sample Mean =", sample_mean), color="blue") +

  annotate("text", x = sla_limit + 1, y = 0.18, 

           label = paste("SLA Limit =", sla_limit), color="red") +

  labs(title = paste("Testing SLA (μ < 50 ms)\nz-score =", round(z_score, 2), 

                     ", p-value =", round(p_value_one_sided, 3)),

       x = "Network Latency (ms)", y = "Probability Density") +

  theme_minimal()

# Arrange all plots

grid.arrange(p1, p2, p3, p4, ncol=2)

cat("Observed Standard Error (n=50):", round(se_50, 3), "ms\n")

cat("Theoretical Standard Error (n=50):", round(se_50_theoretical, 3), "ms\n")

cat("99% Confidence Interval: [", round(ci_99_lower, 2), ",", round(ci_99_upper, 2), "] ms\n")

cat("One-sided test (μ < 50 ms): z =", round(z_score, 2), ", p-value =", round(p_value_one_sided, 3), "\n")

if (p_value_one_sided < 0.01) {

  cat("We can be 99% confident that the SLA is being met.\n")

} else {

  cat("We cannot be 99% confident that the SLA is being met.\n")

}

cat("Required sample size for ±2 ms margin of error:", required_n, "\n")
