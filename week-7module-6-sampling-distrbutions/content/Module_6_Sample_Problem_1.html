Module 6 Sample Problem 1

Problem 1: Material Strength Testing

Problem Statement

A civil engineer is testing the compressive strength of a new concrete mixture for a bridge construction project. Based on previous tests, the compressive strength of this mixture follows a right-skewed distribution with a mean of 4,200 psi and a standard deviation of 350 psi. The engineer needs to estimate the average compressive strength with high precision.

Tasks:

  1. If the engineer takes samples of size n=5, describe the sampling distribution of the sample mean.

  2. If the sample size increases to n=30, how does the sampling distribution change?

  3. Calculate the standard error for both sample sizes.

  4. Determine the 95% confidence interval for the mean compressive strength if a sample of size n=30 yields a mean of 4,150 psi.

  5. How large should the sample size be to estimate the mean compressive strength with a margin of error of ±50 psi at a 95% confidence level?

Solution

1. Sampling Distribution for n=5

According to the Central Limit Theorem (CLT), when we take samples from any population distribution and calculate their means, the distribution of these sample means will approach a normal distribution as the sample size increases. However, with a small sample size of n=5, the sampling distribution will not be perfectly normal since the original distribution is right-skewed.

The sampling distribution of the sample mean will have:

  • Mean = population mean = 4,200 psi

  • Standard error = population standard deviation / √n = 350 / √5 = 156.5 psi

2. Sampling Distribution for n=30

With n=30, the Central Limit Theorem applies more strongly. The sampling distribution of the sample mean will be approximately normal, regardless of the shape of the original distribution.

The sampling distribution will have:

  • Mean = population mean = 4,200 psi

  • Standard error = population standard deviation / √n = 350 / √30 = 63.9 psi

The sampling distribution becomes narrower (smaller standard error) and more closely approximates a normal distribution.

3. Standard Error Calculation

  • For n=5: Standard Error = σ / √n = 350 / √5 = 156.5 psi

  • For n=30: Standard Error = σ / √n = 350 / √30 = 63.9 psi

As the sample size increases, the standard error decreases, indicating more precise estimates of the mean.

4. 95% Confidence Interval for n=30 with mean=4,150 psi

For a 95% confidence interval, we use the formula: CI = x̄ ± (z* × SE)

Where:

  • x̄ is the sample mean (4,150 psi)

  • z* is the critical z-value for 95% confidence (1.96)

  • SE is the standard error (63.9 psi)

CI = 4,150 ± (1.96 × 63.9) CI = 4,150 ± 125.2 CI = [4,024.8 psi, 4,275.2 psi]

5. Sample Size Determination

To determine the required sample size for a specific margin of error, we use: n = (z* × σ / E)²

Where:

  • z* is the critical z-value for 95% confidence (1.96)

  • σ is the population standard deviation (350 psi)

  • E is the desired margin of error (50 psi)

n = (1.96 × 350 / 50)² = (13.72)² = 188.2

The engineer should test at least 189 concrete samples to achieve the desired precision.

Python Solution (link)

import numpy as np

import matplotlib.pyplot as plt

import scipy.stats as stats

import seaborn as sns

# Set random seed for reproducibility

np.random.seed(42)

# Population parameters

population_mean = 4200

population_std = 350

# Create a right-skewed distribution (using gamma distribution as an example)

# Adjusting parameters to match our mean and standard deviation

shape = 144  # Shape parameter for gamma distribution

scale = population_mean / shape  # Scale to get our desired mean

population = np.random.gamma(shape, scale, size=100000)

# Adjust to get closer to our target parameters

population = population * (population_mean / np.mean(population))

population = population * (population_std / np.std(population))

# Function to simulate sampling distribution

def sample_distribution(population, sample_size, n_samples):

    sample_means = []

    for _ in range(n_samples):

        sample = np.random.choice(population, size=sample_size, replace=True)

        sample_means.append(np.mean(sample))

    return np.array(sample_means)

# Calculate sampling distributions

n_samples = 10000

sample_means_5 = sample_distribution(population, 5, n_samples)

sample_means_30 = sample_distribution(population, 30, n_samples)

# Calculate standard errors

se_5 = np.std(sample_means_5)

se_5_theoretical = population_std / np.sqrt(5)

se_30 = np.std(sample_means_30)

se_30_theoretical = population_std / np.sqrt(30)

# Calculate 95% confidence interval for n=30 with mean=4150

sample_mean = 4150

z_critical = 1.96

margin_error = z_critical * se_30_theoretical

ci_lower = sample_mean - margin_error

ci_upper = sample_mean + margin_error

# Sample size determination

desired_margin = 50

required_n = int(np.ceil((z_critical * population_std / desired_margin) ** 2))

# Visualization

plt.figure(figsize=(18, 12))

# 1. Original Population Distribution

plt.subplot(2, 2, 1)

sns.histplot(population, kde=True, color='skyblue')

plt.axvline(population_mean, color='red', linestyle='--', label=f'Mean = {population_mean}')

plt.title('Original Population Distribution (Right-Skewed)')

plt.xlabel('Compressive Strength (psi)')

plt.ylabel('Frequency')

plt.legend()

# 2. Sampling Distribution (n=5)

plt.subplot(2, 2, 2)

sns.histplot(sample_means_5, kde=True, color='green')

plt.axvline(np.mean(sample_means_5), color='red', linestyle='--', 

            label=f'Mean = {np.mean(sample_means_5):.1f}')

plt.title(f'Sampling Distribution (n=5)\nSE (Observed): {se_5:.1f}, SE (Theoretical): {se_5_theoretical:.1f}')

plt.xlabel('Sample Mean Compressive Strength (psi)')

plt.ylabel('Frequency')

plt.legend()

# 3. Sampling Distribution (n=30)

plt.subplot(2, 2, 3)

sns.histplot(sample_means_30, kde=True, color='purple')

plt.axvline(np.mean(sample_means_30), color='red', linestyle='--', 

            label=f'Mean = {np.mean(sample_means_30):.1f}')

plt.title(f'Sampling Distribution (n=30)\nSE (Observed): {se_30:.1f}, SE (Theoretical): {se_30_theoretical:.1f}')

plt.xlabel('Sample Mean Compressive Strength (psi)')

plt.ylabel('Frequency')

plt.legend()

# 4. Confidence Interval Visualization

plt.subplot(2, 2, 4)

x = np.linspace(sample_mean - 4*se_30_theoretical, sample_mean + 4*se_30_theoretical, 1000)

y = stats.norm.pdf(x, sample_mean, se_30_theoretical)

plt.plot(x, y, color='darkblue')

plt.fill_between(x, y, where=(x >= ci_lower) & (x <= ci_upper), alpha=0.3, color='green')

plt.axvline(sample_mean, color='red', linestyle='--', label=f'Sample Mean = {sample_mean}')

plt.axvline(ci_lower, color='green', linestyle=':', label=f'95% CI Lower: {ci_lower:.1f}')

plt.axvline(ci_upper, color='green', linestyle=':', label=f'95% CI Upper: {ci_upper:.1f}')

plt.title(f'95% Confidence Interval (n=30)\nRequired sample size for ±50 psi: {required_n}')

plt.xlabel('Compressive Strength (psi)')

plt.ylabel('Probability Density')

plt.legend()

plt.tight_layout()

plt.show()

print(f"Observed Standard Error (n=5): {se_5:.1f} psi")

print(f"Theoretical Standard Error (n=5): {se_5_theoretical:.1f} psi")

print(f"Observed Standard Error (n=30): {se_30:.1f} psi")

print(f"Theoretical Standard Error (n=30): {se_30_theoretical:.1f} psi")

print(f"95% Confidence Interval (n=30): [{ci_lower:.1f}, {ci_upper:.1f}] psi")

print(f"Required sample size for ±50 psi margin of error: {required_n}")

library(ggplot2)

library(gridExtra)

library(dplyr)

# Set random seed for reproducibility

set.seed(42)

# Population parameters

population_mean <- 4200

population_std <- 350

# Create a right-skewed distribution (using gamma distribution)

# Adjusting parameters to match our mean and standard deviation

shape <- 144  # Shape parameter for gamma distribution

scale <- population_mean / shape  # Scale to get our desired mean

population <- rgamma(100000, shape=shape, scale=scale)

# Adjust to get closer to our target parameters

population <- population * (population_mean / mean(population))

population <- population * (population_std / sd(population))

# Function to simulate sampling distribution

sample_distribution <- function(population, sample_size, n_samples) {

  sample_means <- numeric(n_samples)

  for (i in 1:n_samples) {

    sample <- sample(population, size=sample_size, replace=TRUE)

    sample_means[i] <- mean(sample)

  }

  return(sample_means)

}

# Calculate sampling distributions

n_samples <- 10000

sample_means_5 <- sample_distribution(population, 5, n_samples)

sample_means_30 <- sample_distribution(population, 30, n_samples)

# Calculate standard errors

se_5 <- sd(sample_means_5)

se_5_theoretical <- population_std / sqrt(5)

se_30 <- sd(sample_means_30)

se_30_theoretical <- population_std / sqrt(30)

# Calculate 95% confidence interval for n=30 with mean=4150

sample_mean <- 4150

z_critical <- 1.96

margin_error <- z_critical * se_30_theoretical

ci_lower <- sample_mean - margin_error

ci_upper <- sample_mean + margin_error

# Sample size determination

desired_margin <- 50

required_n <- ceiling((z_critical * population_std / desired_margin)^2)

# Create data frames for plotting

population_df <- data.frame(strength = population)

means_5_df <- data.frame(mean = sample_means_5)

means_30_df <- data.frame(mean = sample_means_30)

# Visualization

# 1. Original Population Distribution

p1 <- ggplot(population_df, aes(x = strength)) +

  geom_histogram(aes(y=..density..), fill="skyblue", color="black", bins=50) +

  geom_density(alpha=0.2, fill="blue") +

  geom_vline(xintercept = population_mean, color="red", linetype="dashed") +

  annotate("text", x = population_mean + 200, y = 0.0015, 

           label = paste("Mean =", population_mean), color="red") +

  labs(title = "Original Population Distribution (Right-Skewed)",

       x = "Compressive Strength (psi)", y = "Density") +

  theme_minimal()

# 2. Sampling Distribution (n=5)

p2 <- ggplot(means_5_df, aes(x = mean)) +

  geom_histogram(aes(y=..density..), fill="green", color="black", bins=40) +

  geom_density(alpha=0.2, fill="darkgreen") +

  geom_vline(xintercept = mean(sample_means_5), color="red", linetype="dashed") +

  annotate("text", x = mean(sample_means_5) + 200, y = 0.003, 

           label = paste("Mean =", round(mean(sample_means_5), 1)), color="red") +

  labs(title = paste("Sampling Distribution (n=5)\nSE (Observed):", round(se_5, 1), 

                     ", SE (Theoretical):", round(se_5_theoretical, 1)),

       x = "Sample Mean Compressive Strength (psi)", y = "Density") +

  theme_minimal()

# 3. Sampling Distribution (n=30)

p3 <- ggplot(means_30_df, aes(x = mean)) +

  geom_histogram(aes(y=..density..), fill="purple", color="black", bins=40) +

  geom_density(alpha=0.2, fill="darkviolet") +

  geom_vline(xintercept = mean(sample_means_30), color="red", linetype="dashed") +

  annotate("text", x = mean(sample_means_30) + 100, y = 0.006, 

           label = paste("Mean =", round(mean(sample_means_30), 1)), color="red") +

  labs(title = paste("Sampling Distribution (n=30)\nSE (Observed):", round(se_30, 1), 

                     ", SE (Theoretical):", round(se_30_theoretical, 1)),

       x = "Sample Mean Compressive Strength (psi)", y = "Density") +

  theme_minimal()

# 4. Confidence Interval Visualization

x_range <- seq(sample_mean - 4*se_30_theoretical, sample_mean + 4*se_30_theoretical, length.out = 1000)

norm_density <- dnorm(x_range, mean = sample_mean, sd = se_30_theoretical)

ci_df <- data.frame(x = x_range, y = norm_density, 

                    in_ci = x_range >= ci_lower & x_range <= ci_upper)

p4 <- ggplot(ci_df, aes(x = x, y = y)) +

  geom_line(color="darkblue") +

  geom_area(aes(fill = in_ci), alpha=0.3) +

  scale_fill_manual(values = c("white", "green"), guide = "none") +

  geom_vline(xintercept = sample_mean, color="red", linetype="dashed") +

  geom_vline(xintercept = ci_lower, color="green", linetype="dotted") +

  geom_vline(xintercept = ci_upper, color="green", linetype="dotted") +

  annotate("text", x = sample_mean - 100, y = 0.006, 

           label = paste("Sample Mean =", sample_mean), color="red") +

  annotate("text", x = ci_lower - 100, y = 0.004, 

           label = paste("Lower CI =", round(ci_lower, 1)), color="darkgreen") +

  annotate("text", x = ci_upper + 100, y = 0.004, 

           label = paste("Upper CI =", round(ci_upper, 1)), color="darkgreen") +

  labs(title = paste("95% Confidence Interval (n=30)\nRequired sample size for ±50 psi:", required_n),

       x = "Compressive Strength (psi)", y = "Probability Density") +

  theme_minimal()
