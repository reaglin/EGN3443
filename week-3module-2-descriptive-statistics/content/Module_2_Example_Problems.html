Basic Statistical Measures Calculation

Dataset

Our dataset: [12, 15, 18, 22, 25, 25, 30, 35, 38, 42]

Manual Calculations

1. Mean Calculation

  • Sum of all values: 12 + 15 + 18 + 22 + 25 + 25 + 30 + 35 + 38 + 42 = 262

  • Number of values: 10

  • Mean = 262 ÷ 10 = 26.2

2. Median Calculation

  • Sorted data: [12, 15, 18, 22, 25, 25, 30, 35, 38, 42]

  • Middle values: 25 and 25

  • Median = (25 + 25) ÷ 2 = 25

3. Mode Calculation

  • Most frequent value: 25 (appears twice)

  • Mode = 25

4. Range Calculation

  • Minimum value: 12

  • Maximum value: 42

  • Range = 42 - 12 = 30

5. Variance Calculation

  • Mean = 26.2

  • Squared differences from mean: (12 - 26.2)² = 200.04 (15 - 26.2)² = 126.44 (18 - 26.2)² = 66.64 (22 - 26.2)² = 17.64 (25 - 26.2)² = 1.44 (25 - 26.2)² = 1.44 (30 - 26.2)² = 14.44 (35 - 26.2)² = 76.84 (38 - 26.2)² = 140.44 (42 - 26.2)² = 247.04

  • Sum of squared differences: 892.36

  • Variance = 892.36 ÷ 10 = 89.236

6. Standard Deviation Calculation

  • Standard Deviation = √Variance

  • Standard Deviation = √89.236 = 9.449

Methods of Plotting Univariate Data

Introduction

Univariate data analysis involves examining the characteristics and distribution of a single variable. Visualization plays a crucial role in understanding the underlying patterns, spread, and central tendencies of a dataset. This guide explores three fundamental methods of plotting univariate data: Stem and Leaf Plot, Box Plot, and Histogram.

1. Stem and Leaf Plot

Description

A stem and leaf plot is a simple yet powerful graphical technique for displaying the distribution of numerical data. It breaks each number into two parts:

  • Stem: The leading digit(s)

  • Leaf: The trailing digit

This method allows for a quick visual representation of data distribution while preserving the original values. It's particularly useful for:

  • Showing the shape of the data distribution

  • Identifying the spread and concentration of values

  • Providing a compact summary of the dataset

Key Characteristics

  • Helps visualize the data's spread

  • Maintains the actual data points

  • Easy to construct manually

  • Works best with small to medium-sized datasets

2. Box Plot (Box and Whisker Plot)

Description

A box plot provides a graphical summary of the distribution of a dataset through its quartiles. It offers insights into:

  • Central tendency (median)

  • Data spread

  • Identification of potential outliers

Components of a Box Plot

  • Box: Represents the interquartile range (IQR)

    • Lower edge: First quartile (Q1)

    • Middle line: Median

    • Upper edge: Third quartile (Q3)

  • Whiskers: Extend to show the rest of the distribution

  • Outliers: Individual points beyond the whiskers

    Note: Many statistics descriptors may include terms you may not fully understand (like quartile). You should become familiar with finding this information, and using AI is a good technique. For example, ask any AI “Define quartile as it refers to a boxplot”. Note that you should always have an AI handy to answer questions as you progress through the statistical analysis of data. 

Key Benefits

  • Compares distributions across different datasets

  • Highlights symmetric vs. skewed distributions

  • Identifies potential outliers quickly

3. Histogram

Description

A histogram represents the distribution of numerical data by dividing the entire range into a series of intervals (bins) and showing the frequency of data points in each interval.

Key Features

  • Shows the shape of the data distribution

  • Reveals:

    • Central tendency

    • Data spread

    • Presence of multiple modes

    • Symmetry or skewness

Advantages

  • Intuitive visualization of data distribution

  • Helps in understanding data density

  • Useful for large datasets

  • Allows for quick identification of distribution patterns

Implementation Example

The following code demonstrates these plotting methods using Python (Matplotlib) and provides a reference R implementation:

# Sample dataset

data = [12, 15, 18, 22, 25, 27, 30, 32, 35, 38, 

        40, 42, 45, 48, 50, 55, 58, 60, 62, 65]

# Python Implementation

import matplotlib.pyplot as plt

import numpy as np

# Custom Stem and Leaf Plot Function

def custom_stem_and_leaf(data):

    sorted_data = sorted(data)

    stems = {}

    for num in sorted_data:

        stem = num // 10

        leaf = num % 10

        if stem not in stems:

            stems[stem] = []

        stems[stem].append(leaf)

    

    print("Stem and Leaf Plot:")

    for stem, leaves in sorted(stems.items()):

        leaves_str = ''.join(map(str, leaves))

        print(f"{stem} | {leaves_str}")

# Visualization

plt.figure(figsize=(10, 4))

plt.subplot(1, 2, 1)

plt.boxplot(data)

plt.title('Box Plot')

plt.ylabel('Values')

plt.subplot(1, 2, 2)

plt.hist(data, bins='auto', edgecolor='black')

plt.title('Histogram')

plt.xlabel('Values')

plt.ylabel('Frequency')

plt.tight_layout()

plt.show()

Conclusion

Each plotting method offers unique insights into univariate data:

  • Stem and Leaf Plot: Detailed view of individual values

  • Box Plot: Distribution and outlier detection

  • Histogram: Overall data distribution and frequency

Choosing the right visualization depends on your specific data analysis goals and the characteristics of your dataset.

Basic Statistical Measures in Quality Control

Let's work with a real example: thickness measurements (in mm) of metal sheets from a manufacturing process

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# Sample data: Metal sheet thickness (mm)

thickness = [5.02, 4.99, 5.05, 5.01, 4.97, 5.03, 5.02, 4.98, 5.04, 5.00,

             5.01, 4.96, 5.02, 5.03, 4.99, 5.01, 5.00, 4.98, 5.02, 5.01]

# Calculate basic statistics

mean_val = np.mean(thickness)
median_val = np.median(thickness)
mode_val = stats.mode(thickness, keepdims=False)[0]
range_val = max(thickness) - min(thickness)
variance_val = np.var(thickness, ddof=1)  # using sample variance
std_dev = np.std(thickness, ddof=1)  # using sample standard deviation

# Print results

print(f"Basic Statistics for Metal Sheet Thickness:")
print(f"Mean: {mean_val:.4f} mm")
print(f"Median: {median_val:.4f} mm")
print(f"Mode: {mode_val:.4f} mm")
print(f"Range: {range_val:.4f} mm")
print(f"Variance: {variance_val:.6f} mm²")
print(f"Standard Deviation: {std_dev:.4f} mm")

# Create a figure with multiple plots

fig = plt.figure(figsize=(14, 10))

# 1. Histogram

plt.subplot(2, 2, 1)

plt.hist(thickness, bins=7, edgecolor='black')

plt.axvline(mean_val, color='r', linestyle='dashed', linewidth=1, label=f'Mean: {mean_val:.4f}')

plt.axvline(median_val, color='g', linestyle='dashed', linewidth=1, label=f'Median: {median_val:.4f}')

plt.title('Histogram of Sheet Thickness')

plt.xlabel('Thickness (mm)')

plt.ylabel('Frequency')

plt.legend()

# 2. Box Plot

plt.subplot(2, 2, 2)

plt.boxplot(thickness, vert=False)

plt.title('Box Plot of Sheet Thickness')

plt.xlabel('Thickness (mm)')

plt.grid(True, linestyle='--', alpha=0.7)

# 3. Stem and Leaf Plot (visualization)

plt.subplot(2, 2, 3)

# Create a manual stem and leaf representation

stems = {}

for value in thickness:

    stem = str(value).split('.')[0]

    leaf = str(value).split('.')[1]

    if stem in stems:

        stems[stem].append(leaf)

    else:

        stems[stem] = [leaf]

# Create a visualization of stem and leaf

stem_leaf_text = "Stem and Leaf Plot\n"

stem_leaf_text += "Stem | Leaf\n"

stem_leaf_text += "----------------\n"

for stem in sorted(stems.keys()):

    stem_leaf_text += f"{stem}   | {' '.join(sorted(stems[stem]))}\n"

    plt.text(0.1, 0.5, stem_leaf_text, fontsize=10, family='monospace')

plt.axis('off')

# 4. Normal Probability Plot to check for normality

plt.subplot(2, 2, 4)

stats.probplot(thickness, plot=plt)

plt.title('Normal Probability Plot')

# Add specification limits (example: 4.95 mm to 5.05 mm)

lower_spec = 4.95

upper_spec = 5.05

# Calculate process capability indices

Cp = (upper_spec - lower_spec) / (6 * std_dev)

Cpk = min((upper_spec - mean_val) / (3 * std_dev), (mean_val - lower_spec) / (3 * std_dev))

# Add capability information

capability_text = f"Process Capability Analysis:\n"

capability_text += f"Specification Limits: {lower_spec} to {upper_spec} mm\n"

capability_text += f"Cp: {Cp:.3f}\n"

capability_text += f"Cpk: {Cpk:.3f}\n"

if Cpk >= 1.33:

    capability_text += "Process is capable (Cpk >= 1.33)"

elif Cpk >= 1.0:

    capability_text += "Process is marginally capable (1.0 <= Cpk < 1.33)"

else:

    capability_text += "Process is not capable (Cpk < 1.0)"

plt.figtext(0.5, 0.01, capability_text, ha='center', fontsize=10, bbox={"facecolor":"lightgray", "alpha":0.5, "pad":5})

plt.tight_layout(rect=[0, 0.05, 1, 0.95])

plt.suptitle('Statistical Analysis of Metal Sheet Thickness', fontsize=16)

plt.subplots_adjust(top=0.9, bottom=0.15)

plt.show()

Interpretation of Statistics in Quality Control

Mean (5.01 mm)

  • Represents the average thickness of all metal sheets

  • Used to center control charts and determine if process is on target

Median (5.01 mm)

  • The middle value when data is arranged in order

  • Less sensitive to outliers than the mean

  • Important when data may contain extreme values

Mode (5.02 mm)

  • Most frequently occurring value

  • Indicates the most common thickness produced

Range (0.09 mm)

  • Difference between maximum and minimum values (5.05 - 4.96)

  • Quick measure of process variation

  • Used in simple control charts (R charts)

Variance (0.000546 mm²)

  • Measures the spread of data points from the mean

  • Critical for understanding process variability

Standard Deviation (0.0234 mm)

  • Square root of variance

  • Same units as the original measurements

  • Foundation for process capability metrics (Cp, Cpk)

  • Used to establish control limits (±3σ)

Process Capability Analysis

With specification limits of 4.95 mm to 5.05 mm:

  • Cp ≈ 0.7: Ratio of specification width to process spread

  • Cpk ≈ 0.6: Accounts for both spread and centering

  • These values suggest the process needs improvement to consistently meet specifications

Visualization Techniques and Their Purpose

Histogram

  • Shows the distribution of thickness measurements

  • Reveals patterns, skewness, and outliers

  • Helps identify if the process follows normal distribution

Box Plot

  • Displays median, quartiles, and potential outliers

  • Provides quick visual summary of data distribution

  • Central box contains middle 50% of data

Stem and Leaf Plot

  • Organizes data to show both distribution shape and actual values

  • Each data point is split into "stem" (4) and "leaf" (96, 97, etc.)

  • Particularly useful for small to medium datasets

Normal Probability Plot

  • Determines if data follows a normal distribution

  • Points on a straight line indicate normally distributed data

  • Critical for validating assumptions for statistical process control

Key Applications of These Statistics

  1. Setting Control Limits: Using mean and standard deviation to establish upper and lower control limits (±3σ)

  2. Process Capability Studies: Determining if a process can meet specifications (using Cp, Cpk)

  3. Root Cause Analysis: Identifying shifts in mean or increases in variability

  4. Acceptance Sampling: Deciding whether to accept or reject a batch based on statistical sampling

In this metal sheet manufacturing example, the statistical analysis reveals that while the process is centered near the target (5.00 mm), the capability indices suggest it may produce some parts outside specification limits. This kind of analysis helps engineers make data-driven decisions about process improvements.
