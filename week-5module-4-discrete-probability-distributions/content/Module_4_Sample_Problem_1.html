1. Random Variables and Probability Mass Functions

Example: Quality Control in Circuit Board Manufacturing

Problem: In circuit board manufacturing, each board has a 5% chance of having a defect. If we inspect 20 boards, what's the probability of finding exactly 2 defective boards?

Solution: This follows a binomial distribution with n=20, p=0.05.

Solution in Python (Link)

import numpy as np

import matplotlib.pyplot as plt

from scipy import stats

# Parameters

n = 20  # number of boards

p = 0.05  # probability of defect

k = 2  # number of defects we're interested in

# Calculate the PMF using the binomial formula

pmf_value = stats.binom.pmf(k=k, n=n, p=p)

print(f"Probability of exactly {k} defective boards: {pmf_value:.4f}")

# Plot the entire PMF

x = np.arange(0, n+1)

pmf = stats.binom.pmf(x, n, p)

plt.figure(figsize=(10, 6))

plt.bar(x, pmf, alpha=0.7)

plt.axvline(x=k, color='red', linestyle='--', alpha=0.7, label=f'k={k}')

plt.xlabel('Number of Defective Boards')

plt.ylabel('Probability')

plt.title('PMF of Defective Circuit Boards')

plt.grid(alpha=0.3)

plt.legend()

plt.xticks(x)

plt.show()

Solution in R

# Parameters

n <- 20  # number of boards

p <- 0.05  # probability of defect

k <- 2  # number of defects we're interested in

# Calculate the PMF using the binomial formula

pmf_value <- dbinom(x=k, size=n, prob=p)

cat("Probability of exactly", k, "defective boards:", round(pmf_value, 4), "\n")

# Plot the entire PMF

x <- 0:n

pmf <- dbinom(x, size=n, prob=p)

# Create the plot

barplot(pmf, names.arg=x, main="PMF of Defective Circuit Boards", 

        xlab="Number of Defective Boards", ylab="Probability",

        col="skyblue", ylim=c(0, max(pmf) * 1.1))

# Add vertical line at k=2

abline(v=2.7, col="red", lwd=2, lty=2)  # Adjusted for barplot offset

text(2.7, max(pmf) * 0.9, "k=2", pos=4, col="red")
