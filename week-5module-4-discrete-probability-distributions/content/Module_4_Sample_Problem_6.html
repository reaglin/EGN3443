6. Combining Multiple Distributions: System Reliability Analysis

Example: Communication System Reliability

Problem: A communication system consists of multiple components with different reliability characteristics:

  • 5 identical transmitters, each with 98% reliability. At least 3 must work.

  • A backbone connection with Poisson-distributed failures (λ = 0.5 failures per month).

  • A power system that has a 99.9% uptime.

Calculate the overall system reliability for a one-month period.

Solution in Python

import numpy as np

import matplotlib.pyplot as plt

from scipy import stats

import math

# Parameters

# Transmitters: Binomial distribution for number of working transmitters

n_transmitters = 5

p_transmitter = 0.98  # reliability of each transmitter

min_working = 3

# Backbone: Poisson distribution for number of failures

lambda_backbone = 0.5  # failures per month

# Power system: Bernoulli distribution for uptime

p_power = 0.999  # reliability

# 1. Calculate probability that at least 3 transmitters work

p_transmitters_ok = stats.binom.sf(min_working-1, n=n_transmitters, p=p_transmitter)

print(f"Probability of at least {min_working} transmitters working: {p_transmitters_ok:.6f}")

# 2. Calculate probability that backbone has zero failures in a month

p_backbone_ok = stats.poisson.pmf(k=0, mu=lambda_backbone)

print(f"Probability of no backbone failures in a month: {p_backbone_ok:.6f}")

# 3. Probability that power system works

p_power_ok = p_power

print(f"Probability of power system working: {p_power_ok:.6f}")

# 4. Overall system reliability (assuming independence)

system_reliability = p_transmitters_ok * p_backbone_ok * p_power_ok

print(f"Overall system reliability for one month: {system_reliability:.6f}")

print(f"Overall system reliability percentage: {system_reliability*100:.4f}%")

# Visualization

plt.subplot(2, 2, 3)

components = ['Transmitters', 'Backbone', 'Power', 'Overall']

for i, v in enumerate(reliabilities):

plt.ylabel('Reliability')

plt.title('System Reliability Breakdown')

plt.ylim(0, 1.05)

# Addition: Monte Carlo simulation to verify result

def simulate_system(num_trials=100000):

    success_count = 0

    

    for _ in range(num_trials):

        # Simulate transmitters

        working_transmitters = np.random.binomial(n=n_transmitters, p=p_transmitter)

        transmitters_ok = working_transmitters >= min_working

        

        # Simulate backbone

        backbone_failures = np.random.poisson(lambda_backbone)

        backbone_ok = backbone_failures == 0

        

        # Simulate power

        power_ok = np.random.random() < p_power

        

        # Check if all components work

        if transmitters_ok and backbone_ok and power_ok:

            success_count += 1

    

    return success_count / num_trials

# Run simulation

simulation_reliability = simulate_system()

print(f"\nMonte Carlo simulation reliability: {simulation_reliability:.6f}")

print(f"Difference from analytical result: {abs(simulation_reliability - system_reliability):.6f}")

plt.tight_layout()

plt.show()

simulate_system <- function(num_trials=100000) {

  success_count <- 0

  

  for (i in 1:num_trials) {

    # Simulate transmitters

    working_transmitters <- rbinom(n=1, size=n_transmitters, prob=p_transmitter)

    transmitters_ok <- working_transmitters >= min_working

    

    # Simulate backbone

    backbone_failures <- rpois(n=1, lambda=lambda_backbone)

    backbone_ok <- backbone_failures == 0

    

    # Simulate power

    power_ok <- runif(1) < p_power

    

    # Check if all components work

    if (transmitters_ok && backbone_ok && power_ok) {

      success_count <- success_count + 1

    }

  }

  

  return(success_count / num_trials)

}
