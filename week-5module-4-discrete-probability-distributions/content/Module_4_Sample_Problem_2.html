2. Expected Value and Variance

Example: Electronic Component Lifetime

Problem: A certain electronic component has a lifetime that follows a discrete distribution. The lifetime (in years) has the following PMF:

  • P(X=1) = 0.1

  • P(X=2) = 0.2

  • P(X=3) = 0.4

  • P(X=4) = 0.2

  • P(X=5) = 0.1

Calculate the expected lifetime and variance. If a system requires 3 of these components in series (system fails if any component fails), what's the expected time until system failure?

Solution in Python (Link)

import numpy as np

import matplotlib.pyplot as plt

# Define the PMF

x_values = np.array([1, 2, 3, 4, 5])

probabilities = np.array([0.1, 0.2, 0.4, 0.2, 0.1])

# Calculate expected value and variance

expected_value = np.sum(x_values * probabilities)

variance = np.sum((x_values - expected_value)**2 * probabilities)

std_dev = np.sqrt(variance)

print(f"Expected component lifetime: {expected_value:.2f} years")

print(f"Variance of lifetime: {variance:.2f} years²")

print(f"Standard deviation: {std_dev:.2f} years")

# For system with components in series, we need to model time until first failure

# This requires survival analysis, but as an approximation, we can simulate it

def simulate_system_failure(n_components=3, n_simulations=100000):

    system_lifetimes = []

    

    for _ in range(n_simulations):

        # Sample lifetimes for each component

        component_lifetimes = np.random.choice(x_values, size=n_components, p=probabilities)

        # System fails when the first component fails

        system_lifetime = np.min(component_lifetimes)

        system_lifetimes.append(system_lifetime)

    

    return np.mean(system_lifetimes), np.var(system_lifetimes)

mean_system_lifetime, var_system_lifetime = simulate_system_failure()

print(f"Expected system lifetime (simulation): {mean_system_lifetime:.2f} years")

print(f"Variance of system lifetime (simulation): {var_system_lifetime:.2f} years²")

# Visualization

plt.figure(figsize=(12, 6))

# Plot the PMF

plt.subplot(1, 2, 1)

plt.bar(x_values, probabilities, width=0.4, alpha=0.7)

plt.axvline(expected_value, color='red', linestyle='--', label=f'E[X] = {expected_value:.2f}')

plt.xlabel('Lifetime (years)')

plt.ylabel('Probability')

plt.title('Component Lifetime PMF')

plt.grid(alpha=0.3)

plt.legend()

# Plot the simulated system lifetime distribution

plt.subplot(1, 2, 2)

simulated_data = np.random.choice(x_values, size=10000, p=probabilities)

system_lifetimes = np.min(np.random.choice(x_values, size=(10000, 3), p=probabilities), axis=1)

plt.hist(system_lifetimes, bins=x_values, alpha=0.7, density=True)

plt.axvline(mean_system_lifetime, color='red', linestyle='--', 

           label=f'E[min(X₁,X₂,X₃)] = {mean_system_lifetime:.2f}')

plt.xlabel('Lifetime (years)')

plt.ylabel('Probability')

plt.title('System Lifetime Distribution')

plt.grid(alpha=0.3)

plt.legend()

plt.tight_layout()

plt.show()

# Analytical solution for expected system lifetime

system_cdf = 1 - (1 - np.cumsum(probabilities))**3

system_pmf = np.diff(np.append(0, system_cdf))

analytical_mean = np.sum(x_values * system_pmf)

print(f"Expected system lifetime (analytical): {analytical_mean:.2f} years")

# Define the PMF

x_values <- c(1, 2, 3, 4, 5)

probabilities <- c(0.1, 0.2, 0.4, 0.2, 0.1)

# Calculate expected value and variance

expected_value <- sum(x_values * probabilities)

variance <- sum((x_values - expected_value)^2 * probabilities)

std_dev <- sqrt(variance)

cat("Expected component lifetime:", round(expected_value, 2), "years\n")

cat("Variance of lifetime:", round(variance, 2), "years²\n")

cat("Standard deviation:", round(std_dev, 2), "years\n")

# For system with components in series, simulate to find expected system lifetime

simulate_system_failure <- function(n_components=3, n_simulations=100000) {

  system_lifetimes <- numeric(n_simulations)

  

  for (i in 1:n_simulations) {

    # Sample lifetimes for each component

    component_lifetimes <- sample(x_values, size=n_components, replace=TRUE, prob=probabilities)

    # System fails when the first component fails

    system_lifetime <- min(component_lifetimes)

    system_lifetimes[i] <- system_lifetime

  }

  

  return(list(mean=mean(system_lifetimes), var=var(system_lifetimes)))

}

simulation_results <- simulate_system_failure()

cat("Expected system lifetime (simulation):", round(simulation_results$mean, 2), "years\n")

cat("Variance of system lifetime (simulation):", round(simulation_results$var, 2), "years²\n")
