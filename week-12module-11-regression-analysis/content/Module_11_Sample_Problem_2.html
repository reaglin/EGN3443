Problem 2: Concrete Strength Prediction

Civil engineers are studying how the water-cement ratio affects the compressive strength of concrete. They prepared test cylinders with varying water-cement ratios and measured the 28-day compressive strength:

Analysis for Problem 2: Concrete Strength

Methodology

  1. Data Collection: Controlled laboratory experiments with different water-cement ratios.
  2. Initial Analysis: Exploratory data analysis revealed a strong negative correlation between water-cement ratio and compressive strength.
  3. Model Building: Applied ordinary least squares regression to quantify this relationship.
  4. Validation: Conducted comprehensive diagnostic tests on model assumptions.

Results Interpretation

  • Regression Equation: Compressive Strength = 72.14 - 76.39 × Water-Cement Ratio
  • Coefficient Interpretation: For each 0.01 increase in water-cement ratio, compressive strength decreases by approximately 0.76 MPa.
  • Goodness of Fit: R² = 0.99, indicating that about 99% of the variation in concrete strength is explained by water-cement ratio.

Statistical Significance

  • p-value: Extremely small (<0.0001), indicating strong statistical significance.
  • F-statistic: Very high value, confirming the overall model significance.
  • Standard Error: Low standard errors for both intercept and slope, indicating high precision.

Diagnostic Tests

  1. Normality: Shapiro-Wilk test p-value > 0.05, indicating residuals follow a normal distribution.
  2. Homoscedasticity: Breusch-Pagan test p-value > 0.05, suggesting constant variance of residuals.
  3. Independence: Durbin-Watson statistic close to 2, indicating no significant autocorrelation.

Key Assumptions

  1. Linearity: The relationship between water-cement ratio and strength is strongly linear within the observed range.
  2. Independence: Test specimens were prepared independently.
  3. Homoscedasticity: Residual plots confirm constant variance.
  4. Normality: QQ plots and statistical tests confirm normal distribution of residuals.

Practical Application

This model enables civil engineers to accurately predict concrete strength based on water-cement ratio. For example, at a water-cement ratio of 0.53, expected strength would be approximately 30.7 MPa with a 95% prediction interval of (29.4 MPa, 32.0 MPa). This precision allows for better quality control in concrete production and more reliable structural design calculations.

Solution in Python (link)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
import statsmodels.api as sm
from statsmodels.stats.stattools import durbin_watson

# Data
wc_ratio = np.array([0.40, 0.42, 0.45, 0.48, 0.50, 0.52, 0.55, 0.58, 0.60, 0.62, 0.65, 0.68])
strength = np.array([38.1, 37.5, 35.2, 33.9, 32.4, 31.0, 28.7, 27.3, 25.8, 24.9, 22.1, 20.5])

# Create DataFrame
data = pd.DataFrame({'Water_Cement_Ratio': wc_ratio, 'Compressive_Strength': strength})

# Exploratory data analysis
print("Data Summary:")
print(data.describe())

# Check correlation
correlation = np.corrcoef(wc_ratio, strength)[0, 1]
print(f"Correlation coefficient: {correlation:.4f}")

# Scatter plot
plt.figure(figsize=(10, 6))
plt.scatter(wc_ratio, strength, color='blue', s=50)
plt.title('Concrete Compressive Strength vs Water-Cement Ratio')
plt.xlabel('Water-Cement Ratio')
plt.ylabel('Compressive Strength (MPa)')
plt.grid(True)

# Fit linear regression using scipy.stats
slope, intercept, r_value, p_value, std_err = stats.linregress(wc_ratio, strength)
r_squared = r_value**2

# Add regression line to plot
x_pred = np.linspace(0.38, 0.70, 100)
y_pred = intercept + slope * x_pred
plt.plot(x_pred, y_pred, 'r-', label=f'y = {intercept:.2f} + ({slope:.2f})x\nR² = {r_squared:.4f}')
plt.legend()

# More comprehensive analysis with statsmodels
X = sm.add_constant(wc_ratio)  # Add constant for intercept
model = sm.OLS(strength, X).fit()
summary = model.summary()

# Get predictions for the actual data points
predictions = model.predict(X)
residuals = strength - predictions

# Residual analysis
plt.figure(figsize=(12, 8))

# Residual plot
plt.subplot(2, 2, 1)
plt.scatter(predictions, residuals, color='green')
plt.axhline(y=0, color='r', linestyle='-')
plt.title('Residuals vs Fitted Values')
plt.xlabel('Fitted Values')
plt.ylabel('Residuals')
plt.grid(True)

# Residuals vs predictor variable
plt.subplot(2, 2, 2)
plt.scatter(wc_ratio, residuals, color='purple')
plt.axhline(y=0, color='r', linestyle='-')
plt.title('Residuals vs Water-Cement Ratio')
plt.xlabel('Water-Cement Ratio')
plt.ylabel('Residuals')
plt.grid(True)

# Histogram of residuals
plt.subplot(2, 2, 3)
plt.hist(residuals, bins=6, color='skyblue', edgecolor='black')
plt.title('Histogram of Residuals')
plt.xlabel('Residual Value')
plt.ylabel('Frequency')
plt.grid(True)

# QQ plot of residuals
plt.subplot(2, 2, 4)
stats.probplot(residuals, dist="norm", plot=plt)
plt.title('Normal Q-Q Plot of Residuals')
plt.grid(True)

plt.tight_layout()

# Tests for assumptions
# Normality test - Shapiro-Wilk
shapiro_test = stats.shapiro(residuals)

# Homoscedasticity test - Breusch-Pagan
bp_test = sm.stats.diagnostic.het_breuschpagan(residuals, model.model.exog)

# Autocorrelation test - Durbin-Watson
dw_stat = durbin_watson(residuals)

# Calculate RMSE, MAE, and MAPE
rmse = np.sqrt(np.mean(residuals**2))
mae = np.mean(np.abs(residuals))
mape = np.mean(np.abs(residuals / strength)) * 100

# Print results
print("\n=== Linear Regression Analysis ===")
print(f"Model: Compressive Strength = {intercept:.4f} + ({slope:.4f}) × Water-Cement Ratio")
print(f"Slope: {slope:.4f}")
print(f"Intercept: {intercept:.4f}")
print(f"R-squared: {r_squared:.4f}")
print(f"Adjusted R-squared: {model.rsquared_adj:.4f}")
print(f"F-statistic: {model.fvalue:.4f}")
print(f"p-value (F-statistic): {model.f_pvalue:.6f}")
print(f"Standard Error: {std_err:.4f}")
print("\n=== Statistical Summary ===")
print(summary)

print("\n=== Model Diagnostics ===")
print(f"Shapiro-Wilk Test for Normality: W={shapiro_test[0]:.4f}, p-value={shapiro_test[1]:.4f}")
print(f"Breusch-Pagan Test for Heteroscedasticity: LM stat={bp_test[0]:.4f}, p-value={bp_test[1]:.4f}")
print(f"Durbin-Watson Test for Autocorrelation: DW={dw_stat:.4f}")

print("\n=== Model Performance Metrics ===")
print(f"RMSE: {rmse:.4f}")
print(f"MAE: {mae:.4f}")
print(f"MAPE: {mape:.4f}%")

# Prediction for new data
new_wc_ratio = 0.53
predicted_strength = intercept + slope * new_wc_ratio

# Calculate 95% prediction interval
t_critical = stats.t.ppf(0.975, len(wc_ratio) - 2)
MSE = np.sum(residuals**2) / (len(wc_ratio) - 2)
se_pred = np.sqrt(MSE * (1 + 1/len(wc_ratio) + 
                         (new_wc_ratio - np.mean(wc_ratio))**2 / 
                         np.sum((wc_ratio - np.mean(wc_ratio))**2)))
lower_pi = predicted_strength - t_critical * se_pred
upper_pi = predicted_strength + t_critical * se_pred

print("\n=== Prediction ===")
print(f"Predicted strength at water-cement ratio {new_wc_ratio}: {predicted_strength:.2f} MPa")
print(f"95% Prediction Interval: ({lower_pi:.2f} MPa, {upper_pi:.2f} MPa)")

# Confidence interval for the model parameters
conf_int = model.conf_int(alpha=0.05)
print("\n=== 95% Confidence Intervals for Parameters ===")
print(f"Intercept: ({conf_int[0][0]:.4f}, {conf_int[0][1]:.4f})")
print(f"Slope: ({conf_int[1][0]:.4f}, {conf_int[1][1]:.4f})")

# Create final visualization with prediction intervals
plt.figure(figsize=(10, 6))
plt.scatter(wc_ratio, strength, color='blue', label='Observed Data')
plt.plot(x_pred, y_pred, 'r-', label=f'Regression Line: y = {intercept:.2f} + ({slope:.2f})x')

# Add prediction intervals
y_pred_all = intercept + slope * wc_ratio
se_fit = np.sqrt(MSE * (1/len(wc_ratio) + 
                        (wc_ratio - np.mean(wc_ratio))**2 / 
                        np.sum((wc_ratio - np.mean(wc_ratio))**2)))
lower_pi_all = y_pred_all - t_critical * np.sqrt(MSE + se_fit**2)
upper_pi_all = y_pred_all + t_critical * np.sqrt(MSE + se_fit**2)

plt.fill_between(wc_ratio, lower_pi_all, upper_pi_all, color='lightgray', alpha=0.5, label='95% Prediction Interval')

plt.title('Concrete Compressive Strength vs Water-Cement Ratio')
plt.xlabel('Water-Cement Ratio')
plt.ylabel('Compressive Strength (MPa)')
plt.grid(True)
plt.legend()
plt.tight_layout()
