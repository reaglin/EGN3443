EGN3443 — Probability & Statistics for Engineers

Week 12 / Module 11 — Regression Analysis

This module introduces the core concepts of regression analysis as applied in engineering contexts. Topics include simple linear regression, the least squares method, model interpretation, and multiple regression models. Use the resources below to review lecture content, complete practice exercises, and submit your graded work.
