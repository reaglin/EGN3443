All Assignments will be submitted as report in report format.  You can copy/paste the format from below or use your own design. 

Title (you may center)

Name
Date
Submitted for/to

Introduction

Brief introduction - a single sentence is sufficient. Example: This report is submitted to fulfill the requirements of EGN3443 assignment #3

Problem Statement

This can usually be a copy paste of the problem statement from the assignments. You only need the core of the problem (do not copy items like outcomes or grading policy)

Methodology

How are you approaching and solving the problem. You do not need equations necessarily, but you should state what statistical method or decisions are being made and why.

Conclusions

What do you conclude? Make sure you answer what is asked in the problem statement. This may include plots of if these are part of the conclusions. 

References

You may be asked to refer to sources for some problems; only include if this is part of the problem statement. 

Appendices

Code goes here and any hand calculations or other items that assist from going from the metholodogy to the conclusions.
