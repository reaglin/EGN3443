Module 3 Sample Problem 3

3. Bayes' Theorem: Structural Health Monitoring

This problem applies Bayes' theorem to determine the conditional probability of actual bridge damage given a positive sensor reading.

Key formula: P(D|+) = [P(+|D) × P(D)] / P(+)

Solution: Despite high sensor sensitivity (98%), the actual probability of damage given a positive reading is only about 14.27% due to the low prior probability of damage (0.5%) and the effect of false positives.

Python Solution (link)

# ======================================================================
# 3. Bayes' Theorem: Structural Health Monitoring
# ======================================================================
print("Problem 3: Bayes' Theorem - Structural Health Monitoring")
print("------------------------------------------------------")

"""
Problem:
A bridge monitoring system uses sensors to detect potential structural damage.
From historical data, we know:
- The prior probability of structural damage is P(D) = 0.005 (0.5%)
- If there is damage, the probability that the sensor will detect it is P(+|D) = 0.98 (sensitivity)
- If there is no damage, the probability that the sensor will falsely indicate damage 
  is P(+|not D) = 0.03 (false positive rate)

If the sensor gives a positive reading, what is the probability that the bridge 
actually has structural damage?
"""

# Python solution using Bayes' theorem
P_D = 0.005  # Prior probability of damage
P_pos_given_D = 0.98  # Sensitivity (true positive rate)
P_pos_given_notD = 0.03  # False positive rate

# Calculate P(+) = P(+|D) × P(D) + P(+|not D) × P(not D)
P_not_D = 1 - P_D
P_pos = P_pos_given_D * P_D + P_pos_given_notD * P_not_D

# Apply Bayes' theorem: P(D|+) = P(+|D) × P(D) / P(+)
P_damage_given_pos = (P_pos_given_D * P_D) / P_pos

print(f"Prior probability of damage: {P_D}")
print(f"Sensor sensitivity (true positive rate): {P_pos_given_D}")
print(f"Sensor false positive rate: {P_pos_given_notD}")
print(f"Probability of a positive sensor reading: {P_pos:.4f}")
print(f"Probability of actual damage given a positive sensor reading: {P_damage_given_pos:.4f} or {P_damage_given_pos*100:.2f}%")
print()
