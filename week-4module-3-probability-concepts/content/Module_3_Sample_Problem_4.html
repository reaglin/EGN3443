Module 3 Problem 4. Series System Reliability: Pipeline System

This problem demonstrates how to calculate reliability for a series system where failure of any component leads to system failure.

Key concept: For a series system, the overall reliability is the product of the individual component reliabilities.

Solution: The overall system reliability with five components in series is approximately 0.9646 or 96.46%. Improving each component's reliability by 0.5% would increase the system reliability to about 0.9829 or 98.29%.

Both Python and R implementations provide the same mathematical results but showcase the different syntax and approaches of each language. The code also demonstrates how to visualize series system reliability trends as the number of components increases.

Python Solution (link)

# ======================================================================
# 4. Series System Reliability: Pipeline System
# ======================================================================
print("Problem 4: Series System Reliability - Pipeline System")
print("---------------------------------------------------")

"""
Problem:
A fluid transport system consists of five pipeline sections connected in series.
The reliability (probability of no failure) for each section is:
- Section 1: 0.992
- Section 2: 0.995
- Section 3: 0.990
- Section 4: 0.994
- Section 5: 0.993

Calculate the overall system reliability. Also, determine how the reliability
would improve if each section's reliability was increased by 0.5%.
"""

# Python solution
section_reliabilities = [0.992, 0.995, 0.990, 0.994, 0.993]

# For a series system, overall reliability is the product of component reliabilities
system_reliability = np.prod(section_reliabilities)

# Calculate improved reliability with 0.5% increase in each section
improved_reliabilities = [min(r + 0.005, 1.0) for r in section_reliabilities]
improved_system_reliability = np.prod(improved_reliabilities)

print(f"Individual section reliabilities: {section_reliabilities}")
print(f"Overall system reliability: {system_reliability:.6f} or {system_reliability*100:.4f}%")
print(f"Probability of system failure: {1-system_reliability:.6f} or {(1-system_reliability)*100:.4f}%")
print(f"Improved section reliabilities: {improved_reliabilities}")
print(f"Improved system reliability: {improved_system_reliability:.6f} or {improved_system_reliability*100:.4f}%")
print(f"Reduction in failure probability: {((1-system_reliability)-(1-improved_system_reliability))/(1-system_reliability)*100:.2f}%")

# Visualization of system reliability as components increase
def plot_series_reliability(base_reliability, num_components):
    components = np.arange(1, num_components + 1)
    reliabilities = [base_reliability ** n for n in components]
    
    plt.figure(figsize=(10, 6))
    plt.plot(components, reliabilities, 'b-o', linewidth=2)
    plt.title('Series System Reliability vs Number of Components')
    plt.xlabel('Number of Components')
    plt.ylabel('System Reliability')
    plt.grid(True)
    plt.ylim(0, 1)
    # Return figure instead of showing to work in artifact
    return plt.gcf()

# Visualization of system reliability as components increase
plot_series_reliability <- function(base_reliability, num_components) {
  components <- 1:num_components
  reliabilities <- base_reliability ^ components
  
  # Create plot
  plot(components, reliabilities, type="b", col="blue", lwd=2,
       main="Series System Reliability vs Number of Components",
       xlab="Number of Components", ylab="System Reliability",
       ylim=c(0, 1), pch=16)
  grid()
}
